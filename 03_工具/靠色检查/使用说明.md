# 靠色检查（脚本）

扫关卡文件，筛出**命中指定靠色对**的关卡；默认口径是 2026-10-26 用户指定的 **16 对**。

## 口径

**默认 16 对靠色对**（2026-10-26 用户指定，顺序同用户给的清单）：

```
1-6 · 1-4 · 4-6 · 2-3 · 2-5 · 3-5 · 2-8 · 3-8
9-10 · 9-11 · 10-11 · 19-22 · 25-29 · 28-29 · 20-22 · 21-23
```

- 一关里某一对的两种颜色**都出现**即命中（各 ≥ `minPixels`，默认 1）；命中多对全部列出；**不按 RGB 距离**判定。
- 统计范围：目标图 `blocks`、棋盘 `spools` 的 `cell.id`、管道 `cell.param` 内元素；只算正整数编号，忽略 `0` / `-1`。
- 色名以主 bin 色表 `bin/js/utils.js` 的 `AntSolver.COLORS` 为准。
- 支持两种关卡文件：
  - `.txt` 像素矩阵（首行 `像素矩阵`，其后每行空格分隔的色号）——只有目标图；
  - `.json` 关卡（`blocks` + `spools`）——覆盖棋盘/管道。

## 用法

```bash
# 默认扫 仓库根/关卡，结果落到 03_工具/靠色检查/输出/
node 03_工具/靠色检查/靠色检查.js

# 指定目录/文件（可多个）
node 03_工具/靠色检查/靠色检查.js 关卡
node 03_工具/靠色检查/靠色检查.js 输出文件/xxx/合格关卡

# 只留命中关的 CSV、调阈值、临时换一套靠色对
node 03_工具/靠色检查/靠色检查.js 关卡 --no-clean
node 03_工具/靠色检查/靠色检查.js 关卡 --min-pixels 2
node 03_工具/靠色检查/靠色检查.js 关卡 --pairs "1,4;2,3"

# 把命中关 / 未命中的关复制出来（只复制，不动源文件）
node 03_工具/靠色检查/靠色检查.js 关卡 --copy-hit 03_工具/靠色检查/输出/命中关卡
node 03_工具/靠色检查/靠色检查.js 关卡 --copy-clean 关卡_无靠色

# CI：有命中时退出码 2
node 03_工具/靠色检查/靠色检查.js 关卡 --fail-on-hit --quiet
```

## 输出

| 文件 | 内容 |
|---|---|
| `输出/靠色检查结果.csv` | 每关一行（含未命中），列：关卡文件 / 尺寸 / 命中靠色 / 命中对数 / 靠色对明细（带两色像素数） |
| `输出/命中关卡.txt` | 命中关的文件名清单，一行一个 |
| `输出/靠色检查结果.json` | 机器可读：规则、汇总、每关命中对与各色像素数 |

控制台会打印命中关清单（含每对的两色像素数）、未命中关清单、各靠色对命中关数。
