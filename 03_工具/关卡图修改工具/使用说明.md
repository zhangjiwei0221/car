# 蚂蚁拿块关卡图修改工具 · 使用说明

> **2026-10-28 起，本工具只做「图纸」：修改、主体提取、图纸库、拼接、导出。**
> 求解路线、进度区间、多路线复核、自动演示、暂存压力图、重构关卡、待导出库、
> 棋盘/暂存对比等游玩与关卡生产功能已从界面和启动流程中移除。
>
> 旧版说明（包含这些功能）已备份为 `使用说明.md.bak-20261028`，仅作历史参考。

## 1. 这个工具做什么

一条链，四件事：

1. **改图**：导入 TXT 像素图纸，在画布上绘制、框选、套索、按色选、换色、导出。
2. **抠主体**：把主体框出来，剔掉框外杂物或挖空框内杂物，位置写 `0`，画布尺寸不变。
3. **攒图纸**：把抠好的主体存进浏览器本地「图纸库」，可导出 ZIP / JSON，也可再导入。
4. **拼接**：新建一张自定规格的画布，把多个图纸摆上去，加背景/包围/分隔，手工补画，最后导出拼接图 TXT。

它**不读取关卡本体、不求解、不模拟、不生成关卡、不评估可玩性**。页面只加载颜色表、
TXT 解析、碎色口径这几个纯数据工具，不加载 Solver / Simulator / PlayerSim / 生成器流程。

## 2. 快速开始

1. 打开工具：
   - 双击本目录的 `一键启动.command`；或
   - 在本目录起一个静态服务，访问 `index.html`（推荐用无缓存服务 `无缓存静态服务.py`）。
   **默认直接进入拼接工作台。**
2. 拼接：设画布规格 → 「② 部件来源」用「导入 TXT 图」或「导入文件夹」拿部件 →
   「放上画布」→ 拖动/几何手绘/规则生成 → 「导出拼接图 TXT」。
3. 改单张图：顶栏点「🎨 回到修图」→ 左栏「1. 导入图纸」选 TXT（可整文件夹）→
   点列表里的图 → 右栏「3. 美术编辑」勾「开启编辑模式」。
4. 改完点「导出修改后 TXT」；只想要截图就点「导出当前视图 PNG」。
5. 要抠主体 → 用选区工具圈住 → 「4. 主体提取」里点「只保留选区内」→「加入图纸库」。
6. 想回拼接 → 顶栏「🧩 拼接图纸」。

## 3. 导入图纸

### 3.1 文件格式

只接受 `.txt`。格式是像素矩阵：

```text
像素矩阵
0 0 1 1 0 ...
0 2 2 1 0 ...
...
```

- 第一行通常是标题（`像素矩阵`），解析时会跳过；
- 之后每行是空格或逗号分隔的色号；
- `0` 表示空位，`1–34` 是标准色号；
- 每行宽度必须一致，否则该文件会被判为解析失败并在日志里报错。

### 3.2 导入方式

- **选择 TXT**：一次可多选；
- **选择文件夹**：递归读取子目录，适合整批导入；
- **清空**：清掉当前列表与编辑状态，不影响图纸库。

列表按文件名排序，右侧显示尺寸；上方过滤框可按名字筛选。同名文件重复导入会覆盖同一张图纸。

## 4. 查看与导出

画布上方有一条统计条，直接显示：**画布尺寸、用色种数、非空/总格数**。
颜色数只统计 `> 0` 的颜色，**不含空位 0**；拼图模式下这条会换成拼接画布自己的「颜色 N 种」。

画布右侧「2. 显示与导出」：

- **像素尺寸**：4–24 px/格，只影响显示，不影响导出的色号；
- **显示格线**：格线只是参考线，不写进数据；
- **显示空位**：把值为 `0` 的格子画成斜纹，剔除后能看清主体边界；
- **描选区边**：把当前选区轮廓描出来；
- **导出当前视图 PNG**：导出你看到的画布（含格线、选区、碎色高亮等叠加效果）；
- **导出修改后 TXT**：在「3. 美术编辑」卡片里；
- **导出对比报告**：列出改动像素数与逐色变化，Markdown 格式。

鼠标悬停在画布上，底部读数会显示 `行 / 列 / 颜色名(色号)`；空位显示「空位（值 0）」。

## 5. 美术编辑

### 5.1 开启编辑

勾「开启编辑模式」，画布进入可编辑状态。切换图纸或点「清空」会自动退出编辑。

### 5.2 五种工具

| 工具 | 用途 |
|---|---|
| 拖动绘制 | 按住拖动，把经过的格子改成当前颜色 |
| 矩形框选 | 拖出一个矩形选区 |
| 套索 | 按住拖出任意形状，松手自动闭合成选区 |
| 同色块 | 点一下，选中与该格同色且四连通的整块 |
| 按色选 | 点一下，选中该颜色的全部像素（不管连不连通） |

绘制工具需要先在下方色库点一个颜色。`0` 不在色库里；清空像素请用「主体提取 → 挖空选区内」。

### 5.3 叠加方式

框选类工具默认「替换」旧选区；也可以选：

- **加选**：并到当前选区上（等同按住 `Shift`）；
- **减选**：从当前选区里挖掉（等同按住 `Alt`）；
- **交集**：只保留与当前选区重叠的部分。

「交集 + 按色选」是去毛边的关键组合：只清掉圈内的某个颜色，主体轮廓上的同色不受影响。

### 5.4 改色、撤销、还原

- 点色库里的色块 = 把当前选区（或光标下的格子）改成该色；
- 色库上方会显示这张图**已有的颜色**和像素占比，未使用的颜色在边框外；
- 「撤销」按批次退回，一次拖动/一次替换算一批；
- 「还原为原图」会丢弃本张图纸的全部像素修改，需要二次确认；
- 「只在选区内绘制」勾上后，拖动绘制只影响选区内的格子。

### 5.5 去毛边配方（边缘与主体共用描边色）

1. 套索圈住要清理的边缘一带；
2. 叠加方式选「交集」；
3. 用「按色选」点一下描边色（或在「选区内颜色」里点该色的「只选」）；
4. 到「4. 主体提取」点「挖空选区内」。

这样只清掉圈内的该色，主体轮廓上的同色一格不动。

### 5.6 靠色检查

固定 5 组容易混淆的颜色，全图统计各自像素数。用来提前发现「两种颜色太接近，
玩家在棋盘上看不清」的问题；只作提示，不阻断导出。

### 5.7 碎色率检查

- 口径与生产端碎色闸门同源（`js/fragment.js` 调用 `bin/js/generator.js` 的同一个函数）；
- 默认阈值 18%，可下拉切换 11.47% / 10.54% 等档位，也可自定义；
- 点「重新计算」后给出碎色率、等级、碎块数、最碎单色；
- 勾「高亮碎色像素」会在画布上标红，直接看该修哪里；
- 修改像素后结果会标记为过期，需要重新计算。

## 6. 主体提取

前提：先在「3. 美术编辑」里做出选区。

- **只保留选区内（剔掉框外）**：选区外的像素全部写 `0`；
- **挖空选区内（删掉杂物）**：选区内的像素全部写 `0`；
- **撤销上一步剔除**：按整图快照退回；
- **还原为原图**：退回本张图纸导入时的状态（二次确认）。

面板会实时显示：

- 画布尺寸（剔除不改变尺寸）；
- 当前非空像素 / 总格数；
- 选区格数、其中真正有像素的格数；
- 剔掉框外 / 挖空框内后各剩多少像素；
- 主体外接矩形（拼接时用它做平移参考）。

### 自动选法辅助

- **选四角同色块**：把四个角各自的同色连通块合并成选区，适合背景铺满外圈的图；
- **只留最大连通块**：按非 0 像素的四连通块切分，只保留最大的一块；
- **选中零碎小块**：选中所有不超过阈值的独立小块，适合剔完背景后清碎渣。

这三个都是加速器，复杂图仍以手动框选/套索为主。

## 7. 图纸库

- 「加入图纸库」保存当前图纸（可填名字，留空用文件名）；
- 图纸库存在浏览器 `localStorage`，刷新不丢，每站点约 5 MB；
- 列表里每张图有缩略图、像素数、画布尺寸；
- **载入**：把该图纸载回当前画布（要求尺寸与当前图纸一致）；
- **移除**：从图纸库删除；
- **导出图纸库 ZIP**：`图纸/*.txt` + `清单.csv` + `说明.md`；
- **导出图纸库 JSON**：单文件备份，可用「导入图纸库 JSON」恢复；
- **清空图纸库**：删除全部本地图纸，需要先导出备份。

## 8. 图纸拼接

页面默认进入拼接工作台；点顶栏「🎨 回到修图」或工作台里的「退出拼接」回到普通修图。

### 8.1 新建画布

填行、列（4–200），点「新建画布」。画布规格决定导出 TXT 的尺寸。
「清空画布」只移除画布上的图层，部件列表保留。

### 8.2 部件来源

- **导入 TXT 图**：可多选，直接作为部件；
- **导入文件夹**：递归读取整个文件夹，只收 `.txt`，其余文件自动忽略；
- **从图纸库全部添加**：把图纸库里的图全部带进来；
- **清空部件列表**：只清列表，不影响已摆到画布上的图层。

每个部件显示尺寸、像素数、实际占位（外接矩形）。点「放上画布」成为一个图层。

### 8.3 图层操作

- 在画布上直接拖拽挪位；
- 选中后用方向键逐格微调，`Shift` + 方向键一次 5 格；
- 画布上 `Shift` 点击或列表里 `Shift` 点名字 = 多选；
- 「合并选中图层为新主体」把多选合成一个整体；
- 每个图层可改名、复制、换色、置顶/置底、上移/下移、居中、固定、隐藏、移除。

部件允许重叠。导出时按图层从底到顶合成，同一格只输出最顶层像素。

### 8.4 规则生成

- **主体包围**：按包围宽和包围色，在主体外扩一圈；
- **背景**：斜纹 / 棋盘 / 点缀 / 条纹 / 纯色，主色 + 辅色；
- **主体分隔**：按分隔色、线宽、距离，在主体之间画分隔线；
- **生成背景+包围+分隔**：一次生成三类规则层。

规则层是独立图层：背景默认最底，分隔与包围在主体下方。重新生成同类规则会替换旧规则层，
不会改主体原图。

### 8.5 手工补画

工具：移动图层 / 手动涂色 / 直线 / 填充 / 边框 / 几何手绘。

- 画布上没有图层时直接画，会自动新建一张覆盖整张画布的「绘制层」；
- 已选中图层时，画在选中图层上；
- 线宽可调，勾「当橡皮擦」可把经过的格子涂成空；
- **几何手绘**：矩形 / 椭圆 / 三角形 / 菱形，在画布上拖一个范围，松手生成；
  - 勾「实心图形」= 实心；
  - 不勾 = 空心，空心粗细用「线宽」；
  - 预览会在落笔前显示，松手才真正写入；
- 边框形态：田字格 / 口字型 / 斜线型 / Z型 / L型 / N型，可拖范围生成，也可「铺满整张画布」；
- **自动生成田字格四框**：一键按当前画布均分成 2×2 四个独立框。
  - 尺寸随画布自适应：40×40 → 四个 20×20；55×55 → 27×27 / 27×28 / 28×27 / 28×28；
  - 四个框各自成环、互不重叠，中缝是两条边框（2×线宽）；
  - 线宽用「线宽」，颜色用当前画笔色；生成后可在「边框部件」列表里单独给某个框换色；
  - 改画布尺寸后，再点一次按钮即可按新尺寸重算（不会自动缩放已有图层）；
- 生成后可在「边框部件」列表里单独给某个部件换色；
- 选中的图层可「导出为模块 TXT」，以后再当部件导入。

### 8.6 撤销 / 重做

- 顶栏与卡片里都有 `↶ 撤销` / `↷ 重做`；
- 快捷键 `Ctrl/⌘+Z` 撤销，`Ctrl/⌘+Shift+Z` 或 `Ctrl+Y` 重做；
- 放上部件、生成规则层、拖动、合并、删图层、改画布规格、画的一笔都能逐步退回；
- 方向键连按会合并成一步撤销点。

### 8.7 出图

- **检查输出**：统计画布尺寸、图层数、非空像素、覆盖格、画布外裁切；
- **最终效果图**：按图层拍平后的预览；
- **要求背景填满后才能出图**：勾上时，背景没铺满会阻止导出；
- **导出拼接图 TXT**：输出当前画布拍平后的像素矩阵；
- **存入图纸库**：把拼接结果作为一张新图纸保存。

「稀少颜色检查」可指定阈值（默认少于 8 格），列出每种颜色的用量，并可高亮/替换，
避免成图里出现一两个像素的孤立颜色。

## 9. 文件与存储

- 图纸库：`localStorage` 键 `antArtTool_pieceLibrary_v1`；
- 界面偏好（卡片折叠）：`localStorage` 键 `antArtTool_uiPrefs_v1`；
- 旧版本的待导出库键 `antArtTool_exportLibrary_v1` 不再读写，旧数据不会被主动删除；
- 清浏览器站点数据会同时清掉图纸库，重要图纸请先导出 ZIP/JSON。

## 10. 常见问题

**导入后列表里没有图？**
看运行日志的「解析失败」行。最常见原因是首行不是像素矩阵、每行宽度不一致、或用了 `.json`。

**画布上点不动？**
先勾「开启编辑模式」。如果当前工具是框选类，单击只会改选区，不会改像素。

**「导出修改后 TXT」导出的是原图？**
只有真正改过像素后按钮才有意义；如果只是看了看，导出内容与原图一致是正常的。

**拼接导出被拦住？**
检查「要求背景填满后才能出图」是否勾着，以及背景层是否覆盖整张画布。

**图纸载入失败？**
「载入」要求图纸尺寸与当前画布一致。拼接请用「放上画布」，不要用「载入」。

**碎色率一直显示过期？**
每次改像素都会让旧结果失效，点「重新计算」即可。

## 11. 代码结构与维护

```text
index.html              页面结构（只保留导入/显示导出/美术编辑/主体提取/拼接）
css/style.css           样式
js/app.js               界面与交互
js/core.js              图纸口径：解析/序列化/掩码/剔除/拼接合成
js/fragment.js          碎色率口径（调用 generator.js 的同一个函数）
bin/js/utils.js         34 色颜色表
bin/js/generator.js     TXT 解析与碎色计算（只用到这两个纯函数）
```

- 页面**不再加载** `solver.js` / `simulator.js` / `solver-strategy.js` / `playersim.js` /
  `analysis.js` / `zip.js`；
- 改完先跑：

```bash
node --check js/app.js && node --check js/core.js && node --check js/fragment.js
```

- 版本号：`index.html` 的 CSS query 为 `v=16`，`core/app` 为 `v=16`，`fragment` 为 `v=10`，
  bin 两个脚本为 `v=114`。

## 12. 回归检查清单

每次改动后至少过一遍：

1. 页面加载无控制台报错；
2. 导入 1 张 TXT，画布显示尺寸正确；
3. 开启编辑，拖动绘制 1 笔，改动统计增加；
4. 矩形框选，主体提取「只保留选区内」，再撤销；
5. 加入图纸库，刷新页面后仍在；
6. 进入拼接，新建画布，从图纸库放上部件；
7. 生成背景，检查输出，导出 TXT；
8. Ctrl/⌘+Z 能退回上一步；
9. 退出拼接，普通画布仍能正常编辑。
