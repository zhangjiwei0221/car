使用说明

1. 导入

按文件名（去扩展名）自动配对同一关：xxx.txt 目标图 / xxx.json 正式关卡本体 / xxx.solve.json 求解数据（可选）。.txt、.json 以外的文件自动忽略。

选择文件夹会递归读取子目录，一次可导入整批（例：输出文件/348关工具导入包/）。 批量导入只做配对与索引，不会自动求解、也不会自动跑多路线。

2. 求解路线

请先选择一关

有现成求解数据时直接回放真实通关路线；没有则现场调用正式求解器求解。 冰块耐久统一按 3 还原。

3. 进度区间

进度口径 = 已完成盒数 ÷ 总盒数（审核统一口径）。盒进度离散，工具会把你输入的上下限吸附到最近的实际可达进度。

4. 多路线复核（按需）

由你主动启动，最多取 3 条不重复的可通关路线；重复路线自动去重，未通关路线不参与统计。批量导入不会自动跑多路线。

        这两个只是加速器。实测 44 张 20×20 素材里，四角同色块一击能剔掉 ≥25% 的只有 20 张，
          有 5 张几乎剔不动（边缘是噪点或整张密铺纹理）—— 主力仍是手动框选与套索。

        重叠格只输出最顶层的像素 id。
