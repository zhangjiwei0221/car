## 1. 术语

| 术语 | 含义 |
|---|---|
| 盒序列 / 消除顺序 / `elimSeq` | 目标图按趋势切分出的盒，及其消除先后下标 |
| 棋盘填入趋势 | 棋盘格 **左→右、首行→尾行** 顺序填盒（顶部先被取=先消除） |
| 骨架 | 棋盘尺寸 + 黑块/墙 + 占位管道（填球前先确定的结构） |
| 占位管道 | 既充当障碍/墙占格制造窄路，又作为盒容器参与顺序填入 |
| 进度区域 | 按初解 `pickOrder` 把每个盒归入 0–100% 进度段 |
| 卡点 | ≥50% 进度段被结构性制造的高压点 |
| 合法性门 | 路线卡死可达检验 + 全知求解可解 |
| 审核门 | `chokepointAudit` 压力四条件 + 玩家版通关（见评分体系） |
| 候选 / 分支 / 轮 | 候选=初生成关；分支=一次卡点制造变体；轮=一次"制造+求解+审核"迭代 |

## 2. 总体架构：多轮候选审核树

> **P3 起用本树取代老版"candidateCount + strengthenBudget 爬山强化"**：爬山(单路径微调、按预算步数迭代)与 `strengthenLevel` 为老策略，**已决定退役**；改用下述 **BxN 分支树 + 卡点制造/换球策略**（B 分支多样性、N 轮、1 关合格即停）。玩家版犯错逻辑(`playersim`)保留不变。

### 2.1 预算参数（算力预算，随时可调）
| 参数 | 默认 | 示例 | 说明 |
|---|---|---|---|
| `candidateCount` 候选数 | **5** | 10 | 每个源图初生成的候选关数 |
| `chokeBranches` B（分支） | **3** | 3 | 每次卡点制造的变体数 |
| `rounds` N（轮） | **2** | 3 | 制造+求解+审核的迭代轮数 |
| 候选总量上限 | `candidateCount × Bᴺ` | 5×3²=**45** | 示例 10×3³=270 |

> 预算权衡：算力紧张时**降候选、增轮次** → 剪枝更多、单支更深。

### 2.2 流程
1. **初生成**：产出 `candidateCount` 个候选，各做 **1 次合法性门检验**。
2. **第一轮求解**：每候选初次求解 → 得棋盘盒排序（消除顺序）与进度区域。
3. **卡点制造（B 支）**：对候选做 B 次卡点制造 → B 个变体，各自求解+审核。
4. **判定**：**任一变体合格 → 立即输出并结束该源图**（目标只需 1 关合格）。
5. **不合格 → 下一轮**：对不合格变体再各分 B 支（第二轮起附带**增压/减压修复**，见 §3.4）。
6. **执行至多 N 轮**或预算耗尽；`candidate × Bᴺ` 内产出合格即停。全程无合格则**兜底输出最接近合格**者（标 `pass=false`）。

### 2.3 树形示意（单候选）
```
候选C(合法) ──求解──▶ 卡点制造 ×B
                        ├─变体1 ─审核─▶ 合格? 输出&停 : 再×B (第2轮,带增减压修复)
                        ├─变体2 ─审核─▶ ...
                        └─变体3 ─审核─▶ ...
     深度 = N 轮，分支 = B，单候选叶子 ≤ Bᴺ
```

## 3. 单关生产规则

### 3.1 建棋盘（初始棋盘生成）
按顺序执行：

1. **尺寸（随机）**：在 `[boardRowsMin,Max] × [boardColsMin,Max]` 范围内**随机**选行列组合（改动：现为"选最小可容纳尺寸"）。盒装不下的部分由管道吸收（见步 3/5 守恒）。
2. **默认黑块/墙**：填入黑块/墙并占格（含窄路墙体）。
3. **占位管道（守恒对齐）**：
   - **守恒公式**：`棋盘有效空位(尺寸格数 − 黑块/墙占格) + 管道数 × 每管容量(4~6) = 盒总量`。
   - 由此**反推管道数**：`管道数 = ⌈(盒总量 − 有效空位) / 每管容量⌉`（溢出量决定管道数）。
   - (a) 管道占位**可充当黑块/墙** → 一并参与制造窄路；
   - (b) **化用参考生产包管道策略**：`关卡生产包/tool/.../elementManager.js` 的 `_distributeToPipes`（管道按位置排序、顺序平铺）+ `levelGeneratorFree.js` 尺寸/黑块/管道思路；
   - (c) 遵守现有限制：`pipeRowStart`（不在首行/末行）、出口在盘内且合法、连通可达校验、每管容量 `pipeBallMin~Max`(=4~6)。
4. **基础填球（消除顺序，逐行左→右）— 第一遍单扫**：把盒序列**逐行从左到右**依次填入，每个棋盘格**只扫一遍**：
   - 遇**普通空格 / 管道出口**格：正常填入 1 个盒；
   - 遇**管道本体**格：把当前盒**填入该管道队列**（**新增功能**）——因单扫每格只填 1 个，故第一遍**每个管道只得 1 个盒，必不填满**。
5. **溢出填管道（第二遍均匀）**：全棋盘扫完后，多余的后置顺序盒按**行数顺序均匀填入剩余管道空位**（管道按位置：行序、同行左→右；round-robin 平铺直至各管达每管容量）。
6. **顺序自检**：填完后棋盘应呈"消除顺序正常填入"（趋势：左→右、首行→尾行）。**加测试校验**填入顺序与消除顺序一致。
7. **首批障碍**：**只有锁链填入 50%**；**问号/冰块全部填入**。剩余 50% 锁链留到卡点阶段填（当前不填）。〔**可调**：此比例为轻量预设，标记为可调参数〕

- **候选差异**：步骤 **1/2/3/6** 按不同策略生成不同候选；**填球顺序（4/5）在候选间一致**。
- **合法性门**：建完做一次「路线卡死可达 + 全知求解」检查，合法才进入求解阶段。

### 3.2 初次求解 + 消除趋势
- 对候选初次求解，期望结果符合默认趋势：**目标图由底部+左右侧向中心消除**（偶因卡点蔓延顶部），**棋盘从首行往下逐行拿盒**。
- 按求解 `pickOrder` 把每个盒划入**进度区域**（0–100%）。

### 3.3 卡点制造（针对 ≥50% 进度段）
**按优先级顺序**尝试（有效性需逐一优化+检验，见 §10）：
1. **换球 / 换盒容量**〔优先级 1〕：依赖链条关键位置换色或调容量，制造依赖卡点。
2. **锁链带动无用球**〔优先级 2〕：用留存的另一半锁链，把无用球绑到关键取法上。
3. **关键颜色分散 / 藏管道**〔优先级 3，**逻辑待定义**〕：把"解锁关键区域所依赖的目标颜色"分散或藏进管道，延后其可得性。
4. **冰块加冰**〔优先级 4，弱扰动，**待定**〕：关键位置加冰；也许更适合**加在锁链上**联动，而非独立使用。
- **目标**：全知版 + 玩家版**都可解**，且符合预期卡点需求（后期高压）与前中期压力阈值。

### 3.4 卡点轮次与增减压修复
- 每候选：卡点制造 **B 次**、求解 **B 次**；合格即输出。
- 不合格 → 下一轮**修复**，执行**增压/减压**：
  - 前期过压（早爆）→ **减压**；后期欠压（无卡点）→ **增压**。
  - **级别定义**：以**障碍基础参数**为基准，**每级 5%**，**增/减各最多 3 级**，参数落在 `基础 × (1 ± 15%)`、**总波动范围 30%**。
  - 〔**待确认**：作用的障碍参数集（黑块%/冰%/问号%/锁链数/管道数…）与增减方向映射；是否复用现有 `strengthenLevel` 扰动。见 §10〕

## 4. 审核 / 合格门（引用 `生产审核评分体系.md`）

- **合法性门**：路线可达 + 全知可解（`structuralDeadlockCheck` + `Solver.solve`）。
- **审核门**（`chokepointAudit`，全知压力样本，暂存上限 `L`）：
  - ① 后期 50–100% 至少 1 个 10% 窗均值 ≥ 高压阈值 `L−1.5`；
  - ② 前期 0–20% 无 5% 窗均值 ≥ 中压阈值 `L−2.5`；
  - ③ 中期 20–50% 无 5% 窗均值 ≥ 高压；
  - ④ 全程暂存峰值 `< L`（不触死亡边界）。
- **玩家版通关**（`PlayerSim`）：真人口径必须能通关，否则不合格。
- **难度分**：本行所列为历史 **v2** 口径（f1 平均暂存 0.45 / f2 平均滞留 0.25 / f3 障碍 0.10 / f4 全知-玩家偏移 0.20）。**当前为 v3**：f1 改用**玩家版**平均暂存 + 玩家每复活一次 +8 分（≤2 次），权重框架不变；详见 `生产审核评分体系.md` §4b（2026-07-27 治理标注）。

## 6. 与现状的差异（重构点清单）

| 环节 | 现状 | 重构后 |
|---|---|---|
| 尺寸 | 选最小可容纳 | **范围内随机** |
| 管道数 | 由 pipeCountMin/Max + 行挤压对齐 | **由守恒反推**（有效空位+管道容量=盒总量） |
| 建棋盘顺序 | 尺寸→墙→黑→管道→铺盒→障碍 | 尺寸(随机)→黑/墙→**占位管道**→**顺序填球(含管道本体单扫填入)**→**第二遍均匀填管道**→**障碍(锁链50%,问号/冰全)** |
| 铺球 | 交错随机 + 溢出 round-robin | **严格逐行左→右顺序**（消除顺序） |
| 障碍 | 一次性放全部 | **锁链 50% 初填**（+问号/冰全填）**+ 锁链另一半留卡点阶段** |
| 卡点 | 解后随机区域换球 | **定向四类卡点(优先级)**，每候选 B 次分支 |
| 顶层 | produce 两轮 | **多轮候选审核树** `candidate × Bᴺ`，1 关合格即停 |

## 7. 待确认问题（已对齐结论）

- **Q1 输出/预算** ✅：1 关合格即输出并停；`candidate×Bᴺ`（默认 45，上限示例 270）为预算上限；无合格则兜底输出最接近者。
- **Q2 尺寸随机** ✅：范围内随机；装不下的盒由管道吸收（管道数守恒反推）。
- **Q3 管道容量/填入** ✅：每管容量 4~6；第一遍单扫每管只填 1 个（必不满），第二遍均匀填满剩余。
- **Q4 溢出分配** ✅：按管道位置（行序、同行左→右）round-robin 均匀填至每管容量。
- **Q5 障碍两批** ✅：仅锁链填 50%，问号/冰全填（比例可调，已标记）。
- **Q6 趋势对应** ✅：目标图"底部+左右→中心"消除 ↔ 棋盘"首行→尾行"拿盒；`_seq` 即此口径。
- **Q7 卡点优先级** ✅：1 换球/容量 → 2 锁链带无用球 → 3 关键色分散/藏管道 → 4 冰块（弱）。按优先级尝试。
- **Q8 增减压** ✅（级别）：障碍基础参数 5%/级、±3 级、总波动 30%。〔具体参数集与方向映射待 §10 细化〕
- **Q9 性能** ✅：默认预算降至 5×3²=45；轻量预筛/早停列为可选优化（§10）。
