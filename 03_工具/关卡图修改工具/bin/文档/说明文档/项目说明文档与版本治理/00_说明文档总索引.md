## 状态词表

| 状态 | 含义 |
|---|---|
| `CURRENT` | 描述当前正式在用逻辑，已核对代码一致 |
| `PARTIAL` | 当前有效，但内容不完整（缺里程碑/字段/公式） |
| `EXPERIMENTAL` | 实验规则或实验产物，非正式发布 |
| `HISTORICAL` | 历史逻辑存档，非当前行为 |
| `REFERENCE` | 参考代码/资料 |
| `STALE` | 与当前代码冲突、尚未修订 |

## 证据强度（贯穿所有治理文档）

- `E1 记录证据`：仅出现在需求/更新记录/日志。
- `E2 代码证据`：当前代码存在且调用链可达。
- `E3 静态验证`：语法 / 数据结构 / 离线探针验证。
- `E4 实机验证`：浏览器真实交互 / 批量生产 / 实际产物验证。
