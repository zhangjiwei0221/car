# 拆图 / 选图 / 验证（只读工具）

> 这个目录里的脚本**不改生产、不写 `输出文件/`**，只回答三个问题：
> **这张图由什么组成（拆图）**、**哪张图值得先产（选图）**、**换切法/换图之后生产会怎样（验证）**。

## 口径（先说清词）

| 口语 | 本目录统一用 | 定义 |
| --- | --- | --- |
| 矿脉 | **色块 / 同色连通块** | 4-连通、同色的最大像素集合；与怎么走、怎么切无关 |
| 层 | **依赖层 / 剥离深度** | 色块邻接图上，从"外部可达"出发的 BFS 层号 |
| 序号 | **贪心日程** | 求解器 🔢 那个：每轮选当前可达像素最多的颜色整片吃掉 |
| 债务 Δ | **解锁延迟** | 实际轮到 − 理论最短 |

## 四个脚本

### 1. `拆图报告.js` —— 一张图的全景
```bash
node 拆图报告.js <目标图.txt> [输出.html]
```
产出 HTML：三张同图（原图色 / 依赖层 / 贪心日程）、层表、**每个颜色的最浅层**、四种切法车单、
纯切球层干跑曲线、判据、**压力旋钮**（每笔提前几辆车 → 峰值几辆）。

### 2. `扫图_深层色.js` —— 批量选图（软筛选）
```bash
node 扫图_深层色.js                       # 扫 输出文件/（历史全部，自动去重）
node 扫图_深层色.js <目录或txt> [更多…]    # 扫任意目录
node 扫图_深层色.js --out 结果.csv <目录>
```
输出分级 + `选图_深层色.csv`：

| 分级 | 含义 | 实测（方案_小图33-40，4 seed） |
| --- | --- | --- |
| A 深色充足 | ≥3 个"≥3 层才露脸"的色、深层像素 ≥15% | 合格 3/4、峰窗 3.5~4、稳健 100%、被埋 0 |
| B 深色不足 | 有深色但不够 | 压力主要靠障碍 |
| C 无深层色 | 0 个 | 合格 0/4，其中一局 被埋 2 + 稳健 0% |

> ⚠ **不做一票否决**：用户认可的"小鹿"是 C 级（它的长债来自**容量**，不是层深）。
> 这个判据只覆盖"层深型"长债，用来**分方向、排优先级**。

### 3. `真跑一关.js` —— 生产链路验证
```bash
node 真跑一关.js <目标图.txt> [更多…]
node 真跑一关.js --scheme <方案.json> <图…>
node 真跑一关.js --cut-only <图…>          # 障碍全关，只看切球层
node 真跑一关.js --fit-small <图…>         # 小图适配（闸门放宽、盒 14~30）
node 真跑一关.js --layer-cut [--order-static] [--beats N] [--beat-pos 15,60,80] <图…>
SEED=123 node 真跑一关.js <图…>            # 换种子（生产用的是 Math.random，必须多 seed）
```
打审核档 / 峰窗 / 被埋 / 玩 18 遍。`--layer-cut` 是实验路径（把按层切的 `forcedBoxes` 直通生产），
**结论已记录为负结果**（工作日志 39.6）：直通后的关卡不如生产默认的按日程切，不接进生产。

### 4. `选图_深层色.csv` / `拆图报告_*.html`
产物，可删可重生成。

## 一起用（推荐顺序）

1. `扫图_深层色.js` 选图 → A 级优先；
2. `拆图报告.js` 看那张图的结构（有没有长债素材、碎不碎）；
3. `真跑一关.js --scheme 方案_小图33-40四方向_v1.json` 跑 4 个 seed 看合格率/公平性；
4. 合格且稳健通关 ≥50%、被埋 0 → 才进正式生产。

## 已知边界

- 干跑**不含棋盘与障碍**：它只回答"切法本身会把债务做成什么样"；61 那种死法是切法+摆位一起造成的。
- **深层色 ≠ 长债的全部**：容量型长债（小鹿）这个判据看不到。
- 生产方案里有 `inputs` 和 `config` 两份同一组参数，改方案时**两份都要改**，否则界面载入后回读会把改动覆盖掉。
