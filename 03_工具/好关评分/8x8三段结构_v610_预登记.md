# v610 预登记：8×8三段式链＋冰组合

日期：2026-10-27

## 基底

无障碍8×8、64车、0黑块基底。

三段固定：

- A 入口：`(0,1)`40 + `(1,1)`16；
- B 第二段：`(1,5)`17 + `(2,5)`17；
- C 长段起点：`(3,6)`40 + `(4,6)`17。

三段双链均至少包含一辆16/17px小车，互不重叠。

## 冰组合

在三段链的触发格上分别测试低/高两档数字冰：

- A：step2＋4/8；
- B：step15＋2/10；
- C：step21＋2/8；

每个剂量档穷举A/B/C是否加冰，共8种；两档共16个变体。

## 评价

- 求解器路线是否真的进入三段；
- maxBuffer、中段3/4、显著释放；
- qGate、freeLow、免费连、吃满中位；
- PlayerSim seed7/1009/2027；
- 容量、守恒、棋盘合同。

## 判定

- 先要求maxBuffer≥3、中段3/4>0；
- 三段组合应优于无遮挡8×8基线；
- 任一seed死亡或高剂量无解，则降低剂量或否决；
- 若三段结构仍没有压力，说明该64车容量组合不适合，需要改容量/颜色。

本实验只读，不修改v575。
