# prefix=12 步骤与 release 覆盖只读定位 · v548 预登记

> 执行前登记。本轮不是生成实验，不比较参数、不修改关卡。唯一目的：把 v547 的结构 near-miss 和 `release unknown` 定位到具体步骤、车辆、压力状态与已尝试备选。

## 1. 背景

v547 的六个 prefix=12 样本：

| 棋盘/seed | 免费连 | 吃满中位 | 中段3/4 | 结构 | 完整目标 |
|---|---:|---:|---:|---|---|
| 7×9/1001 | 5 | 4 | 56.3% | false | false |
| 7×9/1002 | 2 | 4 | 90.9% | false | false |
| 7×9/32677 | 5 | 4 | 56.3% | false | false |
| 9×7/1001 | 7 | 3 | 69.7% | false | false |
| 9×7/1002 | 6 | 3 | 75.8% | true | false |
| 9×7/32677 | 4 | 3 | 75.8% | true | false |

需要回答三个问题：

1. 7×9 的全程吃满中位为何固定为 4，具体有多少 `full>3` 步骤、理论上至少需要改变几步才能让中位≤3；
2. 9×7/1001 的 7 步免费连具体由哪些车辆组成，是否只差一辆/一段；
3. 两个结构通过样本的 `release unknown` 是当前评价器只覆盖了两个高压状态，还是已覆盖状态内也确实没有找到释压动作。

## 3. 只读定位内容

### 3.1 免费连

按结构门同一口径：

```text
free = 5 - bufferBefore
isFree = full >= 2 && free >= 3
```

输出最长连续免费段的：

- 起止步骤、索引和进度；
- 每步 solver step、棋盘坐标、box id、颜色、容量、`full/free`；
- 该段的颜色构成与连续区间。

### 3.2 吃满中位

对六个样本输出：

- `full` 直方图、总数、中位索引与中位值；
- `full>3` 的步骤数和 `minFlipsTo3 = max(0, count(full>3) - medianIndex)`；
- 所有 `full>3` 步骤的坐标、车辆、颜色、进度、free 槽和局部上下文；
- 低压力步骤（`free>=3`）的数量与吃满中位，仅作解释，不替代全程门槛。

### 3.3 release unknown

沿当前参考解重放，列出全部满足当前评价区间的高压状态：

```text
buffer >= 3
0.20 <= progress <= 0.85
```

每个状态记录：

- solver step、进度、buffer、free 槽、buffer 内颜色/进度；
- 参考动作的坐标、颜色、容量；
- 按当前评价器相同顺序得到的前三个备选动作；
- 当前评价器是否会尝试该状态（前两个高压状态）。

同时记录现有 `releaseDecision` 的：

- status/found；
- decisionsTried、alternativesTried、highPressureStates；
- solvedNoRelease、unknownAlternatives、searchLimited、elapsedMs；
- evidence（若有）。

## 4. 判定输出

本轮只产出路由证据，不产生“好关”结论：

1. 若某样本 `minFlipsTo3=1`，列出所有可作为单步局部实验的车辆，不直接修改；
2. 若免费连只超1步，列出该段中可替换的一辆车或一个边界步；
3. 若 release 评价器只尝试2个状态而存在更多未尝试高压状态，下一轮优先做 P1.1 状态覆盖；
4. 若所有已尝试状态都记录到备选搜索耗尽且没有 found，仍需先看未尝试状态数量，不能直接断定关卡无释放；
5. 若 hash 不一致，停止归因并如实报告复现失败。
