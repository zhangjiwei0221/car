# P10 真人校准 · 试玩包（v497 版）

8 个候选关，编号 A~H，**不告诉你哪个是新的、哪个是手作的**（映射在 `_映射_请勿先看.json`，玩完再看）。

本版全部候选：棋盘 6×6 或 5×6，**黑块占比 10%~28%**（上一版 A/B/E/F 是 38%，已作废）。

## 怎么玩

1. 预览服务已在跑：<http://127.0.0.1:8060/bin/index.html>
2. 页面里点「**导入关卡**」→ 选 `A.json` → 在模拟器里玩
3. 玩 1~2 遍（不用打通关也行），在 `评分表.csv` 里填 A 那一行
4. 依次 B~H，约 10~15 分钟

## 评分口径（1~5 分）

| 列 | 1 分 | 5 分 |
|---|---|---|
| 好不好玩 | 很无聊 | 很想再来一局 |
| 难度感受 | 太简单 | 太难了 |
| 前期无聊 | 开局就有意思 | 开局一大段没事干 |
| 中段压力 | 一直很松 | 中段一直憋着 |
| 后段恶心 | 收尾很顺 | 最后被卡得很烦 |
| 背答案感 | 输得明白 | 只能靠试错/背 |
| 观感 | 很乱 | 很整齐好看 |

备注随便写：哪一步让你难受、哪一下觉得爽、有没有看得懂的死因。

## 注意

- 不要先打开 `_映射_请勿先看.json`；
- 觉得某个关根本没法玩（卡死/看不清），备注写「无法玩」，也算有效数据；
- 两个手作锚点（D/E）棋盘是 5×6，低于现行「棋盘≥6」合同，只作手感对照。
