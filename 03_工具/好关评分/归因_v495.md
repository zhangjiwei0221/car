## 结论（v495，11 个失败样本）

### 归因分布

| 归因 | 样本数 | 证据 |
|---|---:|---|
| **容量带不可行（主导）** | 9（推荐 5 + 好图 4） | 推荐带 `[13,13]`、好图带 `[40,40]`；好图 38/38 辆车低于下限、推荐 96/114 辆低于下限；不可行色 13 / 11 个 |
| 容量带部分不可行 + 第0行集中 | 1（006 seed1005） | 5 色无整数拆分；第0行 7 车仅 3 色、同色 3；freeLow 51%（其余 seed 15~21%） |
| 证据不足（贴线失败） | 1（010 seed1004） | 仅 1 色不可行；freeLow 36%（门槛 30%）；单样本不足以归因车序 |
| 障碍导致 | **0** | 失败项全部是 freeLow / freeRun / 吃满中位，没有一次是 J（隐藏信息） |

### 关键事实：棋盘被容量带撑满

```
推荐：10×12 = 120 格 / 120 车（100% 填满），问号10 冰21 链11 管道2
好图：6×7   = 42 格 / 42 车（100% 填满），问号2 冰9 链9
006 ：6×7   = 42 格 / 42 车
010 ：6×7   = 42 格 / 42 车
```

容量带 → 每色车数 `ceil(N_c/min)` → 车数 → 棋盘尺寸，三者被锁在一起。带不可行时车数被推高，
棋盘跟着撑到 10×12，第 0 行排出 12 辆车（推荐），免费车自然多 → freeLow 69~86%。

### 证据边界（不猜的部分）

- 006 / 010 各只有 1 个失败样本，按总纲要求**不下"车序问题"结论**，只记为待积累（需要 ≥5 个同类失败）。
- 双时间线已对每关跑过并保存（`timeline` 字段：激活车数、第5步前激活、唯一供给车、开路边数），
  但本批没有呈现"激活明显早于需求"的一致模式，故不作为主要归因。
- 障碍不是结构门失败原因；问号/冰只影响前瞻与公平性（推荐图 look=0%）。

### 建议的 C 步（单变量，先预登记通过条件）

1. **C1 单值带退化修复**：仅当 `band[0]===band[1]` 时，把带上沿保持、下沿降到"该图所有色可整体兼容"的最小宽度；
   通过条件：推荐/好图的结构门 ≥2/5，006/010 不退化，belowMin 下降；失败则回退。
2. **C2 按色定车数**：不改带，但当某色在带内无整数解时，按 `n_c=round(N_c/chosen)` 定车数并记录该色的余量；
   通过条件同上。
3. **C3 推荐图减车/扩盘**：只改"车数→棋盘"这一环（114 车配 10×12 已 100% 填满），验证是否还要更高容量。

建议先做 C1（只影响退化带，不动 006/010 这类正常带），再用 C2 处理残余 belowMin。
