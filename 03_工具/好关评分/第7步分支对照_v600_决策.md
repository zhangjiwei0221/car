# v600 决策：债务3分支安全但马上释放，尚不构成持续压力

日期：2026-10-27

## 结果

对v599候选第7步的A/B分支，使用3个seed：

- A：取安全满解`(2,1)`颜色13；
- B：取温和债务`(1,0)`颜色30，债务3。

### d7

| 指标 | 结果 |
|---|---:|
| A/B应用成功 | 6/6 |
| A/B通关 | 3/3、3/3 |
| B取后buffer | 1（3/3） |
| B债务释放在几手后 | 1手（3/3） |
| B后续温和债务窗口 | 0/3 |
| B r9相对A | 8 vs 7 |

解释：债务3确实进入暂存，但下一手颜色13满解就完成该车，暂存立即回到0。两条分支路线保持不同，最终都能100%通关。

### d9/d11敏感性

冻结时间延长到9/11手后：

- A/B仍全部通关；
- B仍在取后形成buffer1，并在1手后释放；
- d9、d11的B路线均在后续出现新的温和债务窗口3/3；
- d11的B路线r9为11，A为10；
- 但PlayerSim后续仍选择满解，buffer没有继续叠加。

结论：冻结时长不是“一手释放”的主因；真正原因是第二手颜色13会立即补足颜色30的可达区域。

## 判断

这是一个“安全、可理解、但太轻”的卡点：

- 不会必死；
- 有真实占槽和释放；
- 比纯节点多一次决策；
- 但只持续1手，没有第二笔债务被实际承担。

因此不能把它称作持续卡点，也不接生产。

## 决策

1. 保留v599候选为实验基底。
2. 下一实验连续选择两笔债务：
   - 第7步颜色30债务3；
   - 第9步颜色30第二个债务4。
3. 两笔分支必须保持可通关，并检查buffer是否达到2、何时释放、是否还有第三次机会。
4. 若两笔债务仍立即释放，下一步必须延迟颜色13的补足供给，而不是继续加冰数量。
