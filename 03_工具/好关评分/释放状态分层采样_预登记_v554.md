# release 中段状态分层采样 · v554 预登记

> P1状态采样实验。固定8个高压状态、每状态3备选、350ms/1200节点和当前动作顺序，只改变选中哪8个中段高压状态。

## 1. 假设与证据

v553证明：

- 9×7/1002与32677的显著释放父状态是第25个中段高压状态（step39，进度约67.8%）；
- 当前只机械取路线最前8个状态（step14～21），因此完全漏掉该释放点；
- 9×7/1001只有95.1%的末段显著释放，不属于中段供给。

假设：固定8个状态，改为按中段进度分层采样并优先buffer4，就能覆盖真正释放点，而不需要增加状态数或搜索预算。

## 2. 样本与固定项

- 图：007；棋盘9×7。
- seed：1001、1002、32677。
- 配置与v547 prefix=12一致；必须匹配v547 hash。
- 参考路线、动作顺序、每状态前3备选、350ms、1200节点、releaseWindow4、minReleaseAmplitude1全部固定。
- `maxDecisionStates=8`不变。

## 3. 唯一变量：8个状态的选择

### A：v553基线

沿参考路线取最前面的8个中段高压状态；基线状态为unknown、24个动作全部budget unknown。

### B：中段四分层采样

候选状态：`buffer>=3`且进度20%～85%。

把进度区间`[0.20,0.85]`等分为4段，每段选2个：

1. 段内按buffer降序；
2. 同buffer按progress降序；
3. 再按路线顺序。

若某段不足2个，选完后从尚未选中的全体候选中按同样优先级补齐，直到恰好8个。最后按参考路线顺序执行这8个状态。
