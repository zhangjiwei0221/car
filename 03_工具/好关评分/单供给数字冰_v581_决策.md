# v581 决策：单个数字冰不能保留真实债务

日期：2026-10-27

## 结果

基底为v580 v4（吃满中位3、免费连20、freeLow86%）。

第23步首次出现真实债务4的车 `(5,0)`（颜色30、容量32、可达28）。

逐个冻结1辆干扰车的4个变体结果：

| 冰车 | 目标债务车被取 | 取时实际债务 | bufferAfter | 免费连 | 吃满中位 | qGate |
|---|---|---:|---:|---:|---:|---:|
| chosen (1,2) | 是 | -6 | 0 | 41 | 4 | 否 |
| full1 (4,4) | 是 | -17 | 0 | 20 | 3 | 否 |
| full2 (4,3) | 是 | -17 | 0 | 20 | 3 | 否 |
| full3 (4,1) | 是 | -17 | 0 | 20 | 3 | 否 |

## 解释

- 冻结一辆供给足以改变路线，但目标债务车在新路线上更晚被取，颜色已充分露出。
- 三个完全供给单冰臂与v4基线几乎相同，没有改善压力。
- 冻结当步实际选择车反而使免费连恶化到41。

## 决策

- 不增加第二个冰，不接默认生产；
- 单个障碍无法解决“债务时点漂移”；
- 下一步必须同时约束锚点出现时点和供给时点，或更换目标颜色依赖结构。
