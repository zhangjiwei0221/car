## 一、【总工派工区】为什么调高冰数字：物理意义、为什么绝不会爆炸难 & 具体施工步骤

### 0. 总工给 DeepSeek 讲透物理原理（为什么调高 6–8 步很有意义、且绝不会让游戏爆炸难？）

#### 1) 为什么 #004 的 C 档样板后段波峰 `bufWave[2]` 只有 `1.05 / 1.08 格`（中期冰又早化了）？
看 `实验关/产线v7/README.md §3.2` 早就实测过的 7×7 盘面各行 **首次暴露时已拿车数（$E$）** 与 **自然首次被拿时已拿车数（$P$）** 中位表：
- **行 2**：$E = 9,\ P = 18$
- **行 3**：$E = 15.5,\ P = 23$
- **行 4**：$E = 21,\ P = 28$
- **行 5**：$E = 28,\ P = 35$
- **行 6**：$E = 32,\ P = 41$

而在 #001–#004 中，我们的冰数字写成了：
- v6：`行2(7) / 行3(12) / 行4(18) / 行5(23) / 行6(27)`
- v7：`行2(9) / 行3(14) / 行4(20) / 行5(25) / 行6(30)`

**看清问题了吗？** 之前行 4、行 5、行 6 的冰数字（`18/23/27` 和 `20/25/30`）**全部小于或等于该行首次暴露时的已拿车数 $E$（`21 / 28 / 32`）**！
也就是说，当玩家在前 3 排来回拉扯、并掏出 2 辆管道车，终于在第 28–32 步挖开第 5、6 行时，**第 4、5、6 行的冰块在还没跟玩家照面之前，就已经在阴影里自动归零化光了（相当于空放）**！这就是用户试玩反馈“打到中期冰块就没了”、且 #004 两关后段波峰 `bufWave[2]` 掉到 `1.05 / 1.08` 的唯一根因。

#### 2) 调高冰数字的真正意义：把冰参数从 `≤ E`（暴露前早化）推入 `(E, P]`（暴露后仍封路 4–6 步）！
当我们把冰阶梯上调 5–6 步，推到：
- **v6（四边）**：`行2(9) / 行3(16) / 行4(24) / 行5(30) / 行6(35)`（`--max-ice` 默认升至 `36`）
- **v7（三面墙）**：`行2(10) / 行3(17) / 行4(25) / 行5(31) / 行6(36)`

此时每一行的冰数字都精准落在 **`[E + 3, P - 4]` 的黄金阻挡窗口**：
- 当玩家在第 21 步挖穿到第 4 行时，第 4 行的靶向冰还剩 **`3–4 步`** 才化；
- 当玩家在第 28 步挖到第 5 行时，第 5 行的靶向冰还剩 **`3 步`** 才化；
- 当玩家在第 32 步看见第 6 行时，第 6 行的靶向冰还剩 **`3–4 步`** 才化，直到 **第 35–36 步（约 75% 进度，场上还剩最后 12–13 辆车进入终局时）** 才全部化完！
- 这意味着玩家在 **50%–75% 的中后期过渡段**，眼睁睁看着底下的顺手救援小车还顶着 `3..5` 的残冰点不动，只能硬着头皮先去吃场上裸露的深层债车或开管道——**既彻底消灭了“中期没冰”，又把中段压力顺畅延续到后段（抬升 `bufWave[2]`）**！

#### 3) 为什么这样上调 **绝对不会导致游戏爆炸难或死局**？（四重安全保险）
1. **第一重保险（`boardColorCars ≥ 3` 冗余色铁律）**：我们在 #003 已经锁死 `row 4..6` 的冰块只准冻**盘面有 `≥ 3` 辆车的充裕冗余色**，绝不冻唯一车、紧缺色或 `CLIMAX_SET` 终局钥匙车——封住其中 1 辆，盘面上永远还有同色的另外 2 辆车可以正常周转，**物理上 0 死锁风险**！
2. **第二重保险（`p ≤ 36 < P_row6(41)`，终局最后 25% 依然 100% 明牌）**：一关总车数（含 1 根管道）约 48–51 辆，最高 `p=35/36` 在 75% 进度必定化完，绝不会逼玩家在最后几步无车可消时盲点 0 像素废车去敲冰。
3. **第三重保险（`ChainRatchetCheck` + `Solvable_v1` 硬门兜底）**：任何偶发的棘轮陷阱或不可解都会被硬门一票否决并切 style。
4. **第四重保险（双目标爬山自动动态平衡）**：因为冰是在**爬山之前**落盘的！如果冰从 `p=30` 升到 `p=36` 让基础盘面天然难了 `3–5pp`，后面的 `SwapClimb_v7 / climbFourSide` 在瞄准同一个 C 档目标带（`rand .30–.48 / humMid .45–.72`）时，会自动少往 `row 0..1` 塞 1 辆深色债车——**最终成品关的总难度依然稳稳锁在 C 档区间内，不会失控爆炸，但难度的“发力点”从前排挪到了中后期！**
