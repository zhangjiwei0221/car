## 一、【总工派工区】核心命题：为什么我们要拿最简单的「千层饼图 `11.txt`」开刀？

### 0. 背景与总工诊断（必读）
1. **业务痛点**：美术画的正常图案（小动物、食物、物品）80% 都像 `11.txt` 一样——由**大块纯色 + 水平/成片分层**构成（例如 `11.txt` 中上层有一整块 **`136px` 97% 连通的纯亮红色 `1`**，底层 73% 是 `19/33/15`）。如果产线只能在 `6.txt` 这种高碎片图上出 C 档，一遇到 `11.txt` 就变成 `humMid = .875`、`bufWave[2] = 1.73` 的后期一马平川水关，那工业化量产就会卡在图源上！
2. **为什么现有 `PrepImage_v1.js` 只解决了 v6，没解决 v7 的 `11.txt`？**
   - 现有 `PrepImage_v1.js` 只会做两件事：① 拆四边外框（对 v6 有用，对 v7 底边入口作用很小）；② 把占比 `≥22%` 的最大背景色整块改色（而 `11.txt` 的 `136px` 大红块占比是 `13.7% < 22%`，根本不触发！而且整块改异色容易把图案变成麻子脸毁容）。
3. **总工定下的两把手术刀（零毁容改图 + 车场隔板扣留与哑铃管）**：
   - **手术刀 A（图源端：`PrepImage_v1.js` 新增 `--wall-band` 零毁容同色系阴影腰线切巨块）**：
     - 针对 v7 三面墙（或任何图）中 **单个四连通块 `≥ 75px` 且纵向跨度 `≥ 8 行`** 的大色块（如 `11.txt` 那块 `r=4..18` 的 `136px` 色 `1`），不在里面乱涂红绿麻子，而是在该连通块的**中腰水平位置（`midR = Math.floor((minR + maxR) / 2)`，宽 `2px`）**，用一条**视觉相近的阴影/高光过渡色**（优先选图内已有、或 34 色库同色系近色，且不制造 `<8px` 碎色）画一条水平阴影腰带！
     - **效果**：外观上只是给大红块加了一条自然的中腰阴影线（**0 毁容**），但在策略 0 物理引擎下，一条 2px 腰带像大坝一样把 `136px` 巨块拦腰截断成上下两个 `~60px` 半块，**彻底废掉策略 0“一吸到底”的毛病**！
   - **手术刀 B（车场端：`setupEndgameClimaxV7` 隔板色集中沉底 + `--pipe-mouth dumbbell` 哑铃型管道 `[大,小,小,大]`）**：
     - **为什么后期 `70%–100%` 会一马平川？** 因为以前只把 2 辆内壳车放到 `(6,2)/(6,4)`，但该内壳色的其余 3 辆兄弟车还在前 3 排，玩家在前中段就把内壳剥穿了！
     - **升级 1（隔板色集中沉底 + 顶盖色前置挡路）**：在 `setupEndgameClimaxV7` 中，挑出图上部 `22%–50%` 行（中上隔板带）占比最高且总车数 `2–5 辆` 的 **1–2 个主隔板色 `S`**，把它们散落在 `row 1..3` 的普通车**尽可能与 `row 4..6` 的顶盖色 `T`（图顶部 `0%–22%` 行核心色）对调**！让隔板色 `S` 的主力车队被扣留在 `row 4..6`，玩家不挖穿到最后两排就绝对剥不开顶盖色 `T`！
     - **升级 2（新增 `--pipe-mouth dumbbell` 哑铃型 4 辆管道队列 `[大, 小, 小, 大]`）**：
       - 以前 `big` 是 `[大, 小, 小, 小]`（只压中段，管底是小车，后段无波峰）；`small` 是 `[小, 小, 小, 大]`（有后段波峰，但中段太松）。
       - 新增 `dumbbell`（哑铃型）：在 4 辆管道中，**第 1 顺位（管口）放 `≥26px` 大车塞住中路，第 2、3 顺位放 `12–16px` 小车供中段破口后喘息周转，第 4 顺位（管底）再藏 1 辆 `≥22px` 的深层/隔板大车**（在 70%–75% 进度才从管底吐出来，与 `row 5..6` 终局挪车汇合，把后段波峰 `bufWave[2]` 顶起来！）。

### 任务 1：给 `03_工具/正式版/PrepImage_v1.js` 新增 `--wall-band`（零毁容阴影腰线切巨块，支持 v7 图）

1. 打开 `03_工具/正式版/PrepImage_v1.js`：
   - 新增开关 `const WALL_BAND = process.argv.includes('--wall-band');` 与阈值 `const GIANT_COMP = Number(arg('--giant-comp', '70'));`。
   - 当 `WALL_BAND` 开启时，在主流程之后扫描全图所有颜色的四连通块 `componentsOfColor(outMat, c)`：
     - 找出所有 **`comp.length >= GIANT_COMP`（默认 70px）且纵向行跨度 `maxR - minR >= 6`** 的巨型连通块；
     - 对每个巨型连通块，计算其中腰行 `midR = Math.floor((minR + maxR) / 2)`；
     - **挑选腰带替代色 `bandColor`**：从**图内已有颜色**（保持总色数不变！）中，优先选满足以下条件的颜色：
       1. 不等于当前色 `c`，且在 `midR - 2 .. midR + 2` 附近与该巨块不直接大面积连通（防止切完又连成另一块巨块）；
       2. 优先选与当前色 `c` **色相/视觉协调的图内已有次小色**（`total[cand] >= 10 && total[cand] / TOTAL < 0.16`，按 `colorDist(cand, c)` 从小到大排序——即**优先选图内已有的同色系近色/阴影色**，绝不用刺眼撞色，且严禁出现 `31+32`）；
     - **画 2 行平滑腰带**：将该巨型连通块在 `r === midR` 和 `r === midR + 1` 这两行上的像素改涂为 `bandColor`（确保原色 `c` 剩余像素仍 `>= 20px`，把原本 1 块 `136px` 巨块干净利落地拦腰切成上、下两个独立连通块！）。
2. 运行 `node --check 03_工具/正式版/PrepImage_v1.js` 确保 0 报错。
3. 对 `11.txt` 执行零毁容微创预处理并落盘到 `实验关/派工实验_006_简单图微创与终局高潮/11_band.txt`：
   ```bash
   mkdir -p 实验关/派工实验_006_简单图微创与终局高潮
   node 03_工具/正式版/PrepImage_v1.js \
     --target 实验关/产线v7/材料/34_32并31/11.txt \
     --out 实验关/派工实验_006_简单图微创与终局高潮/11_band.txt \
     --wall-band --giant-comp 65
   ```
   - 在交工报告中打印 `11.txt` 改前 vs `11_band.txt` 改后的**最大连通块变化**与 **ASCII 对比图**，证明图案轮廓完整未毁容、仅在巨块中腰加了平滑分界带！

### 任务 2：给 `BuildV7Stagger_v1.js` 升级「隔板色沉底 + `--pipe-mouth dumbbell` 哑铃管」（当前只聚焦 v7，v6 暂挂起无需跑）

   - 当 `mouthMode === 'dumbbell'` 时，在 `split_pipe_v1.js` 生成 4 辆管道队列 `param`（长度为 4 的数组 `[{id, count}, ...]`）后，将该管道队列内的 4 辆车按容量 `count` 重排为 `[最大车, 最小车1, 最小车2, 次大车]`（即 **第 0 位管口放最大车压中段、中间第 1/2 位放两辆小车周转、第 3 位管底放次大车在 75% 终局吐出造高潮**），写回 `pObj.spools[4][pCol].param`！（100% 不改变任何车的 `id` 和 `count`，只重排该管道内部 4 辆车的先后吐出顺序，**绝对守恒**！）
2. **在 `实验关/产线v7/材料/BuildV7Stagger_v1.js` 的 `setupEndgameClimaxV7` 中补充「隔板色下沉、顶盖色上提」**：

   - 找出 `(6,2)` 和 `(6,4)` 所用的那 1–2 个内壳隔板色 `shellIds = new Set([S[6][2].id, S[6][4].id])`；
   - 扫描前中排 `r ∈ [1, 3]` 的普通无链车：若某格 `(r, c)` 的颜色属于 `shellIds`（说明隔板色的兄弟车跑到了前排，会让玩家提早把隔板剥穿），在后排 `rr ∈ [4, 6]`（跳过 `CLIMAX_SET`）找一辆属于 `corePx > 0 && !shellIds.has(id)` 的顶盖色普通车与之对调（最多对调 2 辆，保留至少 1 辆在前中排防棘轮死锁）！
   - 这样隔板色的主力被压在 `row 4..6`，而顶盖债车被提到 `row 1..3`，保证打到 70% 进度时隔板还没被彻底剥穿！
3. 运行 `node --check 实验关/产线v7/材料/BuildV7Stagger_v1.js` 确保 0 报错。
