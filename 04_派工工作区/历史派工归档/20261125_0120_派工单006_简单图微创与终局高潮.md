## 一、【总工派工区】核心命题：为什么我们要拿最简单的「千层饼图 `11.txt`」开刀？

### 0. 背景与总工诊断（必读）
1. **业务痛点**：美术画的正常图案（小动物、食物、物品）80% 都像 `11.txt` 一样——由**大块纯色 + 水平/成片分层**构成（例如 `11.txt` 中上层有一整块 **`136px` 97% 连通的纯亮红色 `1`**，底层 73% 是 `19/33/15`）。如果产线只能在 `6.txt` 这种高碎片图上出 C 档，一遇到 `11.txt` 就变成 `humMid = .875`、`bufWave[2] = 1.73` 的后期一马平川水关，那工业化量产就会卡在图源上！
2. **为什么现有 `PrepImage_v1.js` 只解决了 v6，没解决 v7 的 `11.txt`？**
   - 现有 `PrepImage_v1.js` 只会做两件事：① 拆四边外框（对 v6 有用，对 v7 底边入口作用很小）；② 把占比 `≥22%` 的最大背景色整块改色（而 `11.txt` 的 `136px` 大红块占比是 `13.7% < 22%`，根本不触发！而且整块改异色容易把图案变成麻子脸毁容）。
3. **总工定下的两把手术刀（零毁容改图 + 车场隔板扣留与哑铃管）**：
   - **手术刀 A（图源端：`PrepImage_v1.js` 新增 `--wall-band` 零毁容同色系阴影腰线切巨块）**：
     - 针对 v7 三面墙（或任何图）中 **单个四连通块 `≥ 75px` 且纵向跨度 `≥ 8 行`** 的大色块（如 `11.txt` 那块 `r=4..18` 的 `136px` 色 `1`），不在里面乱涂红绿麻子，而是在该连通块的**中腰水平位置（`midR = Math.floor((minR + maxR) / 2)`，宽 `2px`）**，用一条**视觉相近的阴影/高光过渡色**（优先选图内已有、或 34 色库同色系近色，且不制造 `<8px` 碎色）画一条水平阴影腰带！
     - **效果**：外观上只是给大红块加了一条自然的中腰阴影线（**0 毁容**），但在策略 0 物理引擎下，一条 2px 腰带像大坝一样把 `136px` 巨块拦腰截断成上下两个 `~60px` 半块，**彻底废掉策略 0“一吸到底”的毛病**！
   - **手术刀 B（车场端：`setupEndgameClimaxV7` 隔板色集中沉底 + `--pipe-mouth dumbbell` 哑铃型管道 `[大,小,小,大]`）**：
     - **为什么后期 `70%–100%` 会一马平川？** 因为以前只把 2 辆内壳车放到 `(6,2)/(6,4)`，但该内壳色的其余 3 辆兄弟车还在前 3 排，玩家在前中段就把内壳剥穿了！
     - **升级 1（隔板色集中沉底 + 顶盖色前置挡路）**：在 `setupEndgameClimaxV7` 中，挑出图上部 `22%–50%` 行（中上隔板带）占比最高且总车数 `2–5 辆` 的 **1–2 个主隔板色 `S`**，把它们散落在 `row 1..3` 的普通车**尽可能与 `row 4..6` 的顶盖色 `T`（图顶部 `0%–22%` 行核心色）对调**！让隔板色 `S` 的主力车队被扣留在 `row 4..6`，玩家不挖穿到最后两排就绝对剥不开顶盖色 `T`！
     - **升级 2（新增 `--pipe-mouth dumbbell` 哑铃型 4 辆管道队列 `[大, 小, 小, 大]`）**：
       - 以前 `big` 是 `[大, 小, 小, 小]`（只压中段，管底是小车，后段无波峰）；`small` 是 `[小, 小, 小, 大]`（有后段波峰，但中段太松）。
       - 新增 `dumbbell`（哑铃型）：在 4 辆管道中，**第 1 顺位（管口）放 `≥26px` 大车塞住中路，第 2、3 顺位放 `12–16px` 小车供中段破口后喘息周转，第 4 顺位（管底）再藏 1 辆 `≥22px` 的深层/隔板大车**（在 70%–75% 进度才从管底吐出来，与 `row 5..6` 终局挪车汇合，把后段波峰 `bufWave[2]` 顶起来！）。
