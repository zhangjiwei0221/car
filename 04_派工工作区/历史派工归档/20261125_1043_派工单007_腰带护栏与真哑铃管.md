### 0. 总工对 #006 的验收批注
你在 #006 的消融实验（`README.md §5`）做得极好，直接定位了 3 个实打实的物理机制漏洞：
1. **漏洞 ①（`PrepImage_v1.js --wall-band` 误选 `15px` 小色 `2` 当腰带，造出 `39px` 单车死墙）**：
   - 原本 `11.txt` 里色 `2` 只有 `15px`（全盘 1 辆小车），被涂上 `24px` 腰带后变成了 `39px`，结果 `SplitLevel_v722` 把它切成了一辆 **`39px` 的独苗大债车**，导致 2/3 的 style 在 28% 进度把认真玩家卡死（`humFair` 掉到 `.100~.292`）！
   - **正解**：腰带色**严禁选 `< 45px` 的小色**！必须选图内原本就有 **`total[cand] >= 45`（即原本就切了 `≥ 3` 辆车）的中型充裕色**（在 `11.txt` 中，色 `28` 有 `66px`、色 `15` 有 `74px`、色 `31` 有 `98px`、色 `30` 有 `112px`，哪怕加 `24px` 也会被均匀分摊到 3–5 辆车上，绝不会产生 39px 独苗死车！）。
2. **漏洞 ②（`dumbbell` 哑铃管退化成了 `[28, 14, 14, 16]`，管底第 4 辆根本不是大车）**：
   - 因为 `split_pipe_v1.js` 只会做“1 整车 + 3 辆对半拆的半车”，而 `32×32` 图上最大车才 `28–32px`，对半拆出来的 3 辆半车只有 `14–16px`，怎么排序也凑不出第 2 辆大车放管底！
   - **正解（真·哑铃管 `[大, 小, 小, 大]`）**：当 `mouthMode === 'dumbbell'` 时，在 `split_pipe_v1.js` 跑完生成 `[大1(28), 半1(14), 半2(14), 半3(16)]` 后，直接在盘面 `row 3..6`（跳过链、管、黑、`CLIMAX_SET`）找一辆 **`count >= 24`（且与管口车异色）的现成整车大车**，拿它跟管道第 3 顺位（管底）那辆 `14–16px` 半车**直接互换对象（`{id, count}` 整体对调）**！
   - 这样一来：盘面上多了一辆 14px 小车，而管道队列瞬间变成真真正正的 **`[28px 管口大车, 14px 小车, 14px 小车, 28px 管底大车]`**，且全盘逐色总像素 **100% 严格守恒**！
3. **漏洞 ③（`BuildV7Stagger_v1.js` 保底选样 `best` 居然选出了 `ratPass = false` 的死锁关）**：
   - 原代码第 628 行 `hardSafe` 把 `ver.humFair >= FAIR_MIN && ver.randFair >= FAIR_MIN` 和 `ver.ratPass` 绑在一个布尔值里，一旦所有 style 都有某项微差，`hardSafe` 全为 `false`，回退逻辑就按 `|randCasual - TARGET_MID|` 盲挑，结果把 `ratPass = false`（棘轮死锁）的关当成最优解输出了！
   - **正解**：保底优先级必须分 3 层：**第 1 铁律 `structOk = solvable && hard0 && ratPass && earlyShare < 0.20 && row1Open >= 3`**（棘轮不过的一律排在最后！）→ **第 2 优先级 `fairOk = humFair >= FAIR_MIN && randFair >= FAIR_MIN`** → **第 3 优先级（离 C/B 档目标带中心 `|rand - TARGET_MID| + |humMid - HMID_MID|` 最近）**！

#### 1.3 修复 `实验关/产线v7/材料/BuildV7Stagger_v1.js` 的保底选样优先级（约第 628–635 行）
将 `best` 比较逻辑替换为分层词典序（**结构与棘轮 `structOk` 永远一票优先**，绝不放行 `ratPass=false` 的关去覆盖 `ratPass=true` 的关）：
```javascript
    const HMID_TARGET = (HUM_MID_MIN > 0 || HUM_MID_MAX < 1) ? (HUM_MID_MIN + HUM_MID_MAX) / 2 : 0.60;
    const rankRec = (r) => {
      const v = r.verify;
      const structOk = (v.solvable && v.hard0 && v.ratPass && v.earlyShare < 0.20 && v.row1Open >= 3) ? 1 : 0;
      const fairOk = (v.humFair >= FAIR_MIN && v.randFair >= FAIR_MIN) ? 1 : 0;
      const dist = Math.abs(v.randCasual - TARGET_MID) + 0.8 * Math.abs((v.humMid ?? HMID_TARGET) - HMID_TARGET);
      return { all: v.allPass ? 1 : 0, structOk, fairOk, dist };
    };
    const betterRec = (a, b) => {
      if (!b) return true;
      const ra = rankRec(a), rb = rankRec(b);
      if (ra.all !== rb.all) return ra.all > rb.all;
      if (ra.structOk !== rb.structOk) return ra.structOk > rb.structOk;
      if (ra.fairOk !== rb.fairOk) return ra.fairOk > rb.fairOk;
      return ra.dist < rb.dist;
    };
    if (betterRec(rec, best)) best = rec;
```
