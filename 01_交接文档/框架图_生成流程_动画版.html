车接小人 · 关卡生成流程框架

从「导入一张像素图」到「输出一关」的完整链路。橙色 = 判定闸门；紫色 = 最终产物。
点「播放」，五个阶段会依次亮起
输入 构造（造关） 评估（打难度分） 判定与输出

① 输入

导入目标图 TXT
像素矩阵（每格一个颜色号，0 = 空）。一张图 = 一关。
gen-file / levelList[]
参数装配
读界面：卡点覆盖率门槛、球容量区间、每图搜索时间；再套预设 → 得到本关的完整 config。
genApplyFixed(cfg)
搜索计划
搜索时间 → 轮数 × 单轮预算（3 分钟 = 4 轮 × 45 秒）；候选数 = 单轮能精算几个。
_searchPlan → portfolioK / timeBudgetMs
▼

② 构造：一关是怎么"造"出来的（每轮换一套结构组合，跑 K 轮）

2.1 分盒（切球）
每个颜色单独切：该色总像素 ≥ 上限 → 按上限一辆辆切；余数不足下限 → 与前一辆平分。
切完整盘再按同色做一次归一化。
pickBoxSplit → baseFillBoxes → normalizeCapacities
2.2 选盘（行列）
在范围里挑一个能装下全部车、可用率 ≈86%、列−行 ≤2 的尺寸；装不下才溢出到管道。
chooseBoardDimsFixed
2.3 摆障碍
墙（黑块）、数字冰、锁链、管道：按比例撒 + 几何约束（可激活 / 不相邻 / 分散）。
buildBoard
2.4 放车
把盒子按暴露顺序铺进格子：只有第 0 行开局可点，所以第 0 行的构成 = 开局的全部选择。
fillBoard / ensureBoardFull（裁行、补黑）
2.5 事后修正
数字冰按时差锁车（冰值 = 需求时刻 − 可取时刻）；第 0 行颜色分散；免费车配额。
applyIceSchedule / diversifyRow0 / limitRow0Free
▼

③ 评估：把"难度"量出来（每个候选都要跑一遍，这是最贵的一步）

3.1 求解
6 遍：贪心×2 → 三步树×2 → 噪声×2，任一遍通关即停。产出一条取盒序列 + 每步暂存。
Solver.solve
3.2 压力曲线
沿求解路线算每步暂存；30~80% 区间里「暂存≥3」的占比 = 覆盖率；区间峰值 = 峰窗。
pressureSamples → band3Pct / band4Pct / peak
3.3 玩家线
5 种"手痒程度"×2 种子 = 10 局，不给复活，看真实玩家能不能通。
PlayerSim.run → playerPassPct
3.4 好关判据
可解 + 峰窗 3.2~4.8 + 稳健 + 覆盖率≥门槛 + 尖峰≥4（可选）+ 玩家通关率≥25%。
goodV3Of → fails[]
▼

④ 没达标怎么办：三层"再来一次"

卡点树（候选内）
在某个候选上只改车：换球（60%）/ 增容（40%），3 分支 × 2 轮，每改一次重新求解判定。
applyOneChoke → chokeSwap / chokeInflate
压力重建
保留结构，只调障碍比例（冰/黑/链），整盘重铺。
applyPressureAdjust
带外纠偏
峰窗跑出 3.2~4.8 时，冰 ±15% 再整轮产一次。
bandFixOnce
全灭兜底
连可解都没有 → 宽松盘（填满率 0.80、允许 2 条管道、只要求可解）。
safe fallback
▼

⑤ 择优与输出

择优顺序
① 可解优先 ② 违规条数少 ③ 覆盖率高的 ④ 目标分近 ⑤ 压力更持久。
portfolioBetter / candBetter
落盘
合格 → 合格关卡/；不合格 → 不合格关卡/（文件名带 __超时兜底 / __遍历兜底）。
genOnResult → genPersistOne
界面回显
目标图上方结果条（覆盖/尖峰/玩家/峰窗/车/容量）+ 棋盘下方「生成过程」列表 + 可导出制作过程 HTML。
genShowResultBanner / genRenderTrace / genExportProcess
一句话概括：切球定"有多少辆车"，选盘定"盘多大"，障碍定"路怎么堵"， 求解 + 玩家模拟定"难度够不够"，六条门槛全过才算合格；不过就一直换结构、换车、换障碍再试，直到预算用完， 最后输出所有候选里最接近合格的那一关。

附：六条判定门槛

#门槛含义不过会怎样
1可解求解器能通关直接淘汰该候选
2峰窗 ∈ 3.2~4.8中段最挤时手里几格记一条违规
3稳健稳健打法通关率在带内记一条违规
4覆盖率 ≥ 滑杆30~80% 里暂存≥3 的占比记一条违规（最常见）
5尖峰 ≥4 占比 ≥5%曲线有没有冒尖（默认已关）记一条违规
6玩家通关率 ≥25%10 局不给复活的真实通关率记一条违规
违规 0 条 = 合格。不全过时，按「违规条数 → 覆盖率 → 目标分」挑最接近的一关输出。

◆ 解得开吗？
解不开
  • 减负重试（≤5 次）：黑 ×0.85、冰 ×0.9、链 ×0.85、窄路提前撤
  • 仍解不开 → 淘汰这个候选，换下一个
解得开
  • 进入评估：覆盖率 / 峰窗 / 尖峰 / 玩家 10 局
  • 同时算死因分布（链/冰/管道/形状/断供）

◆ 六条门槛全过吗？（可解 / 峰窗 / 稳健 / 覆盖 / 尖峰 / 玩家）
↓
不过：太 难
  • 症状：前期就顶满、玩家 10 局大多死、峰窗 > 4.8
  • 动作：减压 —— 冰/黑/问号 ×0.95，链 −1
  • 峰窗出带：冰 −15% 整轮重产（bandFixOnce）
不过：太 简单
  • 症状：覆盖率低、峰窗 < 3.2、中后期没有卡点
  • 动作：加压 —— 冰/黑/问号 ×1.05，链 +1
  • 曲线被压平（没选择余地）：强制减压 ×0.7、链 −2
↓　两种调整都会重新造盘、重新求解、重新评估
