# 生产流水线 · 思维导图（v206）

> 一句话：**一条图进来 → 选盘 → 建盘 → 铺盒 → 设计扫描 → 求解 → 审核 → 择优落库**。
> 每步下面写了「它到底做了什么」，以及「哪些是设计、哪些还是模板/随机」。

```
目标图 TXT
 │
 ├─① 前置检查 ── 底部入口可达性 · 碎色闸门 · 棋盘范围预检（硬范围/自适应）
 │
 ├─② 选棋盘 ──── 行列范围（手填/预设）· 形态约束（列=行+1或+2）
 │                · 可用空间配额联立（黑块+管道+可用率）
 │
 ├─③ 建盘 ────── 黑块/墙（比例+形态约束）· 窄路（可选）
 │                · 管道（守恒反推：装不下的盒进管道）
 │
 ├─④ 铺盒（合球）─ 切盒（像素÷平均容量）→ 车序列 → 逐行左→右填盘
 │                · 首批障碍：问号/冰全填、锁链只填 50%
 │
 ├─⑤ 设计器 ──── 早车档（把"可点且早出"的车换进深处/深埋车换到可点位）
 │                · 增容（深埋色最大车容量 ×1.5~2，同色扣减守恒）
 │
 ├─⑥ 设计扫描 ── 11 个变体各跑一关 → 按 goodV3 择优 → 全过早停
 │
 ├─⑦ 求解 ────── 全知六遍编排 + 三步前瞻树 + 18 局玩家线
 │
 ├─⑧ 审核/评分 ── 卡点线 3.2 · curveOK · goodV3 六条 · 难度分 v3
 │
 └─⑨ 收尾 ────── 标记 → 落库（合格/不合格）→ 打包导出
```

---

## ① 前置检查（不做求解，只做"必然淘汰"判断）

| 检查 | 做什么 | 不过会怎样 |
| --- | --- | --- |
| 底部入口可达性 | 仅 `bottomOnly` 模式：底部能否走到所有像素 | 直接判不可行 |
| 碎色闸门 | 碎色像素占比 > 阈值就拦（防止关卡全是像素点） | 判结构不适配 |
| 棋盘范围预检 | 按"盒数 vs 范围格数"预判装不装得下 | **硬范围**：直接报错；**自适应**：自动换范围 |

> v206 修：手填范围时 `boardAuto:false` + `boardHardRange:true`，**不再被自动范围覆盖**。

## ② 选棋盘（`chooseBoardDimsFixed`）

- **形态硬约束**：列数 − 行数 ∈ {1, 2}（不允许正方形、不允许行多）；
- **在范围内枚举所有合法尺寸**，对每个尺寸解一次"配额联立"：
  可用空间率 `usableSpaceTarget`、黑块比例、管道条数 → 得出该尺寸是否可行；
- 有可行尺寸 → 随机取一个（保留多样性）；
- 没有 → 自适应模式会"逐行缩小"或"按车数反推"；**硬范围模式直接报错**。

## ③ 建盘（结构层）

| 步骤 | 做什么 |
| --- | --- |
| 黑块/墙 | 按 `blackPercent` 撒；形态约束：不得 2×2、直线最多 3 面 |
| 窄路 | 可选，锯齿墙 + 单一缺口，制造"唯一可达通道" |
| 管道 | **守恒反推**：`管道数 = ⌈(盒总量 − 有效空位) / 每管容量⌉` |

## ④ 铺盒（合球）——当前是模板

```
切盒：某色像素数 ÷ 平均容量 → 切几辆、每辆多大
铺盒：车序列按"底+左右向中心"的消除趋势排 → 棋盘首行→尾行、左→右填
首批障碍：问号/冰全填；锁链只填一半，另一半留给卡点阶段
```

**关键事实：这一层还是"像素÷容量"的模板，拆图的层表没进入切法决策。**

## ⑤ 设计器（v198~v206，生产已开）

- **可点集合**：模拟器第一帧所有合法取盒（不是只看第 0 行）；
- **早车档 target**：把"可点且早出"的车与"不可点且深埋"的车对调，直到可点早车 ≤ target；
- **增容 k**：深埋色最大车容量 ×k，多出来的从同色其它车扣（总量守恒）。

## ⑥ 设计扫描（`designSweep`）

11 个变体各跑一整关，取 goodV3 最好的：

```
早车档 4 / 3 / 2 / 1 / 0            （只挪位，5 个）
× 增容 1.5 / 2（配 target 2/1/0）   （挪位 + 增容，6 个）
```

## ⑦ 求解

- **全知求解器**：六遍编排（贪心×2 → 三步前瞻×2 → 噪声×2）；
- **玩家模拟器**：18 局，三套策略（稳健/冒险/随机）；
- 二者共用 `simulator.js`，但信息量不同。

## ⑧ 审核 / 评分

| 判据 | 内容 |
| --- | --- |
| 卡点线 | `L − 1.8 = 3.2`（L=5 暂存上限） |
| curveOK | 中后期出现卡点 + 前期不爆 + 全程不触死亡边界 |
| goodV3 六条 | 可解 / 稳健≥50% / 被埋=0 / 前期≤2 / 峰窗 3.2~4.8 / 稳打落后≤17 |
| 难度分 v3 | `f1×0.45 + f2×0.25 + f3×0.10 + f4×0.20 + 复活×8`，只展示、不参与录用 |

## ⑨ 收尾

标记（`goodV3` / `designStat` / `designSweep`）→ 落库（`合格关卡` / `不合格关卡`）→ 打包（关卡 JSON、txt、求解数据、生产报告、CSV）。
