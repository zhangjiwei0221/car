# 能做“引导关”的图有什么特征？怎么找？

## 一、必要条件（不做就无从谈起）

**四个象限都必须有“独占色”**——只出现在这一个象限、不与别处共用的颜色。

- 原因：伤害阶梯只能用独占色来量。共享色被吃时像素从哪个象限来是不确定的
  （216 那关就踩过这个坑：色 33 同时存在于左上/右上，吃它时全从左上拿）。
- 实测：**216 张官方图里，四象限齐全的有 77 张（36%）**，三象限 103 张，
  其余连一个象限都没有独占色。

## 二、什么特征能预测“跨度大”？（结论：没有）

我对 60 张图算了三个结构特征，与阶梯跨度的相关系数：

| 特征 | 与跨度的相关 |
|---|---:|
| 共享色像素占比 | **-0.25**（弱负相关） |
| 独占色数量 | **0.00**（无关） |
| 每象限最大独占色的像素数 | **0.18**（弱） |

**结论：没有简单特征能预测阶梯大小，只能直接测。**

## 三、所以怎么找：直接扫

```bash
node 03_工具/正式版/GuideScan_v740.js --dir 关卡 --rows 7 --cols 7 --out 输出/引导候选.json
```

每张约 1–2 秒（自切 + 伤害曲线），216 张约 3 分钟。

输出：按“跨度”排序的候选清单，四象限齐全的单独一列。

## 四、选图判据（我建议）

```
① 四象限齐全（都有独占色）
② 跨度 ≥ 30
③ 第一个象限 ≤ 第 6 步被咬
④ 第二象限 ≥ 第一个 + 8 步
```

满足这四条，就有了“天然引导”；再跑 `OverlapBuild` 加压，用 `DamageCurve` 复验阶梯没被打乱。
