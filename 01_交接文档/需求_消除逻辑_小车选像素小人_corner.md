# 需求：消除逻辑（固定起点 · 曼哈顿距离）

## 一、规则

### 原理

**固定起点 = 目标图的左下角像素**（即最后一行、第 0 列）。
该位置固定，不随任何状态变化。

对每个像素小人计算到该起点的**曼哈顿距离**（只能上下左右走的最少步数）：

```
D(行, 列) = |行 - 最后一行| + 列
```

像素小人的消除次序由 **D 升序**决定；**D 相同时，按行号降序、列号升序**。

起点的固定性：

- 不随小车变化；
- 不随小车进入暂存区的先后变化；
- 不随小车实际占用哪一格暂存区变化。

### 行为细则

1. **同 D 的次级次序**
   行号降序（下方优先），再列号升序（左侧优先）。

2. **计算与播放分离**

   - **确定一辆车要消的 N 个像素小人时，逐个确定**：
     每确定一个，立刻在内部把它视为已消除，并重新计算可选集合
     （因此被解锁的格子会立即参与下一次比较），再确定下一个；
   - **播放整批**：N 个确定完成后，一起播放离开动画；

3. **同色小车竞争时的次序**
   剩余容量小者优先；剩余容量相同时，暂存区序号小者优先（左侧优先）。

---
