# 三个新工具（2026-10-28）

## 1. 批量跑分 `03_工具/正式版/BatchScore_v723.js`

```bash
node 03_工具/正式版/BatchScore_v723.js --n 20 --rounds 4 --samples 30 --tag batch1
node 03_工具/正式版/BatchReport_v723.js --in 输出/批量跑分_batch1.json --out 输出/批量跑分_batch1.md
```

流程（每张图）：

1. `SizeAdvisor` 定棋盘与合同；
2. `SplitLevel_v722` 自切（容量守恒校验）；
3. `OverlapBuild_v719` 构建（默认 4 轮 × 30 采样）；
4. `Validate006Level_v706 --audit`；
5. 判定 **PASS**：`at4≥20 且 run4≥12 且 峰值≤4 且 审核通过 且 容量守恒`。

输出：`输出/批量跑分_<tag>.json`（逐图）+ `批量跑分_<tag>.md`（表格与统计）。
**每张图跑完立刻落盘**，中途断了也能看已完成的部分。

## 2. 尺寸顾问 `03_工具/正式版/SizeAdvisor_v723.js`

```bash
node 03_工具/正式版/SizeAdvisor_v723.js --target 关卡/xxx.txt
```

规则：

- 车数 = `round(像素 / 28)`；
- 棋盘：`rows×cols ≥ 车数`、空格 ≤6、尽量方正；
- 合同 = `[floor(均值×0.8), ceil(均值×1.35)]`，并夹在用户给的 `[20,40]` 内；
- **守恒预检**：`车数×下限 ≤ 像素 ≤ 车数×上限`。

例：38×38（1444 px）→ 建议 6×9 / 52 车 / 合同 [22,38] / 守恒 ✅。

## 3. 句型选优 `03_工具/正式版/ChainPicker_v724.js`

```bash
node 03_工具/正式版/ChainPicker_v724.js <关卡.json> --top 10 --probe 8 [--apply 输出.json]
```

输出：

1. **解锁表**：每个颜色首次被取用的步数 + 该色总容量；
2. 候选成链对（相邻、普通车），按“晚 + 稀缺”排序；
3. 对前 N 对**逐个实测**（单独求解），给出 at4/run4/最长无压段的真实变化；
4. `--apply` 把最佳那对写进新关卡。

用途：替代“人工翻棋盘找链对”，但单条链效果有限（实测多为 at4 +0~2），
大规模提升仍靠 `OverlapBuild` 的多轮爬山。
