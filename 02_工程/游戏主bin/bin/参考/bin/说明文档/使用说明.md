# 大像素版毛线关卡 生成-审核-分析 一体化工具

## 使用方法

1. 把待生成的 `.txt` 像素图纸放入 `input_txt/`
2. 在本目录执行：
```bash
node run.js
```
3. 合格关卡自动输出到 `output_json/`

## 流程

```
放入txt → 生成关卡(×5候选) → 求解分析 → 合格判定 → 循环(最多10轮) → 卡死检验 → 分组排序 → 输出
```

合格关卡产出后，会**自动按难度分组排序**（从第1关起），无需手动操作。

## 合格条件（全部满足）

- 难度强度落在区间 [min,max]（默认 30-100，含端点）
- 曲线符合预期（有卡点 或 趋势符合无卡点简单关）
- 全知版通关
- 高手档通关
- 卡死检验通过

## 输出命名

`MMM_NNN.json`
- MMM = 批次序号（按txt文件排序从001升序）
- NNN = txt文件原名（去掉.txt）

例：`001_22_11种.json`

## 参数说明

- 每关每轮生成 5 个候选棋盘
- 最多循环 10 轮（50次尝试/关）
- 50次都不合格 → 标记"需美术返图重修"
- 生产参数：48像素、1.1倍范围、无黑块、不追加颜色

```

├── 说明文档/                 # 全部说明文档
├── input_txt/                # 放入待生成的txt图纸
├── output_json/              # 合格关卡输出 + 两份CSV报告
├── output_sorted/            # 排序好的关卡（第N关_*.json）+ 排序清单.csv
├── 关卡生产工具大像素版48像素无黑块/   # 关卡生成器
├── 大像素毛线关卡求解器/              # 求解器（高手档基准）
└── 关卡验证工具（是否卡死）/          # 卡死检验
```
