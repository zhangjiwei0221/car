# 障碍区域预设（分栏）说明

让冰块/问号/锁链按"区域"分栏生成，而不是全盘随机。可全局生效，也可只对部分 txt 生效。
所有障碍放置后**仍交回求解器反推难度**；没命中目标难度时按原渐进策略多轮重试（多试几轮基本能逼近）。

## 一、如何启用
- **推荐：网页生产页直接配**——选「障碍类型 + 本次占比%」，在棋盘画布上**拖拽框选一个矩形**作为该笔的生成区域；可画多笔叠加（每笔不同色边框）；选「全部关卡」或「仅选定关卡」（勾选 input_txt 里的图纸）。
- 或手工：把根目录 `障碍区域预设.示例.json` 复制为 **`障碍区域预设.json`**。不存在该文件、网页也没配 → 默认随机+渐进，行为不变。
- 也可用环境变量：`OBSTACLE_PRESET_FILE=<路径>` 或 `OBSTACLE_PRESET_JSON='<内联JSON>'`（网页配置即走内联，覆盖文件）。

## 二、五个区域
| 名称 | 范围 |
|---|---|
| 左上 | 上半 × 左半 |
| 右上 | 上半 × 右半 |
| 左下 | 下半 × 左半 |
| 右下 | 下半 × 右半 |
| 中 | 行、列各取中间约 1/3 的交叠区 |

> 区域边界本就是模糊的（"中"与四角会有交叠），这是有意为之——精确难度由求解器把关。

## 三、配置格式（占比制）
区域有两种写法，二选一：
- **相对矩形**（网页拖拽框选生成）：`{ "rect": {"x0":0,"y0":0,"x1":0.5,"y1":1}, "ratio": 0.3 }`
  —— `x0,y0,x1,y1` 是 0~1 的相对坐标（左上=0,0；右下=1,1），按各关实际 `rows×cols` 折算成格子（用格子中心判定是否落在矩形内）。
- **命名区域**（手写方便）：`{ "region": "中", "ratio": 0.5 }`，region ∈ 左上/左下/右上/右下/中。

```json
{
  "global": {
    "ice":     [{ "rect": {"x0":0.33,"y0":0.33,"x1":0.67,"y1":0.67}, "ratio": 0.5 }],
    "question":[{ "region": "左下", "ratio": 0.4 }],
    "chain":   [{ "region": "右上", "ratio": 0.5 }]
  },
  "perTxt": {
    "219_12种": { "ice": [{ "rect": {"x0":0,"y0":0,"x1":0.5,"y1":1}, "ratio": 0.3 }] }
  }
}
```
- `ice`=冰块、`question`=问号、`chain`=锁链**对**。
- 每项的 `ratio`=占"该类障碍按棋盘算出的总数"的比例（0~1，例 0.5=一半）。
- 同一类型可写多块区域（多笔），允许重叠，障碍本身可叠加。各区之和建议 ≤1。

## 四、生效规则
1. **数量仍按占比锁定**：每类障碍总数由生成器的占比公式决定（见《参数配置说明》）。区域预设只决定"其中多大比例落在哪块区域"。
2. **区域配额优先**：先按各块 `ratio×总数` 放置；放不满或还有剩余 → **用剩余名额全盘随机补齐**。
3. **作用域**：网页可选「全部关卡(global)」或「仅选定关卡(perTxt)」；手工配置时 `perTxt[文件名]` 优先于 `global`；某类型两者都没配 → 走默认随机。
4. **锁链**：以"两端都在该区域内的相邻对"为优先；不足再全盘补齐。

## 五、与渐进加压的关系
- 有预设的类型：按预设区域放置（问号默认避开第一行）。
- 难度未命中 `[min,max]` → 仍会进入下一轮，按渐进策略调整（冰块偏后/锁链覆冰/加量）。
- 核心不变：**用高手求解路线的暂存压力曲线衡量难度**，障碍分布只是把曲线往目标推。

## 六、说明
- 网页画布按棋盘最大 10×9 比例显示参考网格；拖拽矩形以相对坐标保存，自动适配各关实际棋盘大小。
- 命名区域（五分区）仍向后兼容，手写配置可用。
