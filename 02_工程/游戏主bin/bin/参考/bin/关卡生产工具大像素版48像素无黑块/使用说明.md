# 48像素1.1倍随机无黑块关卡生产工具

## 目录说明

| 目录 | 用途 |
|---|---|
| `input_txt/` | 放入要生产的 `.txt` 图纸 |
| `output_json/` | 生成后的 JSON 输出目录 |
| `tool/` | 生产脚本和 pixel-yarn 工具 |
| `workflows/` | 本套生产流程 MD |

## 使用方法

1. 把 TXT 文件放入 `input_txt/`
2. 在本目录执行：

```bash
SINGLE_COLOR_EXTRACT_PERCENT=5 SPOOL_BASE_PIXEL_COUNT=48 FIRST_ROW_RANGE_MULTIPLIER=1 NEXT_ROW_RANGE_MULTIPLIER=1.1 \
node tool/scripts/run_batch_txt_node.js noblack input_txt output_json json noextra
```

3. 生成结果在 `output_json/`

## 固定参数

- 无黑块
- JSON 输出
- 不追加补充颜色
- 单色百分比：5%
- 基础像素：48
- 第一行范围倍数：1
- 后续行范围倍数：1.1
- 管道最大深度：6
- 棋盘最大：10 行 x 9 列，列数大于等于行数

## 说明

`failed.txt` 里出现的文件表示自动验证器未判绿，但 JSON 仍然已经完整生成。
