# 48像素1.1倍随机无黑块关卡生产工作流程

> 脚本：`tool/scripts/run_batch_txt_node.js`  
> 工具：`tool/dist_new`（pixel-yarn 3 + 保留验证器）  
> 适用：大图 TXT 像素图纸生成无黑块 JSON 关卡

## 输入参数

| 项目 | 规格 |
|---|---|
| 输出格式 | JSON |
| 黑块 | 不摆放黑块 |
| 颜色 | 只使用 TXT 原始颜色，不追加颜色 |
| 单色百分比 | 5% |
| 基础像素 | 48 |
| 第一行范围倍数 | 1 |
| 后续行范围倍数 | 1.1 |
| 棋盘尺寸 | 最大 10 行 x 9 列，列数必须大于等于行数 |
| 管道深度 | 最大 6 |

## 运行命令

```bash
SINGLE_COLOR_EXTRACT_PERCENT=5 SPOOL_BASE_PIXEL_COUNT=48 FIRST_ROW_RANGE_MULTIPLIER=1 NEXT_ROW_RANGE_MULTIPLIER=1.1 \
node tool/scripts/run_batch_txt_node.js noblack input_txt output_json json noextra
```

## 输出规则

- JSON 文件名与 TXT 文件名保持一致，仅后缀从 `.txt` 改为 `.json`
- 不添加生成序号前缀
- 不添加红点标记
- 验证未通过时仍保存完整 JSON，验证记录写入 `output_json/failed.txt`
- 目标区只保留 TXT 原始颜色
