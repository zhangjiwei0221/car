⚙️ 参数设置

用哪一档玩家表现做审核基准：高手=现网口径(前期≤4.2)；菜鸟=拟合真实低水平玩家(前期严格<3.5，难度下限默认20)。切换后难度/曲线/前期判定都按该档曲线。
难度分落在此区间（含端点）才算合格（满分100）。窄区间可精准命中某难度段。
每个关卡最多尝试几轮，超过标记为"需美术返图"
每轮对同一张图生成几个不同棋盘，有一个合格就过
% 冰块数=棋盘总格数×此值。例：90格×15%=13个冰块。冰块延迟消除4步
锁链对数=1+可用格数÷此值。值越小锁链越多。例：72÷20≈4对锁链
% 问号数=棋盘总格数×此值。问号=未翻开时看不到颜色，增加不确定性
% 第2轮起，50%的冰块优先放在"行号≥此比例"的区域（制造后期高压）
% 第4轮起，在基础冰块数上额外增加此百分比。例：13×10%=多加1-2个冰块
% 打乱多少比例的管道深层球序（基准=全关管道总数）。默认100%=推荐值（回测最优，仍可解、不抬前期）；设 0 关闭。例：10管道×50%=打乱5个
–层 打乱管道第几层球（1=最浅/最先出口，6=最深）。默认 4-6 层=深层 param[3..5]，只动深层故不抬前期
swap2=区间内随机交换2个球（默认/推荐，回测最稳）；full=区间内所有球全随机重排
% 候选审核后没有真卡点(目标区均暂存<4，含"趋势符合"简单关；难度/全知/该档都过、非前期前移)时，按求解进度换中后期球颜色再审一遍，升级出真卡点才用换球版，否则回落原判定。默认0=关闭；回测甜点≈25%
–像素 每个球消除的像素数范围（贴目标图同色块切分）。块落在[下限,上限]整块作一球；超上限按消除顺序切段；不足下限的小块同色合并。默认 28–58
个 连通块识别时、同列方向上下相邻两个同色像素之间允许夹的异色数（≤此值仍视为连通）。越大块越大、球越少、消除越顺。默认1；设0=仅认4直接邻接
像素 切分软目标，用于调控整关总球数（总球数≈各色像素总数之和÷此值）。默认0=不启用（按自然连通块切分）；>0 则朝该平均值靠拢，会被钳到[下限,上限]
合格闸门开关。开=无明确卡点但"后半段峰值>前期且前期不越位"也算合格(趋势符合)。关=必须有真卡点(目标区均暂存≥4)才合格，趋势符合按无卡点判不合格。配合换球比例>0：关了能逼无卡点关进换球升级，升不出真卡点就判不合格。
💡 动态难度平衡策略：常规按轮次升压（第1轮全随机→第2轮冰块偏后区→第3轮锁链覆冰→第4轮加量）。加压：判为"过于简单"则直接在后区加障碍。减压：判为"前期峰值前移"则先后移冰块/锁链，仍跳升再减少障碍比例。目标：50-90%出现压力峰值、且前期不跳升。
🧩 障碍区域预设（拖拽框选，可选）：选「障碍类型 + 本次占比%」，在下方棋盘上拖拽画一个矩形 = 把该占比的此类障碍预设到这块区域。可画多笔叠加（每笔不同色边框），未覆盖部分全盘随机补齐；不画 = 完全默认随机。
