# 🧶 毛线关卡生产 · 新手操作指南

> 这份指南假设你**完全没接触过**这个工具，跟着一步步做就能产出关卡。
> 把整个文件夹复制到任何一台电脑，按下面步骤操作即可，不需要懂编程。

---

## 一、这个工具是干嘛的？

你放进去一张**像素图纸（.txt）**，它会自动帮你：

1. 生成关卡棋盘
2. 自己试玩验证（能不能通关、难不难、会不会卡死）
3. 不合格就自动调整重试（最多试 50 次）
4. 把合格的关卡**按难度从易到难排好序**

最后你拿到两样东西：**合格的关卡** + **排好序、可以直接上线的关卡**。

---

## 二、第一次使用：先装一个 Node.js（只装一次）

这个工具需要 Node.js 才能跑。检查你的电脑装没装：

1. 打开**终端**
   - **Mac**：按 `Command + 空格`，输入 `终端` 回车
   - **Windows**：按 `Win` 键，输入 `cmd` 回车
2. 输入这行命令后回车：
   ```bash
   node -v
   ```
3. 如果显示一个版本号（比如 `v18.17.0`），说明已经装好了，**跳到第三步**。
   如果提示"找不到命令 / not recognized"，就去下载安装：

   👉 下载地址：https://nodejs.org （选左边的 **LTS 长期支持版**，一路下一步装完）

   装完**重新打开**终端，再输入 `node -v` 确认有版本号。

---

## 三、放入图纸

把美术给的 `.txt` 像素图纸，**复制进 `input_txt/` 文件夹**。

- 一次可以放很多张
- 推荐用 **11~12 种颜色**的大像素图（64×64 ~ 90×90）
- ⚠️ 8~9 种颜色的图不建议用（实测 93% 会出太简单的关）

---

## 四、开始生产（两种方式，任选一种）

操作前要先让终端"进入"这个文件夹。最简单的办法：

- **Mac**：在终端输入 `cd ` （注意 cd 后面有个空格），然后把这个文件夹**拖进终端窗口**，回车。
- **Windows**：直接打开这个文件夹，在地址栏输入 `cmd` 回车，终端就会停在这个文件夹。

然后选一种方式启动 👇

### 方式 A：网页版（推荐，能看到进度）

输入：
```bash
node server.js
```
浏览器会自动打开 `http://localhost:3000`，在网页上能看到每一关的生产进度。

### 方式 B：命令行版（更省事，跑完即走）

输入：
```bash
node run.js
```
终端里会滚动显示进度，跑完会有一个"完成"汇总框。

> 生产是全自动的，关卡多的话需要等一会儿，**让它慢慢跑就行**。

---

## 五、去哪里拿成品？

跑完后看这两个文件夹：

### 📁 `output_json/` —— 合格的关卡 + 报告
- `001_xxx.json`、`002_xxx.json`…… 合格的关卡（按图纸原始顺序编号）
- `批量分析结果.csv` —— 每关难度明细（按难度排名）
- `生产汇总报告.csv` —— 每关状态（合格 / 不合格）

### 📁 `output_sorted/` —— 排好序、可直接上线的关卡
- `第1关_xxx.json`、`第2关_xxx.json`…… **从第1关开始，按难度从易到难排好**
- `排序清单.csv` —— 排序明细（关卡号、难度、所属组等）

> 简单说：**要上线就用 `output_sorted/` 里的；要看数据就翻 `output_json/` 里的 CSV。**

## 六、常见问题

**Q：有的关卡标了"不合格 / 需美术返图重修"？**
A：说明这张图纸试了 50 次都做不出合格关卡，通常是图本身太简单、撑不起难度。换张图或让美术重画。

**Q：我想重新生产某些关？**
A：工具会**自动跳过 `output_json/` 里已经有的关卡**。想重做的话，把对应的 `.json` 从 `output_json/` 删掉，再跑一次即可。

**Q：只想重新排序，不想重新生产？**
A：输入 `node sort_levels.js`，它会用现有数据重新排一遍，更新 `output_sorted/`。

**Q：网页版提示端口被占用 / 打不开？**
A：可能上次的没关干净。关掉终端重开，或者直接用命令行版 `node run.js`。

**Q：放工具的文件夹路径有中文，会不会有问题？**
A：不会，工具支持中文路径。
