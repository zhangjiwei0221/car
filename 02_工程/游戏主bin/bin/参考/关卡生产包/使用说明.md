# 毛线关卡生产流程迁移包

这个包用于按当前规则从 TXT 像素图生产关卡 JSON。

## 目录

- `tool/`：生产脚本和关卡工具依赖文件。
- `tool/scripts/run_batch_txt_node.js`：批量生成 JSON 的主脚本。
- `tool/scripts/generate_palette_png.py`：生成 PNG 色库检查图。
- `tool/dist_new/`：生成脚本依赖的工具代码。
- `config/标准色库毛线真实.txt`：真实毛线色库。
- `workflows/`：两份生产流程 md。
- `input_txt/`：放要生产的 TXT 文件。
- `output_json/`：生成后的 JSON 输出目录。
- `palette_png_detailed/`：PNG 色库检查图输出目录。

## 生产黑块版 JSON

把 TXT 文件放进 `input_txt/` 后，在本目录执行：

```bash
node tool/scripts/run_batch_txt_node.js black input_txt output_json json
```

## 生产无黑块版 JSON

```bash
node tool/scripts/run_batch_txt_node.js noblack input_txt output_json json
```

## 生成 PNG 色库检查图

第一次使用如果提示缺少 `PIL`，先安装图片库：

```bash
python3 -m pip install -r requirements.txt
```

生成 JSON 后执行：

```bash
python3 tool/scripts/generate_palette_png.py input_txt output_json palette_png_detailed
```

会生成：

- `palette_png_detailed/*.png`
- `PNG色库检查汇总.md`

## 当前核心规则

- 输出 JSON。
- 棋盘最大 `10列 x 9行`，且列数必须大于等于行数。
- 第一排禁止放置管道。
- 管道最大深度为 `6`，超过则增加管道数量。
- 补充颜色总数 `8-9种`，补充颜色组数 `30-40组`。
- 颜色判断优先使用 `config/标准色库毛线真实.txt`。
- 编号 `2` 粉色优先规避，仅在候选不足时兜底。
- 补充颜色优先覆盖更多色系，禁止连续集中选择同一色系。
- 最终补充颜色序列按色系交错排列；只要存在其他色系候选，禁止相邻两个补充颜色属于同一色系。
- 强近似色对禁止同时作为补充颜色出现：`8/10`、`7/17`、`3/8`、`14/23`、`17/18`、`10/11`。
- 色系分组：
  - 红/粉系：`1,2,3,4,5,6,12`
  - 紫系：`7,8,9,10,11,16,17,18`
  - 蓝/青系：`13,14,15,21,23,33`
  - 绿色系：`19,20,22,24`
  - 黄/橙系：`25,26,27,28,29,30`
  - 浅色/灰白系：`31,32,34`

## 红点文件说明

文件名带 `🔴` 表示结构生成成功，但验证器没有完全绿过。之前的生产流程也是保留这类 JSON 供人工筛选。
