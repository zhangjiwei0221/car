关卡数据说明
每一关单独使用一个json文件
其中json格式为：
{
    "toprow": 7,
    "blocks": [
        [{"id":1,"type":0},{"id":2,"type":0},{"id":3,"type":1}],
        [{"id":1,"type":0},{"id":2,"type":0},{"id":3,"type":0}],
        [{"id":1,"type":0},{"id":2,"type":0},{"id":3,"type":0}]
    ],
    "maprow": 7,
    "mapcol": 7,
    "spools": [
    	[{"id":1,"type":0,"param":0},{"id":2,"type":0,"param":0}，{"id":3,"type":0,"param":0}],
        [{"id":1,"type":0,"param":0},{"id":2,"type":0,"param":0}，{"id":3,"type":0,"param":0}],
        [{"id":1,"type":0,"param":0},{"id":2,"type":0,"param":0}，{"id":3,"type":0,"param":0}],
        [{"id":1,"type":0,"param":0},{"id":0,"type":[11],"param":{2,1,2,3}}，{"id":3,"type":0,"param":0}]
    ]
}
说明：
toprow：是目标区的初始显示行数，由加载原始数据时，确定的基础行数
blocks：二维数组，从上到下，从左到右，目标区的地图布局
{
	blocks数组中的值是一个对象，
	ID表示颜色，是当前元素的编号，0表示为空
	type表示当前元素的特殊功能，
	目标区的type值：0表示没有功能，1表示为问号元素
}
maprow：是元素区的行数
mapcol：是元素区的列数
spools：是元素区的二维数组，从上到下，从左到右，元素区的地图布局
{
	元素区数组的值是对象
	ID表示颜色，是当前元素的编号，0表示为空，-1表示不做任何处理是黑块
	type表示当前元素的特殊功能，如果是0，表示没有，如果是一个数组，每一个数值表示一种功能
	元素区的type值，{
					11表示管道（向上）（使用参数表示管道中包含的元素ID数组，类似队列），
					12表示管道（向右）（使用参数表示管道中包含的元素ID数组，类似队列），
					13表示管道（向下）（使用参数表示管道中包含的元素ID数组，类似队列），
					14表示管道（向左）（使用参数表示管道中包含的元素ID数组，类似队列），
					21表示钥匙1（不用参数），
					22表示钥匙2（不用参数），
					23表示钥匙3（不用参数），
					24表示钥匙4（不用参数），
					25表示钥匙5（不用参数），
					31表示锁1（不用参数，与钥匙ID+10是一对），
					32表示锁2（不用参数，与钥匙ID+10是一对），
					33表示锁3（不用参数，与钥匙ID+10是一对），
					34表示锁4（不用参数，与钥匙ID+10是一对），
					35表示锁5（不用参数，与钥匙ID+10是一对），
					4表示冰块（不用参数），
					5表示链条（使用参数，参数是链条ID，ID相同的是一组），
					6表示问号元素（不用参数）
				  }
	param表示特殊功能所使用的参数，0表示没有，数值或数组都表示是特殊功能所使用的参数
}
