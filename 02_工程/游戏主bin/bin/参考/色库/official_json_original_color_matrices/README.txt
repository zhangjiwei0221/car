官方 JSON 原始颜色编号矩阵版

共 300 个关卡：level_1.txt 至 level_300.txt。
文件格式：第一行「像素矩阵」，后续每行使用空格分隔整数。

颜色：直接保留官方 JSON 的颜色编号 0–21，不进行颜色重新映射，也不加 1。
空位：使用 -1，避免与有效颜色编号 0 混淆。
方向：已修正上下方向。官方 y=0 位于底部，TXT 第一行数据位于顶部；
      JSON [x,y] 对应矩阵下标 [高度-1-y][x]，每行从左到右排列。
内容：提取「像素棋盘.基本层」中的普通像素；钥匙及上一层覆盖物不写入颜色矩阵。

随附「original_color_library.txt」包含 colors.py 中原始颜色编号及 Hex 色值。
导入/预览时应按这套 0–21 色库读取，并把 -1 视为空位。
