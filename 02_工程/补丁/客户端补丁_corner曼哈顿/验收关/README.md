# 验收关：需求文档 §二 那张 10×10 图（A=28）

> 来自 `01_项目文档/需求_消除逻辑_小车选像素小人_corner.md` §二。
> 用途：让客户端和文档**对同一张图**，不用靠描述猜。

## 文件

| 文件 | 是什么 |
|---|---|
| `验收_10x10_A28.txt` | 目标图，编辑器「导入 TXT」直接可用（A=色号 1，共 28 个；其余=色号 13） |
| `关卡_验收A28_容量15.json` | 客户端关卡（10×10；A 车 15 + A 车 13 + B 车 72，容量守恒 100） |
| `关卡_验收A28_容量25.json` | 同上，A 车 25 + A 车 3 + B 车 72 |
| `验收图_容量15.png` / `验收图_容量25.png` | 文档那两张序号表的渲染图，拿来对照 |

## 文档要求的顺序（容量 15）

```
       c0 c1 c2 …            c9
  r0    -  -  -  …            -
  r1   15  ·  ·  …            ·
  r2   14  ·  ·  …            ·
  r3   13  ·  ·  …            ·
  r4   12  ·  ·  …            ·
  r5   11  ·  ·  …            ·
  r6    9  ·  ·  …            ·
  r7    6  8 10  …            -
  r8    3  5  7  …            -
  r9    1  2  4  …            -
```

**最容易被抓包的一格：第 5 个应该是 `r8c1`**（它被 r9c1、r8c0 挡住，前两个被取走后才露出来）。

## 怎么用（游戏里看）

```bash
cd ~/Desktop/游戏版本/ParkPassenger_corner/ParkPassenger.app/Contents/Resources/bin
cp G1_bq_level_1.json G1_bq_level_1.json.bak          # 先备份
cp "<本目录>/关卡_验收A28_容量15.json" G1_bq_level_1.json
```

1. **⌘Q 完全退出游戏**，重新打开；
2. 进第 1 关；
3. **先把颜色 1（橙色那辆）容量 15 的车放上去**（其它车先别放），看它先吃哪 15 个；
4. 对照上面那张表：第 1 个是不是左下角、第 5 个是不是 `r8c1`。

看完恢复：

```bash
cd ~/Desktop/游戏版本/ParkPassenger_corner/ParkPassenger.app/Contents/Resources/bin
mv G1_bq_level_1.json.bak G1_bq_level_1.json
```

## 注意

- 这是**试玩/对表**用的关，不是产出关；车少、图小，只为看清顺序。
- 颜色号用的是 1 和 13（第 1 关里就有的颜色），换别的关替换时注意颜色是否存在。
- 关卡 JSON 的 `blocks` 是**从上到下**（r0 是顶行），和文档表格一致。
