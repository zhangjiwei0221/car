# 目标图生成规范（2026-11-02 定稿）

> **本文只讲“怎么造一张适合做关卡的目标图”。** 关卡生成另见 `关卡流程_当前.md`。
> 新对话从本文件开始即可，不需要读其他历史。

---

## 一、为什么要单独做图

实测结论：**图的色彩结构决定 at4 的上限，但流程的随机性更大**。
现在缺的是“能出好关的图”，所以先把图造好。

---

## 二、硬性指标（造完必须量）

用下面的脚本量（可直接跑）：

```bash
node 03_工具/正式版/ImgFeature_v781.js test/xxx.txt
```

| 指标 | 要求 | 依据 |
|---|---|---|
| 尺寸 | 35–40（方形） | 用户定 |
| **色数** | **16–18** | 官方中位 16；18 色的那张 at4=11（最好） |
| **每色平均像素** | **≈80** | 1444 ÷ 18 |
| **最大色占比** | **≤12%** | 官方最小 10%；超了就是"大色块" |
| **碎度·块数** | **18–22**（每色连通块中位） | 最好那张是 20 |
| **碎度·块大小** | **3–4px**（每块平均像素） | 最好那张是 3.8 |
| **包围色比例** | **≥7%** | 最好那张 7.1%；其余 0–6% |

**目标区间（造图时的硬指标）**：

```
色数 17–18 | 最大色 ≤ 12% | 块数 20±2 | 块大小 3–4px | 包围色 ≥ 7%
```

## 三、构图规则（今天验证过的）

### 1. 背景

| 做法 | 结论 |
|---|---|
| **多色块拼贴**（5–6 色、块 5–20px、直角边、大小不一） | ✅ 用户认可的方向 |
| 大面积纯色（占 50%+） | ❌ 免费车工厂（纯色图 at4 只有 19%） |
| 均匀小网格（6px 以下） | ❌ 太碎、太乱 |
| 双色小棋盘 | ⚠️ 可用，但看着单调 |

**推荐**：`compose_dense_v777.py --pattern patchwork`（大块不规则）或 `--pattern grid`（规律网格），
色板用**浅色系**：米 31 / 浅黄 32 / 灰 34 / 浅粉 5 / 浅蓝 14。

### 2. 主体

| 规则 | 说明 |
|---|---|
| **原尺寸 18×18，不许缩放** | 缩到 16 或 11 都会糊 |
| **紧挨摆放**（间距 1–2px） | 空隙大 = 背景太多 |
| **要有"被包围的关键色"** | 例如蛋黄被蛋白包住、草莓籽被红肉包住 |
| 数量 4–9 个 | 太多会乱，太少背景占比高 |

**有包围色的主体（按包围度排序）**：

```
面包 80% | 拉面 78% | 甜品 76% | 炒饭 74% | 烤肠 73%
单块披萨 69% | 甜虾寿司 69% | 西兰花 68%
```

主体库：`蚂蚁图库/拼接图/主体图纸库_50张/*.txt`（18×18，5–7 色，0=空）

## 四、可用工具

| 工具 | 作用 | 关键参数 |
|---|---|---|
| `compose_dense_v777.py` | **主力**：多色块背景 + 主体紧挨 | `--size --blocks --block-size --pattern(patchwork/grid/checker) --scale 18 --subjects "名@y,x;..."` |
| `compose_free_v775.py` | 纯色/双色背景 + 卡点色散点 | `--bg2 --choke` |
| `compose_uneq_v763.py` | 不等分象限 | `--split x,y` |
| `compose_raw_v757.py` | 四象限（旧） | `--bg4 --fw4` |
| `ImgFeature_v781.js` | **验收图指标** | 输出色数/块数/块大小/包围色% |

**常用命令**：

```bash
# 拼一张
python3 03_工具/正式版/compose_dense_v777.py --size 38 \
  --blocks "31,32,34,5,14" --block-size 6 --pattern grid --scale 18 \
  --subjects "面包-1@0,0;甜品-1@0,20;炒饭-1@20,0;草莓-1@20,20" \
  --out 实验关/目标图_拼接/新图.txt --png 实验关/renders/新图.png

# 量指标
node 03_工具/正式版/ImgFeature_v781.js 实验关/目标图_拼接/新图.txt
```

## 五、造完图后的验证流程

```
① ImgFeature 量指标 → 是否落在目标区间
② 跑一遍关卡生成（GenLevel 8 候选）
③ 看 at4：≥20 说明这张图能出好关
```

**注意**：目前 at4 的随机性很大（同图同参数可在 0–20 之间跳），
所以单次结果不作数，**至少跑 3 次取最好**。

## 六、已知的坑

| 坑 | 说明 |
|---|---|
| 背景一大片纯色 | 该色的车永远能填满 → 没压力 |
| 主体缩小 | 糊成一团，图形不可辨 |
| 主体间空隙大 | 背景占比高，同"纯色背景"问题 |
| 点缀撒在主体上 | 把主体画面冲乱（已加 2px 保护区解决） |
| 点缀不贴边、不压主体 | 视觉上才干净 |
