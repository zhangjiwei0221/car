## 5. 已知的坑（别再试）

| 手段 | 结论 |
|---|---|
| 打碎目标图（1px/2px 打乱） | ❌ 画面不可辨认，用户否决 |
| 末段冰 / 末段大车 / 末段双开 | ❌ 不产生债务，峰值不变 |
| 墙 / 删车并容量 | ❌ 越删越糟 |
| 几何分带（按距离切条） | ❌ 玩家选颜色不选位置 |
| 延后闸门解锁 | ❌ 死锁（前一主体耗尽后无车可取） |
| 按碎片度挑官方图 | ❌ 与 at4 无相关 |
| 只换棋盘边界圈 | ❌ 可换对数不足 |
| 全图打碎目标图 | ❌ 画面不可辨认（用户否决） |
| 管道 | ⚠️ 会留下空格且不可补黑块；用前确认收益 ≥3 步 |
| 冰加在"单车辆颜色"上 | ❌ 直接不可通关（该色没有第二辆车能收） |
| 方形棋盘求「窄暴露」 | ❌ 边框一圈天然全暴露（7×7 就 24 格） |
| 瘦长棋盘（30×4，黑块 50%） | ❌ 数学上能窄暴露，用户不接受「肯定接受不了啊」 |
| 撤链保压力 | ❌ 方形棋盘压力只能靠障碍：04 容错 20%↔95% 随链有无跳变 |

**已确认有效**：颜色按主体独占（目标感）、数字冰闸门（顺序）、`LayerByEdge` 分层（前松后紧）、
`--buf-threshold`、1 格宽内部通道强制车序（但牺牲决策度）、死亡判定「结算后 ≥上限且无车装满才死」。
