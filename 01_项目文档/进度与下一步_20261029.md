### 1.2 已验证的结论（可复用）

**指标判定**（哪些能筛、哪些不能）：

| 指标 | 结论 |
|---|---|
| 硬门（守恒/可通/无空格/最小车） | 必要，但随机基线也有 8/20 通过 —— **只能筛掉一半废关** |
| 峰值 / 中段 / 容错 | 依赖路线，**min 与 player 可完全背离**（手搭 v2：min 峰值 1，玩家峰值 5） |
| 决策度 | 测的是"有选择"，不是"选择有意义" |
| 象限/主体并行 | 四象限专用，对 Mode B 类图失效 |
| at4≥5、容错 55–75% | 校准可疑（手工关也只有 at4=3、容错 18/20） |

**可控性**：

- **能掌控**：容量守恒、可通、最小车、棋盘尺寸/风格、障碍位置与时机、开局免费车数量、大致压力区间
- **不能完全掌控**：玩家的实际路线、动态连锁会吃掉"看起来的债"、指标间互斥（at4/中段/容错）、以及"好"的定义本身
- **结论**：**结构（棋盘/障碍/容量分布）比参数（avg/搜索）重要；指标只能筛废，不能定好；风格是用户的第一判据**

**关键教训**（别再踩）：

1. 骨架黑块/门位**不可复用** —— 一用就"老地方"、同质化
2. 冰参数**不可搬图**（搬 = 容错 0/20；派生 = 8/8 但平）
3. 车数不应倒推棋盘（"少而大"换成 4 行棋盘，被否）
4. 个位数碎车是反模式（官方关几乎 ≥8px）
5. 管道很可能是压 min 路线的必要工具（官方关 21/38 辆车带障碍）
