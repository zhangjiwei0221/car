### 步 2.5 · 加障碍（链 / 冰 / 问号）——2026-11-17 正式入流程

**障碍选择决策表（2026-11-19 定稿；依据 §3.96–§3.98 与日志 §1100–§1127）**

| 目标 | 手段 | 规则 | 不要用 |
|---|---|---|---|

**管道（2026-11-19 定稿，尚未用于任何交付关）**

- 构造：**黑块填格，不许 0 容量管道**；队列首位=死债车；功能管出口放深行（开管中位 ≥25%）；**1 根就够**（多管饱和，胜率被开管率封顶）。
- 剂量：队列 **2 辆即饱和**（3–4 持平、5 回落、6 断崖）；占比 **4% 起效**、24–29% 可更强但不稳定、**≥32% 变随意陷阱**。
- 用法：只当“救早死”的靶向手段，**不当难度工具**；真实关的 4–5 管/29% 结构贴近悬崖，未验证能否安全复制。

**链（正式规则，详见 §3.96.3）**

```bash

```

- 选对：第 0–1 行、正交相邻、绑中段需求色（midShare 高）、两车首次被拿 **2–35%**；
- **颜色窗口（2026-11-20，日志 §1140）**：排除 `windowRisk=true` 的色——`freeLast <0.6` 或 `window=freeLast−freeFirst <0.2`，或（该色唯一车且 `freeLast <0.8`）。扫描器已输出 `windowA/B`、`carsA/B`、`uniqueCar`、`riskA/B`。窄窗独占色（如 140 的色 15：38px、唯一车、窗口 25.6–37%）绑进链 = 永久债陷阱（链色 0 进度 12.4 步/局、结束时卡 0 率 32%）。

- 闸门：`ChainRatchetCheck` PASS、`Solvable --width 8`、`EscapeValveCheck` PASS；1–2 条，先验证一条再加第二条。

**冰（§3.97 实测规则）**

- **只放第 2 行及以后；第 0–1 行不放**——开局冰会锁掉早死坑，把随意档从 .53 抬到 .83–.99（安全绳）；
- **param 按关卡步数配**：47 步关用 **17–48**（线上 35–42 同款）；3–10 在第 4–9 步就碎，深行等于没加；
- 不放在链格上；加完复跑守恒/空格/开局/可通关。

**问号**：2–3 个，放在“容易一口吃满”的非链车（`QuestionMark_v767`），只藏颜色、不影响可解性。

**表演冰（用户 2026-11-19 定名）**：深行冰只为“好看/有节奏”，不改变解法——玩家走到那片区域、进度差不多时，冰刚好解开。

### 3.96.3 规则修正：接受早期链（用户 2026-11-17「先按你说的来」）

`首次被拿`（firstPick）= 底座上 20 局随机路线里，该车第一次被点的进度中位；它在**绑链之前**量，告诉你这条链会在哪一段拆掉玩家的计划。
链的机制是“组内全部成员激活才可点、点一端两端一起进暂存（占 2 格）”，所以 firstPick 越低，拆掉的越是开局本来就少的选项。

- 原规则：firstPick **0.10–0.35**（六个变体试出来的窗口）。
- 下限 0.10 原本是防“开局陷阱”（112 C4：两格第 0 行、7 步吃完、随机 0.076），是**间接护栏**。
- 新证据：194 C2-早链（.038/.043）、205 C1（.088）证明 2–10% 可以做出“难而公平”的关；而直接护栏（三段口径）会把陷阱识别为随意档 ≈0.08，必被拦。
- **新规则：firstPick 2–35%**，同时保留：绑中段需求色、棘轮 PASS、可通关、三段口径。

**结论（修正）**：
- **“开局冰”是安全绳，“深行冰”是纹理**——不是“冰”整体如何；
- **线上 35–42 的冰全部在第 2–6 行**，因此它们的带内数字（.53–.71）没有被冰削弱，之前的“冰削弱后的链”说法作废；

**结论修正——管道不是通用的难度旋钮，是“早死坑的靶向药”**：
- 成立需要**两个条件同时满足**：① 底座有早死坑（lt10/lt25 > 0）；② 锁掉的车确实是随意玩家的早死诱饵。18 满足两条 → 三类全部复现；205 没有早死坑（lt10=0）→ 锁了也无事可做，且管道作为永久阻挡格的成本占上风；211 的“生命线色”27 同时是随机玩家 10–25% 早死诱饵 → 反向变成安全绳。
- **“贪心前 5 步=生命线”这个分类不可靠**：同一颜色可以是“认真玩家必需”又是“随意玩家的早死诱饵”。正确的判别轴是**“这辆车是不是随意玩家早死的诱饵”**——要从死亡回放里找（哪一步、哪辆车之后 lt10 死亡集中），而不是从贪心路线推。

## 4. 还没解决

1. **锁链与管道的内核**：链是"耦合"（两辆车同进同出），管道是"隐藏队列"。数据上它们在中性剂量（1–3 组链、1–3 格管道）与线上表现无关；真正的问题是怎么让"耦合"产生代价。计划：在成批关里挑 3 张，各加 1–2 组链做 A/B（棘轮 + 随机通关 + 熵）。
2. **绝对难度标定**：只能靠试玩与上线数据。
3. **难度曲线/关卡位置**：暂不考虑。
