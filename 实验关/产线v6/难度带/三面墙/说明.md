## 6. 墙模式经验小结

- 墙把难度分布拉得很开（1.00 / .90 / .13），同一张图可能直接不可玩；
- 链色必须按墙模式重算，且要加“车数 2–6”的约束；

## 16. 拆车（容量杠杆）实验（2026-11-22）

在 c 版（换位后）上把三个开局单车色各拆两半，腾格办法是把三辆冗余色的深处车并到同色另一辆：

|---|---|
| 拆 | 色15 `(0,0) 59→30+29`、色6 `(0,1) 57→29+28`、色26 `(1,1) 20→10+10` |

| 项 | 数值 | 判定 |

| 随意 | **.672** | ✅ 带内 |
| 认真 | **.983** | ✅ |
| 倒序 | **1** | ✅ |

| 棘轮 | **FAIL（flags=41）** | ❌ 拆车制造了新陷阱路线 |

- **拆车没有降低早死**：拆开的另一半落在深处，点一半仍欠整色，债务没减，只是变碎；
- **棘轮爆**：小的半车让“认真路线”出现更多坏分支。
