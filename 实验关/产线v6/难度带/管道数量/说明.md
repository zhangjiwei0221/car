> 问题：自然形态下把功能管从 1 根加到 2 根、3 根，安全绳是**叠加、饱和还是互相抵消**？

## 0. 预测（写于扫描前，先看判定标准）

### 0.1 方向性判断

1. **M2（2 根管）：偏向“接近饱和、小幅叠加”。**
   依据：单管 N1 已把随意从 .527 抬到 .903、lt10 141→17；死债首名 (0,2) 11/21 是 BaitLocator 第一债务（98 次），死债 #2 的 28/44（68 次）弱一档。
   预测 M2 随意 **.90–.94**（相对 M1: 0 ~ +4pp），lt10 **≤17**，lt25 **≤34**。
2. **M3（3 根管）：偏向“饱和甚至轻微抵消”。**
   依据：每加一根管 = 多 1 个永久管身格 + 1 个黑块；N4/N5 已显示 5–6 辆/更多占格开始有后段代价（C30_6 只有 .740）。
   预测 M3 随意 **.89–.93**（相对 M1: −2 ~ +3pp），认真 **≥.98**；若出现黑块围死同色像素，可能掉到 .85 以下。
3. **最可能的单一结果**：**饱和**——M1 已把“死债首名”清掉，第二、三根管没有新的“早死主因”可清，收益接近 0，代价（占格）开始显现。

### 0.2 判定标准

- 有效差：**|Δ| ≥ 8pp**（300 局 95%CI ≈ ±5.7pp）；lt10/lt25 以“相对基线的削减量”对比（基线 977 lt10=141 / lt25=264）。
- **叠加**：M2−M1、M3−M2 都 ≥ +8pp（或 lt10/lt25 逐级显著下降）。
- **饱和**：M2−M1 与 M3−M1 都在 ±8pp 内，且开管率/开管后死亡不再改善。
- **抵消**：M3 或 M2 相对 M1 ≤ −8pp，或出现 Solvable 失败 / 棘轮 FAIL / 开管率下降导致的胜率封顶。
- 多管互相锁死：Solvable 宽 8/16/32 失败、棘轮 `allMovesDead`、或两管出口互相阻塞（某管永远不吐车）。

### 0.3 构造预案（先定，扫描前不改）

- **M1**：复刻 N1（管 P=(5,3)↓，出口 (6,3)；队列 [(0,2) 11/21, (5,3) 12/44]）。
- **M2**：M1 + 第二根管，死债车 (0,0) 28/44。**先试 (0,0)**；若开局可点 <5（预计会：黑 (0,0) 使 6→4，加 M1 后 5→3）则换同色同容 **（2,2) 28/44**（自然管道 N2 的既有替代）。
- **M3**：M2 + 第三根管，死债车 (0,1) 32/44。**先试 (0,1)**；(0,1) 是第 0 行，同样压开局；若 <5 换同色 32 的另一辆 **(4,0) 32/27**（自然管道 N3 的既有替代）。
- 每根管的第二辆车（队尾）= 该管 P 自己的车，必须是普通车、该色 ≥2 辆（禁止唯一车进队列）。
- 出口：行 ≥4、互不相同；每根管出口格改关后仍是普通车（否则管永远不吐车）。
- 换格上限 10 次，全部记录在 §6。

## 1. 结论（先看数字）

1. **管道数量是「饱和」，不是叠加，也没有互相抵消。**
   随意档（977/4242）：M1 **.903/.890** → M2 **.940/.913** → M3 **.930/.913**。
   M2−M1 = **+3.7 / +2.3pp**，M3−M1 = **+2.7 / +2.3pp**，M3−M2 = **−1.0 / 0.0pp**；
   全部 |Δ| < 8pp（300 局 95%CI ≈ ±5.7pp），**按预登记的判定标准属于饱和**。
   方向上是“多一点更好”的弱趋势，M2 是三个里最好的，但 M2 与 M1/M3 在统计上不可区分。
2. **认真档不动**：M1 .993/1.000、M2 .993/.993、M3 .997/.993（Δ ≤0.7pp）。天花板已到。
3. **多管没有把“早死局”救回来——胜率被开管率封顶。**
   纯随机（p0）下 **胜率 = 开管率**：M2 .93/.89、M3 .90/.92；**所有死亡都发生在“一根管都没开”的局**（`opensAmongDeaths = 0`，M1 977 仅 1 局例外）。
   加管**没有提高开管率**（92/96% → 93/89% → 90/92%），所以救不了没走到出口的局。
   “安全绳”是**条件药**：走到深出口并开管 ≈ 通关；多一根管只是多一条同样的条件通路。
4. **lt10/lt25 只有方向性小幅改善，不延续到第三根。**
   lt10/lt25（977 / 4242）：M1 **17/34 · 22/46** → M2 **14/23 · 20/33** → M3 **17/27 · 19/31**。
   M2 把残余早死削掉约 1/3（lt25 34→23、46→33），但这是 1100 局里 11–13 局（≈1pp），**低于胜率的 8pp 阈值**；M3 不再继续降。
   M2 的 2200 局死亡分布里 **>50% 进度死亡 = 0**（M1 有 2 局 >90%），死亡全部落在 <50%；M3 又出现 4 局 50–90%。
5. **代价在压力侧，不在胜率侧**：at4（p0.1/p0.2）M1 12.97/12.28 → M2 **15.58/13.83** → M3 14.42/12.93。
   多管把“暂时压力”抬高，但随机胜率不再涨——与自然管道实验里“2 辆打满、更多车只加后段压力”的形状一致。

**一句话**：第一根管（清掉死债首名 11/21）已经把安全绳打到饱和；**第二、三根管在胜率上没有可测增益**，只把残余早死略微削薄、把暂存压力抬高；在本底座上不存在“多管互相锁死/不可解”。

## 4. 机制：开管率就是天花板

| 变体 | 977 开管率 / 胜率(p0) | 4242 开管率 / 胜率(p0) | 开管后仍死 | 没开管就死 |
|---|---|---|---|---|
| M1 | 92% / 91% | 96% / 96% | 1 / 0 | 8 / 4 |
| M2 | 93% / 93% | 89% / 89% | 0 / 0 | 7 / 11 |
| M3 | 90% / 90% | 92% / 92% | 0 / 0 | 10 / 8 |

- **所有 M2/M3 的失败都是“一根管都没开”**；开了任意一根管的局全胜（`opensAmongDeaths = 0`）。
- 逐局核对（977，100 局）：M2 **93 局全开全胜 / 7 局全没开全败**；M3 **90 / 10**；**“只开了一部分管”的局 = 0**（partial = 0）。
  即随机路线一旦走到底部，三根管是一起开的（全有或全无），不存在“第一根救不了、第二根补上”的局。
- 开管是逐管的：每根管只在自己的出口格第一次被拿走时开。多管**没有提高开管率**（M1 92/96% → M2 93/89% → M3 90/92%），
  因为没开管的局死得很早（lt10/lt25），根本走不到第 4–6 行的任何出口。
- 因此第一根管已经把“能走到出口就赢”这条通路铺满；第二、三根管只是**并联了一条同样的条件通路**，
  在“能不能走到出口”这个瓶颈上没有贡献。

## 7. 测量口径与限制

1. **局数/CI**：每 p 100 局；随意/认真各 300 局，95%CI ≈ ±5.7pp；lt10/lt25 每 seed 1100 局。M2/M3 均跑 977+4242；M1 复用 N1（同一关卡文件，逐字段已核对）。
2. **单底座、单管位**：结论只对 194 这张图、这组管位成立；管的**位置**只做了硬门筛选，没有把 3 个通过的 M2 候选都跑 PInterp（避免按结果挑管位）。
3. **死债目标被开局门扭曲**：M2/M3 名义上是死债 #2/#3，实际藏的是同色替代格；(0,0)/(0,1) 这两个**可点诱饵**仍留在盘上。
   这很可能是“第二、三根管不叠加”的直接原因——早死主因 (0,2) 已被 M1 清掉，后面的债务本来就不是主要死因。
4. **开管时机不完全受控**：同一管在不同变体里开管中位 62–82%，黑块/管身改变了暴露顺序。
5. **at4 只反映压力**：M2 at4 最高（15.58/13.83）但胜率也最高，说明“压力更大”不等于“更难赢”；at4 不能单独当难度尺。
6. **全是模型**：没有真人路径/体感验证；多管在视觉上是否自然、是否“看起来像真实关”未测。

## 9. 遗留

1. **“为什么第 2–3 根管不叠加”需要拆成两个因子**：①数量（多一条条件通路）②内容（藏的是不是可点诱饵）。
   本轮受开局门所限，M2/M3 只能藏替代格；若要真正测“再加一根死债首名管”，需要一个开局可点 ≥6 的底座，或允许在别处补 1 个开局可点。
2. **开管率没有被任何加管策略提高**（92→93→90%）。若要突破 .93 的随机天花板，方向应是“让出口更早可达/更多开局通路”，不是加管。
3. **M2 的 lt25 改善（34→23、46→33）** 虽低于阈值，但方向一致；可考虑 4242+其他 seed 复核 1/3 削薄是否稳定。
4. **管位未做结果级比较**：3 个 M2 候选都只过了硬门；若关心“管位本身对难度的影响”，需另跑管位对照。
5. **真人路径**：多管（尤其 M3 三根）在编辑器里的可读性/体感未验证。
