## 1. 结论

1. **占比不是单调变量；安全绳既不是“越加越强”，也不是简单倒 U。** 同一管位、同一出口、嵌套加格下（977）：
   随意 **Q2 .903 → Q4 .927 → Q6 .737 → Q8 .817 → Q10 .790 → Q12 .940 → Q14 .960 → Q16 .513 → Q18 .383**；
   认真 **Q2 .993 / Q4 1.000 / Q6 .563 / Q8 .993 / Q10 .963 / Q12 .993 / Q14 1.000 / Q16 .973 / Q18 .977**。
   曲线有**两个强区**（Q2–Q4 与 Q12–Q14）、一个**中段洼地**（Q6–Q10）、一个**高占比崩塌**（Q16–Q18）；
   **认真档几乎全程高处（除 Q6）**——高占比崩的是随意/半随意，不是技能解。
2. **最强区在 Q12–Q14（24.5%–28.6% 车数 / 23.6%–28.1% 像素），其中 Q14 最高：随意 .960/.963、认真 1.000/.997、lt10=lt25=0。**
   但 Q14 与 Q4（.917 两 seed 均值）/Q12（.933）的差 <8pp（≈1σ），按预登记阈值属于**同一最强平台**，不要单挑 Q14。
   机制不是“车多”，而是**黑块布局把出口提前暴露**：Q14 开管中位 **.432、开管率 100%**（Q2 .816/92%、Q6 .681/77%）；
   安全绳在 ~40% 进度就到账，而不是 80%。
3. **中段洼地是内容/时机陷阱，不是占比的锅。** Q6（12.2%）随意 .737、**认真 .563（p1 = .33）**，67/67 局死在 50–90%；
   它藏了色 28 的第二辆（2/4，54%），且开管中位 .681。**Q6b 对照**（同 6 辆/同 224px，把 (3,0)28 换成 (5,5)30）：
   认真 .563 → **.853**、p1 .33 → **1.00**、lt25 62 → 32 → **“藏同一色第二辆”是主因**；6 辆的纯数量代价仍在（.853 < Q4 的 1.000）。
4. **≥32% 隐藏像素 = “能开、收不住”的晚段技能闸。** Q16（32.7% 车 / 32.5% 像素）随意 **.513**、认真 .973；
   Q18（36.7% 车 / 37.5% 像素）开管中位 .28、开管率 100%，纯随机 **.383**（71/100 死于 50–90%），但认真 **.977（p0.9/1 = 1.00）**。
   8×8 容器 Q20（31.7% 车 / 32.1% 像素）更糟：纯随机 .137、认真 .360、棘轮 FAIL。
   → **边界不是“不可解”，而是“随意崩、认真仍赢”**；Q2–Q18 没有一档开局 <5 或 Solvable 失败。
5. **194 的结构上限 = Q18（36.7% 车 / 37.5% 像素）。** 再往上只剩 (5,2)/(4,1)/(3,1)/(2,1)/(1,1)，
   实测 Solvable 全失败（bestPx 411/319/295/187/143）；(2,3) 会藏掉色 28 最后一辆车（禁用）；
   其余是唯一车/冰/链/第 0 行。**停止原因是格子结构，不是守恒/开局。**

**一句话**：在这张图上，队列占比不是“越多越强”——**最强平台是 4%–29%（Q2–Q4、Q12–Q14，随意 .90–.96、认真 ≥.99，且 Q12/Q14 零早死）**；
中段 12%–20% 可以因内容/时机掉到 .74–.82（Q6 藏第二辆 28 → 认真 .56）；**超过 ~32% 隐藏像素后，对纯随机/半随机变成陷阱
（开管后 50–90% 段成片死亡，随意 .51→.38），对认真玩家仍然可通关（.97–.98）**——是技能闸，不是死关。

### 1.1 预测 vs 实测（事后核对，不改 §0 原文）

- **形状**：预测倒 U、峰值 Q4–Q8 → **实测 W 形**（Q2–Q4 与 Q12–Q14 两个强区，Q6–Q10 洼地），峰值 **Q14**。✗
- **Q14/Q16 预测 ≤.65** → Q14 **.960**（✗，远高于预测）、Q16 **.513**（✓）。
- **认真档 Q2–Q10 ≥.95** → Q6 **.563**（✗）；其余 ✓。
- **不可解边界 Q16–Q18** → **Q18（36.7%）** 是上限（✓）；原因不是“18 冰税”本身，而是格子结构（候选格实测失败）。✓
- **“损失主要来自开管后压力”** → 对 Q12+ 成立（死亡 100% 在开管后）；Q2–Q4 是开管率封顶；Q6 是内容陷阱。部分 ✓。

### 2.1 读表要点

- **开管中位不是常数**：Q2–Q10 为 .68–.82，Q12–Q14 .41–.43，Q16–Q18 .28。黑块位置改变了随机路线到出口的步数。
  这是本轮最大的混杂：**占比与开管时机没有分离**。读“占比”效应时必须带上开管中位。
- 开管率：Q2–Q10 77–92%，Q12+ 100%。高占比档的黑块把出口路线“清”了出来，开管不再是瓶颈；
  瓶颈变成**开管后能不能收住**（Q16/Q18 的死亡 100% 发生在开管后）。
- at4 峰值在 Q10（19.60/19.49），Q12/Q14 反而回落到 ~12–13：压力不等于难度；
  Q14 的“轻松”来自管道早开，不是压力低。

## 6. 遗留

1. **占比与开管时机没有分离（最大混杂）**：嵌套梯里 Q2–Q10 开管中位 .68–.82，Q12–Q14 .41–.43，Q16–Q18 .28。
   “Q12/Q14 最强”同时包含“早开”和“藏 24–28%”两个因素。要回答纯占比，需要**控制开管中位的对照**
   （同开管中位、不同隐藏量；或同隐藏量、不同开管中位）——本轮没有做。
2. **Q6 的认真档崩塌（.563）已用 Q6b 拆分**（同 6 辆/同 224px、换掉色 28 的第二辆 → 认真 .853、p1 1.00）；
   结论是“藏同一色第二辆”为主因，6 辆的纯数量代价仍在（.853 < Q4 1.000）。换其它冗余色的对照可再补，但不是必需。
3. **4242 全部补跑完成**（9 档 × 2 seed）；977/4242 两列都在表里。977 的 300 局 95%CI ≈ ±5.7pp，
   8pp 以内的差异不要当结论（Q4 vs Q2 的 +2pp 属于平台；Q12 vs Q14 的 +2pp 也属于平台）。
4. **单管、单管位**：真实关（G3-148）是 4 管/17 辆。多管同总占比时的释放节奏不同（多出口 vs 单出口），
   本轮的“技能闸”结论是否适用于多管未测；管道数量实验（M1–M3）只做到 6 辆/11.3%。
5. **8×8 底座是平凡关**（同图 8×8 切分、无冰/链，基线 ~.99），且 Q20 棘轮 FAIL；不能替代 194 读安全绳。
   真实的 7×8 已交付关（G3-148）本轮未拿来当底座（仓库/客户端里没有可直接复制的该关）。
6. **全是模型**：PInterp / at4 / openprobe 都是模型口径；真人路径（`OpeningCheck --path`）未跑，
   “看起来自然/好玩”未验证。
7. **Q18 的 18 辆单管队列**在形态上不自然（真实关每管 4–6 辆）；它回答的是“占比上限”，不是“推荐做法”。
   可玩性上，Q12/Q14（24–29%）是更现实的候选。
