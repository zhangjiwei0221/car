## 0. 问题与待验证假设

已知（日志 §1131、`冰剂量/说明.md`）：

- 冰在解封前是墙；墙本身不等于难度，决定方向的是**墙住的车是否本来会被拿**。
- 已有数据：冰-陷阱车 = 安全绳（把难度打没）；冰-生命线色 + 长 = 不公平；冰-冗余车/晚色短 = 近中性。

用户 2026-11-19 假设：

> **冰-免费车 + 短封锁（走几步就解）只提供短暂博弈、不抽走安全绳，可作为纹理。**

本实验在同一底座上把「冰压在哪类车」作为唯一变量，各做短/长两档，共 6 个变体。

## 4. 判定规则（扫描前写定）

- **可作纹理**：`|Δ随意| ≤ 5pp` 且 `Δ认真 ≥ −3pp`；
- **安全绳**（把难度打没）：`Δ随意 ≥ +8pp`；
- **不公平/陷阱**：`Δ认真 ≤ −5pp`，或出现新的中段死亡簇（25–50% 或 50–90%）。

参考口径：随意 = p0/0.1/0.2 胜率均值；认真 = p0.8/0.9/1.0 均值。
**Δ 用 977+4242 两种子平均**（单种子 100 局/档噪声约 ±5–9pp，见 `冰剂量/说明.md` §5）。
另记录 at4（p0.1/0.2）、lt10/lt25、墙覆盖步数。

## 5. 预测（扫描前写定）

1. **冰-陷阱车-短（p3）**：p3 约在第 2–3 步碎，早于该车首可点步 5 → 墙≈0。
   预期 `|Δ随意| ≤ 3pp`，**纹理**。它测不到「陷阱车 = 安全绳」，只测“冰没压在窗口上”。
2. **冰-陷阱车-长（p8）**：墙压在首可点窗口 5–8 上，正好挡住死债源。
   按已有数据「冰-陷阱车 = 安全绳」，预期 `Δ随意 +8~+15pp`，**安全绳**；Δ认真 ≥ 0。
3. **冰-免费车-短（p3）**：开局阀被挡约 2–3 步，随后恢复。按用户假设，预期
   `|Δ随意| ≤ 5pp` 且 `Δ认真 ≥ −3pp`，**可作纹理**（倾向 +0~−3pp）。
4. **冰-免费车-长（p5）**：阀被挡约 4–5 步。若随意玩家开局依赖该阀，可能
   `Δ随意 −5~−10pp`；认真档预期 ≥−3pp。**可能越过纹理线**，重点看开局死/早死簇是否增加。
5. **冰-冗余车-短（p3）**：p3 早于首可点步 13 → 墙≈0，预期 `|Δ随意| ≤ 2pp`，**纹理**。
6. **冰-冗余车-长（p16）**：墙压在窗口 13–16；色 7 有 4 辆车，冰一辆不产生新债。
   预期 `|Δ随意| ≤ 5pp`，**纹理**（可能略负 −2~−5pp）。

**总预测**：真正会把难度打没的只有 **冰-陷阱车-长**；会罚认真的只有 **冰-免费车-长**（若发生）。
「冰-免费车-短」应落纹理。

## 13. 回答用户的假设

> “冰-免费车 + 短封锁只提供短暂博弈、不抽走安全绳，可作为纹理。”

**按胜率口径：成立。** 冰-免费车-短的 Δ随意 −3.8pp、Δ认真 −2.3pp，两条都在纹理线内；
开局仍有 3 个逃生阀，安全绳没有被抽走。墙探针显示它只挡 2.45–2.52 步，确实“走几步就解”。

**但它不是纯中性，而是“中段税”：**

- 中段 p0.4–0.6 胜率 977 .710 vs 底座 .803、4242 .710 vs .823，**Δ中间 −10.3pp**（两种子完全同向）；
- lt25 从 76/63 升到 80/86，25–50% 死亡从 125/139 升到 173/178；
- 也就是说：**端点（随意/认真）不变，但中段玩家会更常死**。
  如果“纹理”要求“什么都不变”，它不是；如果按预先规则只看随意/认真两条，它是。

**长封锁立刻变成另一种东西**：冰-免费车-长只多挡约 1.7 步（墙 4.2 vs 2.5），
Δ随意 −9.7、Δ认真 −6.3，且中段死亡 221/212、977 认真死 38 局 → **不公平/陷阱**。
免费车这条线是**陡峭的**：短（2.5 步）可作纹理，长（4+ 步）越线。
