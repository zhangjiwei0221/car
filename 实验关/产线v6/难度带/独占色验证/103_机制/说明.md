## 1. 要回答的问题

上一轮 `103/变体_低独占/` 的链 `(0,5) 色1/35 + (1,5) 色19/32` 在 p0–p1 共出现 **13 局死亡**（死亡进度 2.9%–4.0%，第 5–6 步，暂存 4）；同图高独占链 `(0,0) 色29/50 + (0,1) 色3/49` 为 0 死亡。三个候选假设：

- **H1 早入链双占位**：链组 ~1.4% 一起进场，长期占 2 个暂存位，两色都凑不满。
- **H2 只是 firstPick 太早**：不管独占与否，1–2% 就被拿的链会锁死开局。
- **H3 共享色竞争**：两车颜色都有别的车共享，像素被分走，链组迟迟凑不满。

## 3. 13 局死亡的共同形态

**一句话：链组一次也没有进场；死亡是“开局 4 辆 0 进度车占满暂存 + 链把唯一能单格吃满的逃生车 (0,5) 锁死”。**

- **13/13 链组从未进入暂存**（`link>0` 计数为 0），死亡时链格仍完整在盘上。
- 死亡恒在 **第 5–6 步、暂存 4**；进度 **2.9%（9 局）或 4.0%（4 局）**。
- 死亡时暂存都是 **4 辆、至少 3 辆 `progress=0`**，只有色 33 有时 `progress=14/43`：
  - `{3,20,25,30}` 全 0 进度 ×4（第 6 步、4.0%）；
  - `{3,20,30,33}`（33=14/43）×5（第 5 步、2.9%）；
  - `{3,20,29,33}`（33=14/43）×4（第 5 步、2.9%）。
- 死因不是“链组占两个位”，而是 **`(0,5) 色1/35` 这个逃生阀被链吞掉**：
  - 色 1 是目标图外框背景色，corner 口径开局就能吃满；`(0,5)` 是第 0 行唯一的色 1 车，也是开局唯一“单格一次吃完、能腾出暂存位”的车。
  - **9/13**：`(1,5)` 尚未激活，链锁使 `(0,5)` 根本不可点（`isChainLocked`）；死亡选项里连 `0,5` 都不出现。
  - **4/13**：`(1,5)` 已激活，`(0,5)` 可点但整组要 2 个空位，`4+2>5` → blocked。
  - 其余所有选项都是“加第 5 辆车、本步无完成” → `overflow(满且本步无完成)`；`(0,5)` 若强行取则 `buffer=6` → `overflow(>limit)`。
- 4 辆 0 进度车的颜色（20/25/29/30/3/33）是目标图内圈色，corner 开局未解锁；**色 3/49 是 100% 独占色，同样 0 进度**——所以这些 0 进度不是“共享色被分走”造成的。

### 3.2 逃生阀反事实（同一盘面的直接对照）

对上述 6 步在 V_原 与 V_无链 上分别重放（两关在这 6 步内没有取链格，盘面完全相同），然后点 `(0,5)`：

```
V_原  (0,5) groupSize 2, blocked true  → buffer 6: …, 1/p35/n35 L1, 19/p0/n32 L1 → overflow true, deadEnd true
V_无链 (0,5) groupSize 1, blocked false → buffer 4: 20/p0,30/p0,25/p0,3/p0 → overflow false, deadEnd false
```

即：底座靠 `(0,5)` 单格吃满 35 px 腾位而活；同一盘面在链变体里因 `(0,5)` 被绑成 2 格组而溢出。**13 局死亡的差异完全由这一点解释，与链组是否进场无关。**

## 5. 结论：H1/H2/H3 都不成立，实际是 H4「逃生阀被链吞掉」

| 假设 | 判据 | 结论 |
|---|---|---|
| **H1 早入链双占位** | 13/13 死亡局链组从未进场；V_早独占在 0.3%–3.1% 进场、双占位 20%–28% 进度，1100 局 0 死亡 | **不成立** |
| **H2 firstPick 太早** | 13 局里链一次没被拿；底座的 `.014` 是“无链”统计，链变体实际进场 p0 只有 8%、p1 为 0；V_早独占 0.3% 进场仍 0 死亡 | **不成立** |
| **H3 共享色竞争** | 死亡局链组未进场；“0 进度车”里色 3/49 是 100% 独占色；V_共享晚两端共享色、驻留 22%–27% 进度，1100 局 0 死亡 | **不成立** |
| **H4 逃生阀被链吞掉（本次新发现）** | 13/13 死亡盘面为“4 辆 0 进度内圈车”；唯一单格吃满的 `(0,5) 色1/35` 被链锁（9 局不可点）或 2 格超限（4 局 blocked）；同一盘面 V_无链 点 `(0,5)` 存活、V_原 溢出死亡 | **成立** |

机制一句话：**这条低独占链不是“拖两辆车等色”的链，而是把开局唯一的单格逃生车 `(0,5) 色1/35` 绑到内圈未激活的 `(1,5)` 上；链组本身几乎不进场，却让“4 辆 0 进度车占满暂存”的开局死锁无法用 `(0,5)` 腾位。**

因此：103 的 13 局死亡不能归因于“独占比例低”或“firstPick 早”，而是**链的位置/角色**——绑住了 corner 口径下开局唯一能立即吃满的色 1 车。高独占链 0 死亡也不是因为“独占高”，而是因为它没有动 `(0,5)`（且把两个内圈 0 进度车从开局池里拿走）。at4 方向仍可复现（V_早独占 13.78/11.22、V_共享晚 13.98/14.14 vs 底座 12.98/11.21），但那是“双占位过程压力”，与死亡是两件事。
