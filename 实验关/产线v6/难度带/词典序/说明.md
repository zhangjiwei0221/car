# 构造选择“词典序”规则验证（2026-11-21）

> 用户：“如果一个关卡既可以做成两个锁链，又可以做成 3 个锁链，既可以 2 个冰，又可以 10 个冰，既可以有管道，又可以没有，那我们的产线会做成什么样呢，在没有我干预的情况下”
> 规则见 `README 步 2.7`。本文件用三个底座验证：规则选出来的构造是否落带、早死是否合格，以及规则会不会淘汰底座。

## 2. 验证结论

1. **规则可执行、结果确定**：140 → 2 链 + 9 冰 + 无管；73 → 3 对链 + 9 冰 + 1 根合法化管；图 2 → 整张图淘汰。
2. **早死硬门是最强的筛子**：它单独就能把“带内但不公平”的图 2 挡掉，而三段口径放行。
3. **一个修正**：100 局/档的倒序对 ±4pp 抖动敏感；出现倒序 3 且单次下凹 ≤4pp 时用 200 局/档复核（140 的 A2 由 3 变 2）。已写入 README 步 2.7。
4. **剩余缺口**：图 140 的 A1（2 冰）也通过全部门槛，与 A2（9 冰）只差冰数；规则按用户 2026-11-20 的要求选 A2（≥9 冰）。说明“冰 ≥9”是**用户观感约束**，不是难度约束——它的代价只在倒序噪声上（已用 200 局复核解决）。
