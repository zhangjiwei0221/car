## 0. 结论（先看数字）

1. **顺序是稳健主效应（V1→V2，干净对比）**：仅把队列从 [19,3] 换成 [3,19]，盘面逐格相同，随意 977/4242 **.510/.440 → .643/.650（+13.3/+21.0pp）**，认真 **.933/.947 → .980/.967（+4.7/+2.0pp）**，at4 +2.07/+3.18。两种子合并 +17.2pp（≈6σ）。早死形态改变：lt10 16→10（977），但 lt25 30→35（4242 31→42）——**<10% 的即时早死减少，10–25% 的死亡增加**。
2. **方向单独不足以解释（V1→V3，且与出口格耦合）**：向下后随意 977 **.510→.533（+2.3pp，落在 ±5.7pp 噪声内）**、4242 .440→.530（+9.0pp）；两种子合并 +5.7pp（≈2σ，**边缘/不显著**）。认真 .933→.973（977）/ .947→.937（4242）；at4 **−2.29/−1.61**（压力反而更低）。方向不是独立主效应，且下出口把吐车位从 (0,3) 普通车换成 (1,2) 链条车（与 (1,1) 成链对），方向与出口格无法分离。
3. **内容/壳的合成效应最大（V1→V4/V5）**：队二换成 34（死债色）或 15（生命线色），随意都到 **.800/.803（+29pp 左右）**；但两车所在格变壳，壳从 (1,0) 挪到第 0 行 (0,6)/(0,5)，**“内容”和“被挡格”一起变**，不能把 +29pp 单独记给内容。
4. **V4 是纯安全绳，V5 是“随机安全绳 + 认真陷阱”**：
   - V4（队二 34，壳 (0,6)）：随意 .800、认真 .977、**lt10/lt25 = 0/0**、p1 0/100 死——最稳的安全绳（早死清零），且无认真端代价。
   - V5（队二 15，壳 (0,5)）：随意 .803（比 R 还高 13pp）、但认真 **.860**（比 R −8.7pp、比 V1 −7.3pp），**p1 死亡 7/100 全部在 44.0–46.1%**，认真档 42/300 死中 41 个在 40–50%。
5. **最受控的内容对照是 V4 vs V5**（两个壳相邻、都在第 0 行）：随意几乎相同（.800 vs .803），认真 **.977 vs .860（−11.7pp，≈5σ）**，lt10 0 vs 11、lt25 0 vs 27、at4 18.34/14.82 vs 20.36/19.43、p1 死亡 0 vs 7。**内容对“认真端”有效，对随意端几乎无效**。
6. **没有出现末段（>90%）陷阱**：认真档死亡绝大多数集中在 **40–50%** 的底座中段墙（少数在 10–25/25–40%）；随意档只有 R 的 2–3 局和 V5 的 2 局落在 >90%（样本噪声级）。V5 的认真陷阱也在 **44–46%**，不是深行 2 车那种 92–93% 末段陷阱。锁定“中段要用的色 15”把死亡钉在中段墙，而不是末段。
7. **V1 本身是 2 车的最差组合**：从 V1 出发，单独改顺序、方向、内容**每一个都让随意档上升**。所以“2 车抹掉安全绳”不是某一个因素单独造成，而是 **[19 队首 + 右向 + 队二 3]** 这个组合的交互；不能把 −16pp 归因给三者之一。

## 5. 结论与限制

### 5.1 三因素回答

1. **顺序（V1→V2，干净）**：有稳健效应。仅换队列顺序，随意 **+13.3/+21.0pp**、认真 **+4.7/+2.0pp**。把单色 3 放队首后，管口第一次吐出的不再是晚色 19，即时早死（<10%）减少；代价是 10–25% 死亡增加（lt25 变大）。**顺序能解释 V1 损失的一大半，但不能单独把随意档抬回 R 的水平**（.643/.650 < .673/.670）。
2. **方向（V1→V3，不干净）**：不能确认独立主效应。977 仅 +2.3pp（噪声内），4242 +9.0pp；合并 +5.7pp（≈2σ，边缘）。at4 反而下降 2.29/1.61。且下出口把吐车位从普通车 (0,3) 换成链条车 (1,2)（与 (1,1) 成链对），**方向效应里混着“出口格更难清”**；本实验不能把两者拆开。
3. **内容（V1→V4/V5，合成）**：对随意档看似最大（+29pp），但内容和壳位一起变，不能单独归因。**最受控的 V4 vs V5 显示：内容对认真端有效（.977 vs .860，−11.7pp），对随意端几乎无效（.800 vs .803）**。34（死债色）锁进去 = 纯安全绳；15（生命线色）锁进去 = 随机端安全绳 + 认真端中段陷阱。

### 5.2 哪些对比干净、哪些合成

| 对比 | 判定 |
|---|---|
| **V1 ↔ V2** | **干净**：盘面逐格相同，仅管道 `param` 队列顺序互换；壳位置、方向、两辆车都相同。 |
| V1 ↔ V3 | **方向 + 出口格耦合**：管格/队列/壳相同，但方向必然改出口格；右出口 (0,3) 普通车 17×49，下出口 (1,2) 链条车 31×41（与 (1,1) 33×41 成链对）。 |
| V1 ↔ V4/V5 | **内容 + 壳位合成**：队二车换了，其原格变壳，壳从 (1,0) 挪到 (0,6)/(0,5)；盘面同时变 2 格。 |
| **V4 ↔ V5** | **最受控的内容对比（仍非完全干净）**：两个壳在相邻的第 0 行格（(0,6) vs (0,5)），队二 34 vs 15；但壳格本身不同，内容与“被挡格”仍绑定。 |
| R ↔ V1 | **合成**：车数 1→2、加 1 壳、队二车 3 同时变化。 |

### 5.3 “某个因素单独就能把安全绳翻成陷阱？”

- **没有出现末段（>90%）陷阱**。深行 2 车的 92–93% 死亡没有在开局复现；认真档死亡绝大多数在 40–50% 的底座中段墙（少数在 10–25/25–40%）。
- **严格说，没有“干净的单因素”能把安全绳翻成陷阱**：唯一同时出现安全绳与陷阱信号的变体是 V5，而 V5 是“内容 + 壳位”的合成。若接受合成，V5 的“内容=15”是最接近的答案：随意 .803（比 R +13pp）、lt10 11/1100（随机端安全绳），但认真 .860（比 R −8.7pp，≈3.6σ），p1 7/100 死在 **44–46%**（认真端中段陷阱）。它不是末段陷阱——锁的是中段要用的 15，死亡位置跟着“何时需要该色”走。
- **V4（内容=34）是纯安全绳**：随意 .800、认真 .977、lt10/lt25=0/0、p1 全通。
- **V1 是最差组合**：从 V1 出发，顺序、方向、内容任一单独改变都提高随意档；−16pp 的损失是 [19 队首 + 右向 + 队二 3] 的交互，不能归因给单一因素。

### 5.4 限制

1. V4/V5 只跑了 977 一个种子（300 局/档，95%CI ≈ ±5.7pp）；V2/V3 有两种子。V5 的认真 −11.7pp（V4 对照）约 5σ，方向可信，但绝对值需 4242 复核。
2. 2 车队列必然附带 1 个永久空壳；本实验无法给出“纯队列深度”或“纯内容”效应，只能给“内容+壳位”合成。
3. V3 的方向与出口格（链条对）绑定；若要干净的方向对比，需要找“同格、同队列、两个方向出口都是普通车”的管位（本底座 (0,2) 不满足）。
4. V4/V5 的开局可点降到 5（贴 ArlCheck 下限），硬门仍 PASS；更复杂的底座上可能不允许这种搬法。
5. 只有图 6 C2 一张底座；205/211/18 的复现实验已表明管道三分类不普适（`难度带/复现_管道/说明.md`），本结论不应直接外推。
6. “15 在中段被需要 → 44–46% 墙”是**与死亡位置一致的机制假设**，未用逐步探针单独验证（例如记录 p1 路线首次需要色 15 的进度）。
