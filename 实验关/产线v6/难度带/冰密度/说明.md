## 5. 判定规则（任务给定，扫描前写定）

- **通过** = `|Δ随意| ≤ 5pp` 且 `Δ认真 ≥ −3pp` 且 `|Δ中间| ≤ 5pp`（两种子平均）；
- 随意 = p0/0.1/0.2 均值；中间 = p0.3–0.7 均值；认真 = p0.8/0.9/1.0 均值；
- 不通过则记录越线的格与 param，用墙探针（冰碎步 vs 该车首可点窗口）定位。

## 6. 预测（据 `冰剂量` §6/§9、`冰的靶子` §结论，扫描前写定）

1. **短**：7 块全在累计 2–3 盒时碎，远早于各格首可点（8–24 盒）→ 墙≈0、丢失选项≈0。
   按“冰-冗余车-短 = 严格空操作”，预期 `|Δ随意| ≤ 3pp`、Δ认真 ≥0、|Δ中间| ≤3pp → **通过**。
2. **前置**：构造上冰碎在首可点前 3 盒（类似晚色 C 变体“碎在车可用前”）→ 墙≈0。
   预期 `|Δ随意| ≤ 4pp`、Δ认真 ≥ −1pp → **通过**。风险：以 base 首可点为基准，
   7 块冰同时改变了流程，个别局里某格首可点可能提前 3 盒以上 → 残留短墙。
3. **混合**：短+前置各半，预期介于 1、2 之间 → **通过**。
4. 若失败，最可能出在 (3,3)/(5,0)（首可点率低、中位条件化）或 (2,0)（最短前置缓冲只有 5）。
5. 共同风险：7 块同时下手，即使每块墙≈0，**“可点列表被短暂拿掉”本身会改道 PInterp 的随机流**
   （`冰剂量` §8：单种子 100 局/档的版本间 Δ 有 ±5–9pp 抽样改道噪声），所以判定必须用两种子平均。

  3 块短冰本身（同格、短变体实测）无害。
- 越线的格与 param：**(5,0) p21**（墙 0.60–0.65 步、丢 0.65 选项，两块补充里都最大）、
  **(3,3) p13**（0.35–0.60 / 0.17–0.30）、**(3,5) p10、(3,1) p10**（0.1–0.4 / 0.1–0.2）、
  以及行 2 的 **(2,6) p7、(2,5) p6、(2,0) p5**（0.09–0.48 / 0.04–0.11）。
  共同点：param ≥5 让冰封到累计 4–19 盒，全部落在 25–50% 进度段；同格的 param 3 版本则全部无害。

## 14. 结论

1. **7–9 块能守住纹理标准——但只限“全短”配法。** 短变体 9 块总冰（原 2 + 新 7，param 全 3）：
   Δ随意 **−3.2pp**（977 −1.0 / 4242 −5.3 / 31337 −3.0；三种子 −3.1）、Δ中间 **+1.8pp**、Δ认真 **0.0**。
   7 块新冰都在累计 2–3 盒碎，首可点 8–23 步，墙 0–0.03 步、丢失选项 ≈0——
   与 `冰的靶子`“冰-冗余车-短 = 严格空操作”一致，把密度从 2 提到 9 块仍成立。
2. **“首可点 − 3”的前置配法在 7 块密度下沉。** 前置 −12.7pp（977 −13.0 / 4242 −12.3，两种子同向），
   混合 −10.7pp。每块平均墙只有 0.1–0.7 步，但相位在 4–19 盒（25–50% 进度）：
   随意档新增死亡集中落在 p25_50（977 53→91/80，4242 60→78/79），与 `冰剂量` B/E 的中段签名相同。
   **“碎在车可用前”是 per-block 的性质，不是密度的性质**——7 块同时下手时，冰自身改变流程，
   个别局里车在冰碎前就可点，且多块小墙叠加足以把随意玩家推死。
3. **哪种配法最稳：S-短（param 3）。** 前置、混合都越线；混合的越线额几乎全部由 4 块深前置
   （p10–21）承担（§13）。若确实需要长 param 的“表演感”，本实验数据支持的上限是**极少块**，
   且必须按最终密度重测墙的相位，不能沿用“首可点 − 3”的公式外推。
4. **给造关的规则（可复用）**：
   - 7–9 块纹理冰 = **全部 param 3**，靶子用冗余色车（该色 ≥3 辆、非末两名）、行 ≥2；
   - 想放长 param，先测该密度下每块冰的“冰碎步 vs 首可点步”、并把总冰数降回 1–2 块再验；
   - 判定必须两种子（单种子 100 局/档有 ±5pp 级改道噪声）；本实验短变体补第三种子确认 −3.1。

**对 §6 预测的复盘**：短（预测通过）命中；前置（预测通过）**失败**——低估了多块前置冰在
4–19 盒窗口的叠加；混合（预测通过）**失败**——同一原因。与 `冰剂量` §9 的复盘同型：
把 per-block 的“碎在可用前”当成 density 级的安全条件，忽略了墙的相位与密度叠加。
