# 中段难度杠杆（2026-11-20）

> 用户：“中段难度杠杆做吧”。目标：找出一种让随意玩家**在中段（30–70% 进度）背债死亡、而开局不死**的手段，替换现在“难度全在开局债务”的造法。
> 底座：`140_去开局链.json` = 140 成品关去掉两条开局链（保留 2 块表演冰）。**基线随意 .987、早死 0/126**——这是“没有开局陷阱”的干净底座。

## 2. 结论

1. **v6 现有的障碍全是“开局杠杆”**：链必须在第 0–1 行才咬（中段链 −2pp），管道/冰对中段几乎无感（≤6pp）。这不是参数问题，是机制问题——中段玩家可选面大，任何单格障碍都能被绕开；开局可选面小，一绑就出债。
2. **140 的“中段死亡”不是中段杠杆造的**：它同样是开局链，只是它的链色组合让债务在 40–77% 才爆。也就是说“难度位置”由**底座的颜色结构**决定，不由障碍位置决定。
3. 因此“中段难度杠杆”的正确形态可能是：**选底座 + 选链色组合，让债务的引爆点落在中段**——需要一个“链后死亡位置”的筛选器，而不是新的障碍类型。

## 4. 给下一步的判据（已部分实现）

- **选底座的可执行判据**：先按标准配方加链，再跑 `BaitLocator --early 0.1`——早死 <20% 的底座进入下一步（140 = 0/126、图 73 = 0–2/95–105；图 2 = 92%、图 3 = 98% 直接淘汰）。
- **1px 小色的合法处理**：把 1px 车放进管道（`build_natural_pipe`，队列 1 格）——管道格 count=0，`LayoutScore` 不再报 ≤5px，守恒/可解不受影响（图 73 实例）。
- **中段微调旋钮**：中层冰的 p14–18 是真实墙（图 73：.72→.61）；p16–20 过冲（.553、倒序 3）。
