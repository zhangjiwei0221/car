### 3.1 曲线形状

- 1→2：0.675 → 0.581（**−9.4pp**，突然下台阶）。
- 2→3：0.581 → 0.594（**+1.3pp**，噪声内，不降）。
- 3→4：0.594 → 0.920（**+32.6pp**，大幅回升，比 C1 还高）。
- p=0.1：0.756 → 0.708 → 0.719 → 0.954（1→2 **−4.8pp**，跌幅只有随机玩家的一半左右；
  3→4 同样大幅回升）。
- **不是平滑下降**：第 2 条链造成一次下台阶，第 3 条链无效，第 4 条链把关卡显著变简单。

### 3.2 死亡进度（失败局的 deathProgress）

| 变体 | 死亡局数 | 中位 | p10–p90 | 读法 |
|---|---:|---:|---|---|
| C1 | 390 | 0.232 | 0.229–0.240 | 全部死在进度 ~23% |
| C2 | 503 | 0.167 | 0.167–0.174 | 死得更早，且更集中 |
| C3 | 487 | 0.167 | 0.167–0.849 | 双峰：多数早死，少数晚死 |
| C4 | 96 | 0.803 | 0.745–0.912 | **早死陷阱消失，只剩少量晚死** |

机制：前几条链抽掉开局选项，随机玩家在进度 17%–23% 就无路可走；g4 加在第 2 行中段，
改变了早期合法选项链，反而让随机玩家绕开了早死陷阱（只剩 8.0% 的局在 75%–91% 晚死）。

## 5. 结论（图 211）

1. **不是剂量-反应式平滑下降。** 1→2 掉 9.4pp，2→3 不降反升 1.3pp，3→4 回升到 0.920。
   p=0.1 是同形曲线：0.756 → 0.708 → 0.719 → 0.954。
2. **p=0.1 玩家比随机玩家抗得多**：同一组链随机掉 9.4pp 时，p=0.1 只掉 4.8pp。
3. 熵：C1 1.496 → C2 1.426 → C3 1.424 → C4 1.447，**加第 2 条链后跌破 1.45 门槛，
   之后一直在门槛附近**；不是单调下降。
4. freeP3：C1 0.333 → C2 0.043 → C3 0.022 → C4 0.044，**第 2 条链起会玩压力被打到近 0**。
5. 棘轮 / 可通关 / 守恒 / 开局全部通过；无失败变体。
6. **落在 0.55–0.75 的变体：C1（0.675）与 C2（0.581）；C3（0.594）也在带内。**
   C4（0.920）不在带内。
