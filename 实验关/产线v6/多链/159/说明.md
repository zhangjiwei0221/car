# 图 159 · 多链叠加实验（2026-11-13）

> 目的：159 的单链版**无效**（单链随机仍 1.000）。本实验在它上面继续叠加两连锁，
> 看多链能不能把这张“容错余量很大”的图救成有压力的关。
> 口径：`--mode a --ref corner`；`useSlotStart:true`、`instantChain:false`（AGENTS 红线 2）。
> 只改锁链（`type:5`、同组 `param`），不改容量 / 颜色 / 目标图 / 冰 / 问号 / 管道。

### 3.1 曲线、死亡与插值玩家

- C1 随机 1.000，与单链版“无效果”一致。
- C2 随机 0.993（相对原关 −0.7pp，噪声内），死亡 8/1200，全部死在进度 0.878–0.885（**晚死**，
  不是开局陷阱）；链组被拿率 g1 0.993、g2 1.000。
- C3 随机 0.923（相对原关 −7.7pp），死亡 92/1200，中位进度 0.879（p10–p90 0.857–0.886）。
- C4 随机 0.881（相对原关 **−11.9pp**），死亡 143/1200，中位进度 0.880（0.836–0.886）。
  这是 159 上第一次跨过“下降 ≥8pp”的判定线，但**死亡仍然集中在进度 ~88%**（晚死）。
- freeP3：0.333 → 0.340 → 0.217 → 0.244；熵：1.575 → 1.549 → 1.318 → 1.317。
  第 3 条链起 freeP3 才开始降、熵跌破 1.45，但仍在 0.22–0.24 的“偏烦”区间。
- p=0.1：1.000 → 0.998 → 0.985 → 0.892。C2/C3 时插值玩家几乎不受影响
  （0.998/0.985），但 **C4 掉到 0.892，与随机 0.881 几乎相同**——第 4 条链造成的晚死，
  连“稍微贪心”的玩家也躲不掉（与 211 的 C2 形成对照：211 的下降主要打在随机玩家身上）。

## 5. 结论（图 159）

1. **多链能救 159，但要 3–4 条才见效。** 随机通关 1.000 → 0.993 → 0.923 → 0.881：
   C2 基本无感（−0.7pp），C3 开始降（−7.7pp，略低于 8pp 线），**C4 首次达标（−11.9pp）**。
2. 曲线是**渐进**的（不像 211 那样 1→2 突然下台阶、3→4 又反弹），每多一条链多掉几百个基点。
   p=0.1 同向：1.000 → 0.998 → 0.985 → 0.892；C2/C3 插值玩家几乎无感，C4 才与随机同步下跌。
3. 机制与 211 不同：159 的失败**几乎全部是晚死**（C3/C4 死亡中位进度 0.879/0.880，
   p10–p90 约 0.84–0.89）。不是“开局选项被抽掉”，而是链组在中后段把两辆车绑在一起、
   在接近通关时卡死。所以它降的是随机通关，但 freeP3 仍有 0.22–0.24（会玩的人不背债），
   熵却掉到 1.32（选择空间变窄）。
4. 棘轮 / 可通关 / 守恒 / 开局全部通过；无失败变体。
5. C4 的 0.881 仍高于 0.55–0.75 目标带；要进带内还需再加链或换更深的位置（本实验未做）。
