# 三连锁形状对照（2026-11-13）

> 目的：在同一张关 `ZC_115_p47_win85` 上只加 **1 组三连锁**，比较纵向 / 横向 / 直角 × 中段 / 开局 六种组合。
> 口径：`--mode a --ref corner`；`useSlotStart:true`、`instantChain:false`（与 `Solvable_v1` / `ChainRatchetCheck_v1` / `PopulationSim_v1` 一致）。
> **硬门：每个变体必须 Solvable 宽 8 可通关 + ChainRatchetCheck PASS（0 flags / 0 traps）**；FAIL 就按候选顺序换下一组格子。

## 4. 三个问题的答案

### Q2 形状有没有差别？
**不能把差异归给形状本身。** 同位置三种形状用的格子/颜色不同（棘轮强制换格），差异主要由三件事决定，而不是“纵向/横向/直角”这个几何标签：

1. **链首次可点进度**（位置 > 形状）：中段 0.75–0.91，开局 0–0.74。
2. **被链锁住的是哪些颜色**：锁早/中段需求色（如 L_中段锁 24）会抬高早期死亡；锁本来就晚的颜色（H_中段锁 7/1/1）几乎无影响。
3. **fill（3 格占暂存的步数）**：H_开局随机 fill 6–7 → 通关掉 5.9pp；H_中段/ L_中段 fill≈0 → 通关接近或高于底座。

同锚点证据（唯一能控制格子的对照）：开局锚点 (0,0)，纵向 PASS、横向 FAIL、直角 FAIL——同一位置换形状就能从“能用”变“不能用”，说明形状至少决定了链的可点时机/锁哪些格，但这不是“形状好坏”的稳定排序。

### Q3 位置有没有差别？
有，但方向随形状反转：

- 纵向：开局 0.875 > 中段 0.793（+8.2pp）
- 横向：开局 0.773 < 中段 0.860（−8.7pp）
- 直角：开局 0.905 > 中段 0.787（+11.8pp）

规律不是“开局更好/中段更差”，而是：
- **开局就亮、且随机一开局就抓**（H_开局）→ 3 格立刻进场、fill 6–7，最掉容错；
- **开局亮但会等到能收的时候再拿**（V_开局/L_开局）→ 链变成“延迟解锁的像素银行”，反而略升容错；
- **中段/深位才亮**（H/L_中段）→ 大多数随机局活不到那时，链近乎惰性；锁住早需求色时则小幅掉。

### Q4 有没有“会玩的人仍能过、随机明显掉”的组合？
有，但幅度不大：
- **H_开局**：随机 0.773（−5.9pp），free-first/max-eat/small-debt 全通，solver 通；随机局 99.3% 一开局就抓链，背 3 格 6–7 步。
- **L_中段**：随机 0.787（−4.5pp），会玩全通，fill≈0；掉容错来自链锁住的颜色（24/7/1）在 0.91 前不可完成。
- **V_中段**：随机 0.793（−3.9pp），会玩全通，但会玩 fill=13（三格背很久）。

作为对比，同底座两连锁是 −17.0pp；**三连在“能过棘轮”的落点上没有再现那个量级**。

## 5. 结论

1. **三连可用，但只能用在少数落点**：14 组普通车三格里只有 6 组过棘轮（且 1 组还过不了 Solvable 8）。任务给的示例 (3,0)(4,0)(5,0) 直接 **Solvable 宽 8 不过 + 四条策略路线全死**。
2. **形状没有稳定的独立效应**；决定成败的是“链何时可点 + 锁哪些颜色 + 3 格要背多少步”。同位置换形状可以从 PASS 变 FAIL，但这不能外推成“某形状更好”。
3. **位置效应也不稳定**：开局纵向/直角略升容错，开局横向明显掉；中段横向/直角接近底座，中段纵向掉。**没有“三连一加就变难”的普遍规律。**
4. **三连作为难度旋钮偏弱**：最大掉幅 −5.9pp，且会玩路线全通、fill 常常 0–2；真正“占 3 格”的成本只在开局立即被抓时体现（H_开局 fill 6–7）。
5. **取用条件苛刻的直接证据**：同锚点 6 组只有 1 组 PASS；V_中段示例让最小路线也死（`solvable=false`，bestPx 1466/1600）。这不是“会玩的人能过、随机掉”的理想加压，而是**大部分落点直接把关卡做坏**。
