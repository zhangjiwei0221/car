产线 v4（三面墙 / 仅底边出口）作为分组4 的产线版本，**停止**。第一关 v3 虽然按 G4 硬门口径通过，但没有拿到可用的真人试玩结论；试玩入口本身也不成立（棋盘大面积黑块 + 色库口径不一致 + 编辑器模式口径直到最后才对齐）。

## 3. 失败原因（实测）

1. **试玩入口不成立：棋盘全是黑块。**
   - v3 是 7×7，只用了 0–3 行，`29/49` 格为空 → 渲染出来大半是黑块。
   - 压缩到 4×7 可保留 G4 硬门（指标不变），但用户已决定停止，未再继续。
2. **色号口径不一致。**
   - 关卡来自正常关（老 34 色库），12 色里有 8 色 >21（24/26/27/28/29/30/31/33）。
   - 编辑器若按官方 0–21 色库渲染，这些颜色会显示为黑块；需要老色库/自动识别或先做色库转换。
3. **编辑器“仅底部入口”口径长期不对。**
   - v637 及以前是 **ring（圈序）**；需求要求“内层像素不受影响、原消除逻辑不变”，应为 **corner（左下角）**。
   - 直到编辑器 v638 才对齐；此前所有“仅底部入口”试玩都不是分组4 口径。
4. **机制收益未验证。**
   - 三面墙的目的是让玩家从底部开始解、先形成入口路径；但没有任何有效试玩反馈证明这一点成立。
   - 唯一通过的 v3 仍是点击结算口径好、PlayerSim 0 复活 N，真实玩家可恢复性不成立。

## 5. 不再做的事

- 不再继续分组4 的关卡生成、修复、试玩。
- 不再以 v4 产出候选上线。
- 如未来重开“墙/底边入口”机制，必须：
  1. 先确认编辑器/客户端色库口径；
  2. 先做紧凑棋盘（车数 ≈ 格数），不要留大片空格；
  3. 编辑器口径先对齐（bottomOnly=corner）；
  4. 再做真人试玩，指标只做护栏。
