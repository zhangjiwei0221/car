## 2. 结论

1. **`C0@buffer<5 > 0` 只在 L2/L5 出现**（两张都是高流失；L5 首次 C0 在第 6 步、开局只有 3 辆）。这是“劝退型”高流失的干净信号：所有低流失关都是 0。
2. **`F0@buffer≥3 ≥ 3`（或 `maxF0 ≥ 3`）也只在 L2/L5 出现**：L2=5、L5=3；L3/L12/L10 是 2，低流失 L9/L13 也是 2。阈值 3 能分开“严重恢复稀缺”。
3. **`OpeningCheck` PASS/FAIL 不能单独当门**：
   - 高流失 L7 **PASS**（mid 87%，长磨型，问题不在前段）；
   - 低流失 L6/L10/L13 **FAIL**，但只是 1–2 个 F0@buf3，没有 C0。
4. **L3/L12 与低流失 L10 重叠**（F0@buf3=2、maxF0=2）：不能只靠前段分开；需要结合 mid/tol/长磨等分桶。
5. 高流失不是单一机制：
   - **劝退型**：L2/L5（C0 + F0≥3 + 开局窄）；
   - **长磨型**：L7（OpeningCheck 过、mid 87、tol 19）；
   - **极端曲线型**：L3（mid 43、tol19）、L12（mid 17、avgF 低）。

## 3. 建议的试用门（在点击结算口径上）

**硬失败（当前证据支持）**：

- `C0@buffer<5 > 0`：存在“所有候选都 0 消除”的纯被迫步；
- `F0@buffer≥3 >= 3` 或 `maxF0 >= 3`：高压时恢复窗口严重稀缺。

**标记/排序（不作单独判死）**：

- `F0@buffer≥3 == 2`、`openM <= 3`、`avgF` 低；
- `mid` 极端（<20 或 >80）、`tol` 落在两端；
- `policy0=Y` 但只有 1–2 条策略能过（策略广度低）。

**分桶**：劝退型 / 长磨型 / 极端曲线型分别用不同的后续检查，不能用一个总分。
