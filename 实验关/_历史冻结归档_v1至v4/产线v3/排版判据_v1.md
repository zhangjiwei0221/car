# 排版判据 v1（2026-11-06，用户口述 → 量化草案）

> 用途：产线 v3 的第三张证书「排版合理」。
> 原则：**硬否决只放“一眼就不行”的；其余记软分，报告出来，不悄悄淘汰。**
> 状态：阈值是草案，待用 `候选_标记用` 的 8 张反例校准确认。

---

## 1. 用户原话（7 条）

1. 大量色块的车被切成 3px、5px 等，不合理，也卡不住人 → **否决**。
2. 黑墙可以存在，但让局面变成单选题 → **否决**。
3. 白色车排成一行、蓝色排成下一行 → **直接不行**；这样基本没排版，也排不出决策和卡点。
4. 整个关卡没障碍：目标是卡点，不是障碍数量；有障碍会好看一点，但**不加障碍能做出卡点是不是也可以？**（待回答，见 §4）
5. 锁链组不在正交相邻位置 → **直接 pass**（规则问题，不能改规则）。
6. 问号盖在链组伙伴上 → **问题不大**（冰块也可以在锁链上），生成时再看，不作硬否决。
7. 棋盘挤成 1 格宽迷宫 → 基本是黑块太多的锅，归到第 2 条。

---

## 2. 硬否决（任何一条命中 → 不进候选）

| 编号 | 判据 | 建议阈值 | 怎么算 |
|---|---|---|---|
| **L1 碎车（上下文）** | 背景/大像素色被切成个位数车 | 该色总像素 ≥100 且出现 **<8px** 车 → 警告；同一大色出现 **≥3 辆 <8px** → 否决。本身像素很少的颜色，小车不算碎车 | `spools[].count` + 该色总像素 |
| **L2 半成品排版** | 整行/整列一种颜色，像半成品 | **≥2 行/列整行同色** → 否决（半成品特征）；3–4 连同色只记软分，关卡合理就不否决 | 行/列扫描 + 同色 2D 连通块 |
| **L3 单选题** | 黑墙把局面压成单选择 | **最长连续没得选 >2** 或 **没得选占比 >50%** → 否决；黑墙本身不否决 | 决策指纹（`Decision_v794` / PlayerSim） |
| **L4 锁链不正交** | 链组不在正交相邻 | 任一链组存在非正交相邻成员 → 否决 | `chainGroups` / `type 5` 坐标 |
| **L5 目标图不可辨** | 1–2px 打碎、画面认不出 | 用户已否决，沿用 | 目标图连通块/主体识别 |
| **L6 单格迷宫** | 1 格宽走廊逼成单行道 | 若导致 L3 命中 → 按 L3 否决；否则只记软分 | 棋盘空格连通宽度 |

> 黑墙、1 格迷宫**本身不是否决项**；只有当它们把局面变成「单选题」时才否决。这和第 2、7 条一致。

## 3. 软分（只报告，不淘汰）

| 项 | 说明 |
|---|---|
| 车尺寸分布 | min / 中位 / max；<8px 数量；>80px 数量 |
| 同色聚簇 | 最长同色连（2–3 连记软分）；同色连通块 4–5 辆 |
| 边框/内部大小车比例 | 对照 `--edge-big-ratio` 的历史偏好 |
| 黑块 | 数量、黑块行/列最长连、黑块比例 |
| 障碍 | 各类型数量、链组正交性、问号是否在链组伙伴上（**只标记**） |
| 棋盘空间 | 空格率、最窄通道宽度 |
| 目标图可读性 | 主体数、色块数、包围色比例 |

**报告格式**：每项给数值，不给总分；总分只会掩盖问题。

---

## 4. 「没障碍也可以吗」

**可以，但要有补偿条件。**

- 障碍不是配额。目标是卡点，不是障碍数量；零障碍关只要决策指纹和体验证书过，就能出货。
- 但零障碍关必须额外满足一条：**至少有一笔可读的债/卡点**（进入步、释放步、可见信号），否则它只是「大车小车排一排」，没有节奏。
- 证书里显式写 `obstacleFree: true`，让你一眼看到「这关没障碍」，而不是悄悄放过去。
- 如果零障碍关的决策指纹和加障碍版一样、但观感更平，再考虑加障碍作为**厚度**，不是作为「合格条件」。

**这与你指出的反例一致**：E/F/G 是碎车 + 同色行，H 是碎车；A–D 虽然数据上不触发 L1/L2，但**你判定它们是垃圾，不能当底线**。排版判据只负责「不出现明显半成品」，不负责「好看」；真正的参照是 G2 那 10 张。

**已确认的口径（2026-11-06）**：
1. 同色 3/4 连不单独判死；只有「整行/整列一种颜色、≥2 行」这种半成品特征才否决。
2. 碎车看上下文：大像素色（≥100px）出现 <8px 车是警告；同一大色 ≥3 辆 <8px 才否决；本身像素少的颜色，小车正常。
3. 同色 2×2 不硬判，记软分。
4. 排版是「不出现半成品」的底线，不是「好看」的标准；A–D 不是底线，G2 是参照。
