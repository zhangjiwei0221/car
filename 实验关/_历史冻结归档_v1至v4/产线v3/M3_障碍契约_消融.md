## 4. 结论

1. **障碍不是「一类一个作用」**：同样是冰，r0c0/r1c1 是 0 复活硬门，r1c4 是峰值硬门，r0c2 是中段/容错。
2. **锁链是中段压力的承重**：去掉后仍能通关，但中段 0%、容错 9/20——「能通但没拉扯」。
3. **问号在当前关卡是装饰**：对 oracle 和 visible 都没有 Δ；如果要它有用，需要让它隐藏的车辆真正影响决策（当前 r6c2 30:17 可能一直没被选）。
4. **障碍之间有交互**：去冰+去链后，0 复活仍通关——单独去冰会死，是因为链组还在；契约必须成组评估。
5. **管道的契约还没测完**：需要容量重分配才能消融。
