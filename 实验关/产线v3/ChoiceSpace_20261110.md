**读法**：

1. **`entropy`（选项后果熵）比 `M`、`tol` 都强**：选项后果越多样，流失越低。这最接近“选择性/可学习性”。
2. **M/C/D 主要量“选项多少”**：M 高通常流失低；overload 反而与低流失相关，说明“选项多”不是问题，“没得选/选项都一样”才是。
3. **`F`（不加债选项）单独很弱**：玩家要的是“有差别的选项”，不是“安全但无聊的选项”。
4. **`fakeChoice` 单独不预测**：G2 2–13 里完全同后果的步不多；更常见的是“选项有差别，但差别不够/看不到”。
5. **L3/L7/L13 是例外**：L3 entropy 1.43 但流失36.7（中段/曲线问题）；L7 1.42 但长磨；L13 1.39 但漏斗末段、样本小。说明选择空间不是唯一因素，仍需分桶。

## 4. 结论 / 下一步

1. **tol 不能当主指标**；ChoiceSpace 的 `entropy` 是更强的设计侧信号。
2. 高流失关分两类选择问题：
   - **没得选**：L2（M3.4、entropy1.01、forced2）、L5（entropy1.22、fake6、forced3）；
   - **选项有但后果趋同/看不清**：L10（M7、entropy1.28）、L11（M4.6、entropy1.20）；
   - L3/L7/L12 更多是曲线/长磨，不是选择数量。
3. 组 3 的改法：
   - L2/L5：加真实选项/恢复窗口；
   - L10/L11：让选项后果更可区分（目标图去碎、调色、减少同质选项）；
   - L3/L7/L12：修中段/长磨，不要只加选项。
4. 试玩候选优先：
   - **00005_v27_w14_m8**（选择空间最好）
   - **00005_v27_w14_m10**（更干净）
   - **pin15_w10_m6**（不同图源，中段56）
5. 注意：n=12，entropy 与 M 有共线；需要更多关卡/线上数据验证。
