# 关卡00001 试搭：负结果（2026-11-08）

> 图源：`关卡/关卡00001_原图044-015-014-046_整体单色_38x38.txt`（38×38、17 色、1 个边框色 28）。
> 做法：5 个 `28` 开场（40/40/40/40/39），其余颜色做冰/链/管道。12 版迭代在 `迭代/`。

## 最好的一版（v3）

- `ArlCheck_v793`：峰值 **4** ✅、开局 **5** ✅、容错 **15/20** ✅、排版 hard0/warn0 ✅、0 复活 ✅。
- **中段 at3 只有 1 步（3%）** ❌：噪声求解器的 20 条路线里，绝大多数车都能当场吃完，buffer 上不去。
- 加冰（6 个位置 × 6/10/14 三档）、加第三链组、加重管道队列都没把中段抬起来；加大会 `33/4/13` 又会让最小路线失败。

## 结论

`00001` 的颜色拓扑是「边框色 28 + 一圈很早就可达的内饰色」，没有 F2 那种「某色在中期仍 0 可达」的窗口；语法可以做出通关和峰值，但做不出中段债务。**不再在这张图上耗**，改用 `00005`（4 个边框色 + 4 个主体），见 `M4_新图证书_关卡00005.md`。

**保留 v3 作为「峰值/通关/排版都能过，但中段不可造」的证据**；其余版本在 `迭代/`。
