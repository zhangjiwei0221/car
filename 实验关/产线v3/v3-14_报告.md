# v3-14 报告：preferSmallDebt——策略族加一员，2 复活 88→103

> 日期：2026-11-07
> 改动：`playersim.js` 新增 `preferSmallDebt`（默认关）；`PlayerEngineCheck --prefer-small-debt` 把它作为策略族的一族成员（false + true 都跑，任一通关算可通）。
> 结论：2 复活通关 88→103；0 复活 15→16；策略有改善，但 0 复活仍低，剩余是结构问题。

---

## 1. 规则

只在候选 **全部不可消** 时生效：

```
score -= cell.count * 0.1
```

可消候选的行号偏好保持不变。这样「小债」优先，而不是「第 0 行」优先。

## 4. 结论

1. **`preferSmallDebt` 是有效的策略改进**：2 复活 88→103（+15），0 复活 15→16（+1）。
2. **但不能替换默认策略**：单独用它会把 0 复活从 15 降到 11（v3-15 前一版扫描）；作为策略族成员（两种都跑、任一通关）才是只增不减。
3. **0 复活仍然只有 16/110**：剩下的 94 张不是「策略不够好」，是结构问题（reach/capacity/timing）；策略族再扩也救不了。
4. 这符合 v3-08 的判断：fatal 时序是结构量；策略只能改变「谁先死」，不能创造可达像素。
