## 5. 产线 v3 怎么生成这些关卡

### 5.1 先说清：G2 2–13 不是 v3 生成的

- 它们是 **产线 v1 的上线关卡**（工作日志 §1031：②=产线v1上线关卡，①=最初版本）。
- **产线 v3 不是生成器**：v1 出候选，v3 负责解释、筛选、修复、出证书（`README §2`）。

### 5.2 当前 v3 的生成/修复路径

| 环节 | 工具 | 做什么 |
|---|---|---|
| 候选生成（v1） | `JointSearch_v799` | 目标图 TXT → 切车/构建/障碍 → 多比例/拓扑/处方搜索 |
| 配方重建 | `BuildFromRecipe_v1` | 目标图 + cars/black/obstacles/pipes → 关卡 JSON（容量守恒校验） |
| 候选变体 | `M5Build_v5` | base recipe → 点击结算路线 → window reach → 调容量/链 → 重建 → ArlCheck/PlayerEngine/Layout |
| 批量 | `M5Batch_v1` | 4 base × window/margin 网格 → 新六项检查 → 排序 |
| 诊断/修复 | `WindowPlan_v2`、`CapacityPlan_v2`、`ReachPlan_v1`、`MoveAdvisor` | early/never、容量、可达、单点修复 |
| 障碍/拓扑 | `RxPrescribe_v796`、`TopoSearch_v797`、`ForceSeq_v795`、`LayerByEdge_v754` | 冰/链/管道、黑块、车序、分层 |
| 验收 | `ArlCheck_v793`、`PlayerEngineCheck_v1`、`OpeningCheck_v1`、`ClickSettleEngineCheck_v1`、`ClickSettlePolicyCheck_v1`、`ChoiceSpaceCheck_v1` | 19 项 + 玩家引擎 + 前段 + 点击结算 + 选择空间 |

### 5.3 新补的关键缺口：LevelToRecipe_v1

`03_工具/正式版/LevelToRecipe_v1.js` 把现有关卡 JSON 反推成配方：

- `spools[r][c]` → `cars`（id>0）/ `pipes`（type 11–14）/ `obstacles`（type 5/6/7/数组/q）/ `black`（id≤0 非管道）。
- 12 关 round-trip：`blocks/spools` 深比较全部一致（L10 仅 `q:false` 无关字段差异）。
- 有了它，v3 才能对 G2 2–13 做“配方级修改 → BuildFromRecipe → 新检查”。

### 5.4 组 3 的具体生成路径

1. 对目标关跑 `LevelToRecipe_v1`，得到 recipe。
2. **恢复/容错变体（L2/L5）**：
   - 在 recipe 里加/挪车、拆链、改冰/管道；保持每色像素总数守恒；
   - `BuildFromRecipe` 重建 → 新检查。
   - 注意：`M5Build_v5` 只调容量/链，**不会自动加缓解车/补开局**；这部分需要手工改 recipe 或新写 `RecoveryBuild`。
3. **曲线/长磨变体（L3/L7/L12）**：
   - 调同色容量分配、链/冰/管道位置，把 mid 拉回 40–75、缩短耗时；
   - 可用 `M5Build_v5` 做容量/链搜索，再人工选。
4. **目标感变体（L10/L11）**：
   - **只改 `blocks`**：保持每色像素数不变，把碎块合并成大块/主体轮廓更清晰；
   - `spools` 可以完全不动（每色总数不变，容量守恒仍成立）；
   - `BuildFromRecipe` 重建 → 新检查。
5. **撞色变体（L10/L13）**：
   - 对 `blocks` + `spools`/obstacles/pipes 做**同一套颜色置换**，保持每色像素数和车容量；
   - 选一组 RGB 距离更大的映射；如果 34 色库找不到全 ≥85，就最大化最小距离/最小化相邻近色对。
6. 每个变体跑：`ChoiceSpaceCheck` + `ClickSettlePolicy` + free-first `OpeningCheck` + `ArlCheck` + `PlayerEngine` + `Layout`；通过后打包进组 3。

### 5.5 当前缺口

- 没有“恢复窗口/补开局”专用 builder（只能手工 recipe 或新写）；
- 没有目标图去碎工具（可写一个保持每色计数的重排器）；
- 没有调色板置换/撞色优化工具；
- 漏斗位置混杂：组 3 必须与组 2 同序列、只改目标关。

## 6. 复现

```bash
# 反推配方
node 03_工具/正式版/LevelToRecipe_v1.js <关卡.json> --out <配方.json>
# 重建
node 03_工具/正式版/BuildFromRecipe_v1.js <配方.json> --out <重建.json>
# 新检查
node 03_工具/正式版/ChoiceSpaceCheck_v1.js <关卡.json>
node 03_工具/正式版/ClickSettlePolicyCheck_v1.js <关卡.json>
node 03_工具/正式版/OpeningCheck_v1.js <关卡.json> --click <free-first click.json>
```
