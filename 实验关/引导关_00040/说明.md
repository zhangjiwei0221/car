`关卡/关卡00040_原图018-045-044-047_分图4色_40x40.txt` —— **官方原图，一像素没改**。

四个主体：左上面包/香肠、右上纸杯蛋糕、左下饮料杯、右下青绿杯子。

## 新指标：伤害阶梯（DamageCurve_v739）

定义：**某象限的“独占色”（只在该象限出现的颜色）被消掉的比例**，
首次达到 10% 的步数 = 该主体“被咬”的时刻。

> 为什么不用“颜色首用”：共享色会被多个象限共用，吃它时像素从哪来不确定，
> 会造成“首用 ≠ 该主体被破坏”（216 那关就踩过这个坑）。

## 结果

| 项 | 值 |
|---|---|
| 容量 | **1600 = 1600** |
| 页面 | 峰值 4、**at4=23、run4=13**、道具 0 |
| 全知 | 46 步；窗口 6–32:4、34–36:4、39–41:4 |
| 障碍 | 3 组链（7 格），无冰、无黑块 |
| 审核 | 仅前期卡点（允许） |
| **伤害阶梯** | **左上 1 步 → 右上 7 步 → 左下 13 步 → 右下 35 步（跨度 34）** |

**这是第一张“官方原图 + 真实引导 + 有压力”的关**，而且是筛选出来的，不是硬拼的。

## 关键发现

官方图里本来就有“天然的伤害阶梯”——我扫了 60 张，其中
`00040`（1→17→24→35）、`00050`（10→16→30→44）、`00048`（12→14→46→48）
等图天然就有先后。

**所以引导不必改图**：先在官方图里挑“阶梯已经拉开”的，再用构建器加压即可。
