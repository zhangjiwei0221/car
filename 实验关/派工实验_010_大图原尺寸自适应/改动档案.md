## 1. `SplitLevel_v722.js`（第 407–425 行）：`--stagger-cap` 动态错配

**改前**：
```js
const delta = Math.min(8, Math.max(0, lo.count - 11), Math.max(0, 34 - hi.count));
```
**改后**：
```js
const avgC = Math.round(arr.reduce((s, x) => s + x.count, 0) / n);
const loMin = avgC > 26 ? Math.max(16, Math.round(avgC * 0.52)) : 11;
const hiMax = avgC > 26 ? Math.round(avgC * 1.48) : 34;
const maxDelta = avgC > 26 ? Math.round(avgC * 0.42) : 8;
...
const delta = Math.min(maxDelta, Math.max(0, lo.count - loMin), Math.max(0, hiMax - hi.count));
```
- `avgC<=26`（32×32/35×35）→ 11/34/8 与原值完全相同。
- `avgC>26`（40×40~55×55）→ 50+50 可错配成 28 / 72。
- **零影响实测**：`11.txt`（32×32）改前/改后 `SplitLevel` 输出网格逐格一致（49 车，max 38px）。

## 5. 施工发现

1. **4 个常数确实是根因**：`7×8` + 动态错配 + 视线阈值比例化后，55×55 首次拿到 B 档 `allPass`（`G1_4`）。
2. **大图天然偏硬**：`G1_13` 降到 `Gear -2` 仍是 `hum .183 / mid .525`；5 槽 + 56 格 + 50px+ 大车本身极难。真要 B 档，可能得允许“大图 6 槽”或更激进拆大车。
3. **死车未除**：整色只有 2 辆车的颜色仍会产出 100–132px 单色大车（如 `G1_4` 色 14 的 132px）。下一步建议对大图调小 `boxSizeMax` 或允许同色切 3 车。
4. **AutoGear 混合信号盲点**：`rand` 偏易 + `hum` 偏难时按“偏松”先判，升挡方向可能反（`G1_294`：rand .792 但 hum .15）。
5. **耗时**：单 style 10–20 分钟（55×55 的 40 局 × 6 p × 2 模型 + 30 轮爬山），一关 6 style + 2 轮换挡 ≈ 2–3 小时；4 关并行也没压进 2 小时——下次开跑前应先报时间预算。
