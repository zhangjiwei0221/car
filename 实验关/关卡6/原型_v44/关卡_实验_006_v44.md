# 006 · v44：用管道顶替一条锁链，平台不变

## 思路

v42 的 8 条链里，有些只在“按住释放”。逐条测试“把这条链换成管道”
（管道格阻挡 + 车进队列），寻找**页面曲线完全不变**的替换。

结果：**组 3（`(4,1)+(4,2)` 15 色对）换成 `(4,1)` 管道后，页面指标一模一样**。

## 结果

| 项 | v42 | v44 |
|---|---:|---:|
| 锁链组 | 8 | **7** |
| 管道 | 1 | **2** |
| 页面口径：峰值 / 停在4的步数 / 最长连续4 | 4 / 14 / 5 | **4 / 14 / 5** |
| CLI 口径：步数 / 峰值 / 窗口 | 37 / 4 / 3 段 | 38 / 4 / **3 段**（14-18:4、20-24:4、30-33:4） |
| 产品审核 | ✅ | ✅（前期 0.0 / 后期 4.0） |
| 全知免费步 | 11（30%） | 13（34%） |
| 守恒 / 往返 / 连锁体检 | ok | ok（7 组） |

页面曲线里 4 的位置没变：15–18 一段、21–25 一段。

## 结论

管道可以顶替“按住型”锁链，曲线不变、链数下降。
下一步继续找第二组可替换的链（实测组 11 → 管道时 at4 会从 14 掉到 10，暂时不动）。
