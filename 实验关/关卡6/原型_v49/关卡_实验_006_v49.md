# 006 · v49：只交换“非锁链格”的开局重排

## 做法

写了一个开局重排搜索（`Search006Opening_v716.js`）：
- 只交换**不在锁链组里、也没有冰**的车（28 辆可选），链组与冰的位置完全不动；
- 每次随机换 2–4 对，用页面口径筛：可通关、峰值≤4、道具0、at4≥12、run4≥6；
- 在满足条件的解里，选“免费前缀最短、at4 最高”的。

## 结果（v47 → v49）

| 项 | v47 | **v49** |
|---|---:|---:|
| CLI 步数 / 峰值 | 39 / 4 | 39 / 4 |
| CLI 窗口 | 2 段 | **4 段**（14-17:4、19-25:4、27-31:4、34:3） |
| 页面：at4 / run4 / 峰值 | 13 / 7 / 4 | **14 / 7 / 4** |
| 审核 | ✅ | ✅（前期0.0/后期4.0） |
| 免费前缀（beam20） | 15 步 | **14 步** |
| 障碍构成 | 6链+2管+3冰+2问号+2黑 | 同（未动链与冰） |
| 守恒/往返/连锁体检 | ok | 1225对1225 / 可解 / 6组ok |

页面曲线里 4 的分布：14 步处在 4，最长连续 7 步。

## 老实说

- 开局重排把**平台从 3 段做成 4 段**、at4 从 13 提到 14；
- 但**免费前缀只从 15 降到 14**——开局“白/黄/青”那批免费车，靠换非锁链格压不下去，
  因为它们占全图 44%，总能在某处补位。
