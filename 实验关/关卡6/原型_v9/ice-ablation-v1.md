# 006 · E1-R3 数字冰移除消融

## 对比

| 窗口 | 无冰 v8 | 数字冰 v9 |
|---|---:|---:|
| 第一债务可点选项 | 5 | 1 |
| 第一债务死债 | 0 | 0 |
| 第二债务可点选项 | 5 | 2 |
| 第二债务死债 | 0 | 0 |

## 路线

| 项目 | 无冰 v8 | 数字冰 v9 |
|---|---:|---:|
| 全知符合计划 | 是 | 是 |
| PlayerSim符合计划 | 是 | 是 |
| 全知峰值 | 2 | 2 |

## 结论

移除数字冰不会改变全知或PlayerSim的六步路线与峰值，但会把第一债务窗口从1个可点选项扩大到5个，把第二债务窗口从2个扩大到5个。数字冰的必要性因此是“让人看见顺序约束”，不是“让关卡从无解变可解”。
