## 2. 合成器实现要点

### 2.1 5 套程序化背景母版（均 `SIZE` 参数化）

| 母版 | 结构 | 反碎块/防粘连处理 |
|---|---|---|
| `window_well` | 2px 分段外框（每 11 格换色）+ 2 道 3px 横梁 + 1 道 3px 竖梁 + 窗格内 4 行浅色横带 + 3×3 角花 | 外框按 11 格换色，避免 264px 整环；横/竖梁异色，避免十字连成 201px |
| `wave_ribbons` | `floor((y+round(2sin(xπ/8)))/4)` 正弦彩带，4 色循环 + 波峰 2×3 高光 | 每 13 列加 3px 竖向「彩带立柱」，把 140px 横带切成 ≤105px |
| `stagger_bricks` | 5×8 错缝砖（半块错位）+ 1px 勾缝，勾缝按砖行交替两色 | 勾缝网被颜色切断，最大块 55px |
| `seigaiha_arches` | 半径分层的青海波同心弧（中心 5 行 × 14 列交错） | 弧带 4/8/12px 三层，最大块 45px |
| `bunting_garland` | 3 段横幅（12/11/12）+ 2px 旗绳 + 6×5 倒三角旗 + 2px 花边 | 3px 立柱（p3）与旗绳（p2）分色，最大块 84px |

### 2.2 布局

- `pin`：底左 S1 / 底右 S2 / 顶中 S3；透明角允许「擦边」，实际 mask 重叠 0–2px。
- `diag`：左下 + 右上；**2 主体 1:1 最多只能到 ~36% 覆盖（<38% 下限），脚本对 diag 自动按 1.15× 最近邻放大**，`comp_03` 实测 38.9%。
- `trio_diag`：左下 / 中右 / 左上阶梯。

### 2.3 护栏与偏差（如实记录）

| 护栏 | 实现 | 偏差 |
|---|---|---|
| ① 满格正方形 | `zeros===0`、`W===H` | 无 |
| ② 轮廓零撞色 | 背景 4 色与所有主体外轮廓色 `id` 不同且 `RGB>=80`；外部背景做「邻接图着色」量化，保证相邻纹样不并色 | 无（6 张最小距离 87.1） |
| ③ 色数/碎色 | 合成图 10~16 色、每色 ≥16px；主体内 <16px 非轮廓色并入最近色 | 无 |
| ④ 美观/分隔 | 主体占比 38~58%、`avgColChanges` 7.5~16.5、`maxComp<=110` | 砖高取 **5px**（规格 4px）：4px 实测 `avgColChanges=17.3` 破上限；5×8=40px 仍是大砖。`seigaiha` 背景只用到 **2 色**（规格 3~4）：3 色弧带在 `maxComp<=110` 下会连成 >700px 大网 |
| ⑤ 预览 | 每图输出 `.preview.txt`（背景/合成/掩码） | 另加 `renders/*.png` 彩色放大图 |

## 5. 特别观察：多主体背景 vs `11.txt` 单调背景

| 版本 | rand | hum | **humMid** | **bufWave[2]** | allPass |
|---|---:|---:|---:|---:|---|
| #007 `11.txt` 原图（无腰带） | .517 | .500 | .800 | 1.02 | false |
| #007 `11.txt` 腰带版 | .508 | .450 | **.625** | **1.55** | true |
| #008 `comp_06`（chevron 背景） | .483 | .433 | .650 | 1.35 | true |
| #008 `comp_04`（青海波，偏简单） | .567 | .842 | .825 | **2.00** | false |
| #008 `comp_01`（井字，B 档） | .533 | .642 | .750 | 1.80 | true |

- **humMid**：多主体背景没有自动赢过 `2px` 腰带版——`comp_06` `.650` 与 #007 `.625` 基本同档（+2.5pp），`comp_04` 反而 `.825`。
- **bufWave[2]**：`comp_04` 的 `2.00` 是全场最高（但该关整体太简单），`comp_01` `1.80` 次之；**能同时进 C 档的 `comp_06` 只有 `1.35`，比 #007 的 `1.55` 低 0.20**。
- 结论：背景的「纵向换色密度」确实提供了分层（`avgColChanges 13–15`），但主体自带的 10–15 个小车色把盘面变软了；**背景负责“不千层饼”，难度仍要靠车场端的沉底/链/管/爬山去顶**。

## 6. 遗留 / 建议

1. **B 档 `comp_02`、C 档 `comp_04/05` 偏简单**：可对这三张图加 `--black-mode 3` / 提高 `--q-count` 或换更碎的母版重跑；本轮严格按任务单命令（`black-mode 2`）执行，未擅自加码。
2. **2 主体 diag 的 38% 覆盖下限**：1:1 上限约 36%，脚本已用 1.15× 最近邻放大解决；若总工不接受缩放，需把该 guard 对 2 主体放宽到 30–35%。
3. **砖高 5px / 青海波 2 色** 是为满足 `avgColChanges<=16.5` 与 `maxComp<=110` 的工程折中，已在 §2.3 标注。
4. **后段波峰**：本轮最高 `2.00`（青海波）来自“整体偏简单”的关；若下一步要“难且高潮”，建议在 `comp_06` 这类稳图上单独加一轮 `--games 120` 复核 + 终局机关强化。
5. **未动客户端 `bin/`**；6 关可直接作为后续换装候选。
