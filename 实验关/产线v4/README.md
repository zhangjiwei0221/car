## 3. v4 生成流程（简版）

1. **目标图**：正常关卡的 `blocks`（或目标图 TXT）。
2. **底边顺序**：`eliminationOrder(blocks, R, C, true)` → 轮次段。
3. **切车**：逐色总量守恒；轮次早的颜色优先放棋盘顶行。
4. **造债**：`--lump` 同色合并大车；`--split-colors` 拆指定色；`--auto-chain` 相邻同色成链。
5. **检查**：`RecoveryVariantCheck --bottom-only` + PlayerSim。
6. **迭代**：先修中段/后段债，再加冰/管道；不要用“加冰”代替结构设计。

详细步骤/命令/红线见 `生成流程_v4.md`。
