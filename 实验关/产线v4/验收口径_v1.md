# 产线 v4 / 分组4 验收口径 v1（2026-11-11）

> 用户确认：**“低流失硬门 + 旧目标感项只做诊断”**。
> 适用：产线 v4 生成的分组4关卡（三面墙 / 仅底边出口）。
> 指标定义仍沿用 `实验关/产线v3/指标口径_v1.md`；这里只规定“哪些是硬门、哪些是诊断”。

## 1. 硬门（必须全过）

| 类别 | 项 | 目标 |
|---|---|---|
| 基础 | 容量守恒、无空格、可通关（最小路线） | 必须 ✓ |
| 基础 | 排版 `LayoutScore` | hard 0 |
| 压力 | 峰值 | =4 |
| 压力 | 玩家中段 | 45–80% |
| 压力 | 容错 | 11–15/20 |
| 选择 | 开局可点 | ≥5 |
| 恢复 | `C0@buf<5` | =0 |
| 恢复 | `F0@buf≥3` | ≤2 |
| 恢复 | 点击结算 `policy0` 或 `forced` | 至少一个 Y |
| 恢复 | free-first 0 复活 | Y |
| 后段 | 玩家后20% at3 | ≥2 |
| 真实玩家 | PlayerSim 2 复活 | Y |

> **PlayerSim 0 复活是诊断，不是硬门**；分组2/3 也大量是 p0=N、p2=Y。硬门只要求“2 复活能过”。

## 2. 诊断项（只记录，不否决）

- 19 项里的 **象限并行度**、**主体并行度**、**未动主体**、**at4**；
- PlayerSim 0 复活；
- 19 项其余软项（最长连续免费、低压、决策度等）；
- 选择空间 M/entropy、D 分数。

**原因**：三面墙/底边入口本身就是用“入口路径”解决目标感；再用四边时代的象限/主体并行当硬否决，会和机制目标冲突。它们仍可用于解释“玩家会不会觉得散”，但不决定 G4 是否可上线。
