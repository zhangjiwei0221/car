## 4. 结论

这是第一张“按底边重排”的可用骨架，v2 已把中段补起来，但仍不是成品：

- 底边轮次切车 + 同色大车 + 少量链，能把 peak 做到 4、mid64、tol11、open7；
- v2 的后段 at3 从 0 到 1、at4 从 3 到 4，但还没到 2/5；
- 目标感三项（象限/主体/未动主体）仍弱；
- PlayerSim 0 复活仍 N，说明债的时序还不对，不能只看点击结算。

下一步优先补后段可恢复债和目标感，不是继续加冰；每次跑 `--bottom-only` + PlayerSim。
