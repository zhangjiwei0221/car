# 产线 v7 · 三面墙 + 四方向瞬时连锁（2026-11-22 立项）

> **定义（用户 2026-11-22）**：**三面墙（仅底边入口）+ 四方向瞬时连锁（策略 0）**——即当前**分组4 客户端的实机配置**。
> **与 v6 的关系**：v6 是“四边入口 + corner + 非瞬时 + 无墙”的完整流程，已冻结。v7 **沿用 v6 的框架，重标所有参数**：消除策略与入口变了，颜色暴露顺序变了，v6 的数字不能借用。
> **材料位置**：`实验关/产线v7/材料/`（2026-11-22 自 `产线v6/难度带/三面墙/` 迁入）；**v7 的规则与结论以本文件为准**。

---

## 1. 为什么单独成线

| 维度 | v6 | v7 |
|---|---|---|
| 入口 | 四边 | **仅底边（bottomOnly）** |
| 消除策略 | 非瞬时（corner 排序） | **四方向瞬时连锁（策略 0）** |
| 墙 | 无 | **三面墙** |
| 指标口径 | PInterp 默认 | `--bottom-only --instant-chain` |

同一关、同一障碍，只换策略：随意档差 **6pp**（34 号 .563 → .500）；冰的剂量甚至**方向反转**（v6 拆半 −3~7pp，v7 +4pp）。所以 v7 必须独立标定。

## 2. 沿用 / 不沿用

**沿用**：七步流程、步 2.6 规格（9 条）、步 2.7 词典序、三段口径与早死门、工具链（全部支持 `--bottom-only`/`--instant-chain`）。

**不沿用（必须重标）**：
- 链的颜色分类（按墙暴露表重算）、位置（行 ≤2）、车数约束（2–6）；
- 冰的格与 param（**格比参数更重要**）；
- 管的剂量与方向；
- freeP3 / 熵等参考指标（现有工具是四边口径，v7 需要自己的压力指标）。

## 3. v7 规则（截至 2026-11-22）

### 3.1 链（2026-11-23 补充：三锁链 `3-car chain` 专项实验结论，日志 §1188/§1190）
- **颜色**：按 `扫描_v1 --bottom-only --instant-chain` 的逐色表取 mid/weak-mid，**且车数 2–6**（14 辆车的大色绑不动，**全盘唯一车 `cars===1` 严禁入链**）；
- **位置（2026-11-23 更新：错落分布）**：**行 2–3（`row 1..2`）放 2 对破口链**（10–25% 进度咬合最强，实测压 15–25pp）+ **行 4–5（`row 3..4`）放 1–2 对中腰链**（45–65% 进度接力）；`建B_v1.js` 传 `--max-row 4`。第 1 行（`row 0`）严格无链；
- **布局**：分对、不串排（第二排 `row 1` 强制留 `≥3` 个无链无冰畅通单车口）；
- **三锁链（3连链，`--with-3chain`）安全使用铁律（图 3 固定底座 5 变体对照实测，日志 §1190）**：
  - **为什么三锁链不能绑 3 辆异色大车？（负结果 `D1`）**：在行 1–2 绑 `[28px+28px+34px]` 异色三大车三连链，短视真人胜率从基准 `.567` 暴跌至 **`.233`（−33.4pp）**——点开瞬间 3 辆 28–34px 大车全部吃不饱，一次性占死 3 个暂存槽当场暴毙（点击成本与消除成本双高）。
  - **正确配方（「2 小 1 大」配比，`D2/D3` 正结果）**：在同样位置改配 **2 辆 `12–14px` 冗余小车 + 1 辆 `28–34px` 大车**（如 `[12px+14px+34px]` 或 `[12px+28px+12px]`），短视真人胜率立刻恢复至 **`.522 / .422`（认真档 `.989–1.000`，早死 `0%`，棘轮 `0f/0t`）**，中段暂存峰值保持在 `3.57–3.80 格`！物理机制：点开三锁链时，2 辆 12px 小车在浅层当场吃满秒退，实际只留 1 辆大车占 1 个槽——**既有“一把解开三锁链”的视觉爽感，又把实际占槽成本从 3 格降到了 1 格**。
  - **中深层下沉三锁链（`D4` 行 3–4 `[12+12+20]`）**：若前排保留 3 对二连链不动，再在第 3–4 行叠一条三连链会把短视真人压到 `.389`（中段峰值 `3.93 格`）；若用中层三连链替掉 1 对前排链（`C4`），则难度放宽至 `.889`。因此全盘有 1 条「2小1大」三锁链时，二连链保持 2 对（共 3 组链，总链格 7 格）最为均衡。

### 3.3 管（2026-11-23 更新：大小车错配新底座 + 双尺子 6 变体对照实测，日志 §1189）
在全新的「大小车错配（`--stagger-cap`）」底座上，用双尺子（原随意档 + `--human-casual` 短视真人 + `bufWaveMean` 三段暂存区波形）在 3 套独立底座（v7 `G4-2` 图 3、v7 `G4-6` 图 11、v6 `G3-45` 图 140）上对 6 种管道装法做了严密单变量对照，推翻并修正了旧底座下的管道结论：
1. **为什么以前觉得“加管道会吃掉难度”？（正负归因）**
   - 旧底座每辆车均分 `~20px`，对半拆后变成 `10px` 极小碎车（`V4` 拆 20px 中小车：v7 短视真人从 `.567` 升至 `.600` 变简单 +3.3pp；`V5` 传统抽车进管出 3 个黑块：短视真人升至 `.700` 变简单 +13.3pp 且毁棋盘）。
   - **新法则（只拆 `≥26–50px` 冗余大车，严禁拆 `≤20px` 中小车）**：在 `--stagger-cap` 底座上只挑最大的 3 辆冗余大车对半拆（如 `56px → 28+28px` 或 `28px → 14+14px`），拆出来的半车依然是标准容量，**不仅不吃掉难度，还能通过管口大小车顺序精准调控难度与心流波形**！
2. **管道队列顺序方向性定律（「管口放大车」vs「管口放小车」相差 22.2pp）**：
   - **管口放大车 `[32, 14, 14, 14]`（`--pipe-mouth big`）**：v7 图 3 短视真人从 `.567` 压至 **`.467`（增难 −10.0pp）**，中段暂存峰值从 `3.57` 推高到 **`3.90 格`**；v6 图 140 原随意档从 `.667` 压至 **`.617`（增难 −5.0pp）**，短视真人从 `.317` 升至 **`.550`（+23.3pp，因消除了盘面 55–58px 巨车死局）**。物理机制：管口大车像“中路塞子”，玩家必须先凑够外层同色块把管口大车一口喂饱，才能掏出肚子里的 3 辆 14px 顺手车并打通第 5–6 行纵深通道。

3. **最大实用发现：「管道替深水冰」（1 根管口大车 4 辆管 = 拔掉行 4 & 行 6 的 4 块深水冰）**：

### 3.7 步 2.4 剂量标定（2026-11-22 新增，解决“图换色库后障碍加少了”的漏洞）
