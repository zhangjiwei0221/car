# 产线 v7 · 三面墙 + 四方向瞬时连锁（2026-11-22 立项）

> **定义（用户 2026-11-22）**：**三面墙（仅底边入口）+ 四方向瞬时连锁（策略 0）**——即当前**分组4 客户端的实机配置**。
> **与 v6 的关系**：v6 是“四边入口 + corner + 非瞬时 + 无墙”的完整流程，已冻结。v7 **沿用 v6 的框架，重标所有参数**：消除策略与入口变了，颜色暴露顺序变了，v6 的数字不能借用。
> **材料位置**：`实验关/产线v7/材料/`（2026-11-22 自 `产线v6/难度带/三面墙/` 迁入）；**v7 的规则与结论以本文件为准**。

---

## 1. 为什么单独成线

| 维度 | v6 | v7 |
|---|---|---|
| 入口 | 四边 | **仅底边（bottomOnly）** |
| 消除策略 | 非瞬时（corner 排序） | **四方向瞬时连锁（策略 0）** |
| 墙 | 无 | **三面墙** |
| 指标口径 | PInterp 默认 | `--bottom-only --instant-chain` |

同一关、同一障碍，只换策略：随意档差 **6pp**（34 号 .563 → .500）；冰的剂量甚至**方向反转**（v6 拆半 −3~7pp，v7 +4pp）。所以 v7 必须独立标定。

## 2. 沿用 / 不沿用

**沿用**：七步流程、步 2.6 规格（9 条）、步 2.7 词典序、三段口径与早死门、工具链（全部支持 `--bottom-only`/`--instant-chain`）。

**不沿用（必须重标）**：
- 链的颜色分类（按墙暴露表重算）、位置（行 ≤2）、车数约束（2–6）；
- 冰的格与 param（**格比参数更重要**）；
- 管的剂量与方向；
- freeP3 / 熵等参考指标（现有工具是四边口径，v7 需要自己的压力指标）。

## 3. v7 规则（截至 2026-11-22）

### 3.1 链
- **颜色**：按 `扫描_v1 --bottom-only --instant-chain` 的逐色表取 mid/weak-mid，**且车数 2–6**（14 辆车的大色绑不动）；
- **位置**：行 ≤2（墙下第 2 行在 10–21% 激活）；
- **布局**：分对、不串排；
- **组合效应**：单独每对可能 ≥.96，三对组合才咬（34 号）；单独棘轮 FAIL 的链组合后可能 PASS，但不可靠。

### 3.2 冰（2026-11-22 补完：暴露盒数标定 + 链留豁口冰封豁口）
- **为什么 v6 的冰数字（p6–15）在 17 色墙下像贴在空气上**：`exposure_probe --bottom-only --instant-chain` 测得 7×7 盘面各行**首次暴露时已拿车数（E）与首次被拿时已拿车数（P）中位**为：
  - 行 1：`E=4 / P=9`；行 2：`E=9 / P=18`；行 3：`E=15.5 / P=23`；行 4：`E=21 / P=28`；行 5：`E=28 / P=35`；行 6：`E=32 / P=41`。
  - 若行 3 贴 `p14`，玩家挖到第 3 行时早就拿够 15 辆车，冰在暴露前已化光（0 作用）；若贴到 `>P` 且锁死同色全部剩余车，认真档直接崩到 `.03–.15`（无差别杀伤）。
- **v7 9 块冰标准配参表**（落在 `[E, P]` 窗口内，只冻冗余色）：
  - **行 1 豁口冰（1–2 块）**：`p=9–10`（**核心机制：“链留豁口 + 冰封豁口”**——第 1 行链与链之间留 1–2 个单车豁口避免串成横链墙，用 `p9–10` 冰暂时封住豁口，逼玩家在 10% 进度先解链、解完链冰刚好碎，单靠此项可把 `.846` 压到 `.628`，认真档 `.97+`！）；
  - **行 2（2 块）**：`p=14–16`；
  - **行 3（2 块）**：`p=19–21`；
  - **行 4–5（1–2 块）**：`p=24–28`；
  - **行 6（2 块）**：`p=33–34`（≈ 0.85×P）。

### 3.3 管（2026-11-22 补完：17 色墙下实测）
- 在 17 色墙下，中段（行 3–5）4 辆混色管（整车或拆半，无论藏大色还是稀缺色）对随意档只有 **−1~−4pp** 的微调作用（玩家挖到第 4 行时可选面已大）；
- **拆半管（`split_pipe_v1`，1 整 + 3 半，零黑块）** 可与“4 链 + 9 冰”完美共存（39 号：随意 `.655/.673/.647`、认真 `.96+`、早死 `8.7%`），作为三件齐全的形态旋钮，不损伤公平性。

### 3.7 步 2.4 剂量标定（2026-11-22 新增，解决“图换色库后障碍加少了”的漏洞）
不同图源（34 色 vs 17 色）单车色数量差一倍，固定“1–3 条链”会在厚供给图上失效。**进步 2.5 前必须先做剂量标定**：
1. **跑暴露表**：`exposure_probe_45579.js <底座> --bottom-only --instant-chain`，拿到各行 `E/P` 中位，确定 9 块冰的逐行参数；
2. **跑链剂量梯**：在行 1–2 按 2 → 3 → 4 → 5 对链测随意档，找到把纯链压到 **`.78–.86`** 的最小链数 $k$（34 色图通常 $k=3$，17 色图 $k=4$）；
3. **链留豁口 + 9 块标定冰**：$k$ 对链在行 1–2 错位排布（同行链对之间留单车豁口，不串成横墙），用 9 块冰（含 1–2 块行 1 豁口冰 `p9–10` + 行 2–6 标定冰）把 `.82–.85` 压进 **`.58–.66`**；需要管道形态时加 1 根深行混色拆半管。

### 3.4 换位（v7 新工具）
- `SwapClimb_v7.js`：以墙+瞬时随意档为适应度做随机换位爬山，目标可含**早死 / 认真 / 倒序**；
- 实测：单次换位 ±2.4pp；180 用 11 次换位从 .963 → .683；免疫图（1.000）换位救不动。

### 3.5 容量与同色大小车错配（2026-11-22 突破，日志 §1181）
- **同色大小车不等分错配（`SplitLevel_v722 --stagger-cap` / 前小后大）**：将同色均等 `19px+19px` 改为 **`14px（浅层小车）+ 25px（中深层大车）`**（总像素 100% 守恒，每关有 11–15 种车面额）。
- **物理机制与方向对比（图 3 同链同冰实测）**：
  - **均等车（`19+19`）**：随意 `.657`；
  - **前大后小（`25+13`）**：随意升至 **`.860`（变简单 +20.3pp）**——策略 0 下前排大车帮玩家一口吸干浅层大块加速破口；
  - **前小后大（`14+25`）**：随意压至 **`.603`（变难 −5.4pp，比前大后小难 −25.7pp，认真 `.977`，早死 `0%`，棘轮 PASS）**——浅层小车 `14px` 在浅层吃满退场不占坑但只吃掉色块一半；中段 `25px` 大车露出时浅层残余仅 `10–15px`，大意玩家点上去即剩 `10px` 卡在暂存区，**必须找挡在深处同色外面的异色车剥开下一层才能把暂存区里的大车喂饱救走**。

### 3.6 开局开阔度（v7 诊断）
- 墙关典型形态：**宽而浅**（7 色 × 每色 1 辆），四边关“窄而深”（5 色含 2 辆）；
- 规则定为 **“首对 ≤4 步（≤10% 进度）”**（34 号第 4 步出现；img1 天然 depth=2）。
