## 验收口径

```
主指标（必须）：at4 ≥ 20 且 run4 ≥ 12
硬约束：可解、峰值 ≤ 4、sum(count)=像素数、首手消除 ≥80% 容量
参考：late4（与 at4/run4 抢预算，不强制）
```

## 怎么复现

```bash
EVAL_WORKERS=2 node 03_工具/正式版/ProduceBatch_v747.js \
  --dir 关卡 --list "<12 张图名>" --out 输出/批次_主指标 \
  --jobs 4 --rounds 3 --samples 60 --plan --attempts 2
```
