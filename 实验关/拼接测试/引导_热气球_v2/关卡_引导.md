# 引导（修正版）：四框全保留，只让热气球贴边

## 上一版错在哪

把另外三个主体边框**涂成背景红**：等于把“四个边框色”这个设计直接抹掉，
棋盘上就剩一堆红色车 —— 那不是引导。

## 这一版的做法

**不改任何颜色，只改构图**：

- 热气球（左上）**保持贴画布边**；
- 另外三个象限**整体内缩 2px**，空出来的 2px 用背景（1/31 的 2px 棋盘）填；
- 结果：**只有热气球边框（14 青）和背景贴边**，另外三个框都藏在背景带后面。

画布 44×44（1936 px），13 色不变。

## 验证

| 项 | 结果 |
|---|---|
| 贴画布边界的颜色 | **只有 1、31（背景）和 14（热气球边框）** |
| 取用顺序 | **14@1** → 3@2 → 31@3 → 1@5 → **18@8** → **19@13** → **11@18** → 30@27 → 26@29 → 15@30 → 28@32 |
| 引导 + 构建器 8 轮 | 峰值 4、**at4=9、run4=5**、道具 0、49 步可通关 |

也就是说：**玩家第一步必然在开热气球**；另外三个主体要到第 8/13/18 步才被碰到。

## 代价（说清楚）

- 画布从 40×40 变成 44×44（内缩要地方），像素 1600 → 1936；
- 压力比“涂红版”低（at4 9 vs 15），因为热气球边框只有 5 辆车，撑不起长平台；
- 想要更高压力，得让热气球边框更“厚”（比如 2–3px），边框车变多才能成链。
