# 引导实验：让玩家从「热气球」开始消

## 原理（三件事）

1. **只有目标主体的边框贴着画布边界**：它的边框色最早被暴露；
2. **其余三个主体的边框用 2px 背景色盖住**（本图用红色 1），它们要等背景被吃掉才露出来；
3. 于是开头能点的、能填满的只有「热气球边框色 14（青）」，玩家第一步必然在开热气球的壳。

## 目标图改造

- 原图：`拼接实验txt.txt`（4 象限，四个边框色 14/18/11/19 全部贴边）
- 改造：`拼接实验_热气球优先.txt` —— 热气球（左上）保留贴边；
  另外三个象限外侧 2px 用背景红 1 覆盖 → 它们的边框不再贴边。

![改造后](../renders/拼接实验_热气球优先.png)

## 验证：取用顺序真的变了

| 版本 | 颜色首次取用顺序 |
|---|---|
| 原图（v7） | 14@1 → 1@2 → 11@3 → 18@7 → 19@15 …（四个边框都早） |
| **引导图（自切）** | **14@1 → 1@2 → 31@4 → 18@6 → 19@13 → 11@23** |
| **引导图 + 构建器** | **14@1 → 1@2 → 31@3 → 15@4 → 3@6 → 26@7 → 11@8 → 18@9 …** |

热气球边框（14）永远是**第 1 步**；另外三个边框被推到第 8–24 步。

## 压力（引导版 + 构建器 6 轮）

| 项 | 值 |
|---|---|
| 页面 | 峰值 4、**at4=15、run4=8**、道具 0 |
| 最长无压段 | 3 步 |
| 全知 | 49 步 |

## 结论

“从某个主体开始消”**可以实现**，靠的是**画布边界上只暴露一个主体的边框**，
其余主体的边框藏在背景带后面。改造只需要改目标图，不改引擎。
