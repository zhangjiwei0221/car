# 三层合成器 v1（M1）

## 配置

```json
{
  "size": 44,
  "background": [31, 1],          // L2：奶油 + 红 2px 棋盘
  "border": [25, 12, 25, 12],     // L3：上/右/下/左四段
  "subjects": [
    {"cell":"TL","outline":14,"depth":1, ...拉面},
    {"cell":"TR","outline":28,"depth":3, ...独眼兽},
    {"cell":"BL","outline":19,"depth":5, ...鹦鹉},
    {"cell":"BR","outline":16,"depth":7, ...杯子蛋糕}
  ]
}
```

## 结果

| 指标 | 值 |
|---|---|
| 画布 | 44×44 = 1936 px |
| 色数 | **14**（上限 15） |
| L1 阶梯 | **14@3（深1）→ 28@7（深3）→ 19@19（深5）→ 16@29（深7）** |
| 关卡 | 49 步、峰值 1、at4=0（合成图本身没压力，需构建器） |

**深度决定先后**：depth 1/3/5/7 → 首次被消 3/7/19/29 步，完全单调。

## 命令

```bash
node 03_工具/正式版/ComposeLayers_v729.js --config 实验关/三层/三层_v1_配置.json \
  --out 实验关/三层/三层_v1_44x44.txt --png 实验关/renders/三层_v1.png
node 03_工具/正式版/SplitLevel_v722.js --target 实验关/三层/三层_v1_44x44.txt \
  --out 实验关/三层/关卡_三层_v1.json --rows 7 --cols 7
```
