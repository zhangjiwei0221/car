# 四象限合成 v1（M3 突破：引导 + 压力同时成立）

## 关键发现

**主体内部必须是“官方图的象限”（碎色马赛克）**，用干净图标素材做主体时，
无论深度怎么调、是否抖动、棋盘多大，at4 都是 0。

| 主体来源 | F=0 步数 | at4（构建前） | at4（构建后） |
|---|---:|---:|---:|
| 干净图标（拉面/独眼兽/…） | 2 | 0 | 0 |
| **官方象限**（00011/00041/00071/00101） | **12** | 3 | **26** |

## 配置

- 画布 44×44 = 1936 px，**15 色**（超限时按最近色合并）；
- 四个官方象限的“左上象限”当主体，深度 **0 / 1 / 2 / 3**；
- L1 描边：14 / 28 / 19 / 16；L2 背景：31/1 棋盘；L3 保留象限自带边框。

## 结果

| 项 | 值 |
|---|---|
| 容量 | **1936 = 1936** |
| 页面 | 峰值 4、**at4=26、run4=20**、道具 0 |
| 全知 | 45 步，窗口 5-6:4 / 13-33:4 / 36-43:4 |
| 链条 | 3 组、合法 |
| 审核 | ⚠️ 仅“前期卡点”（允许） |
| **L1 阶梯** | **14@1（深0）→ 28@3（深1）→ 19@12（深2）→ 16@31（深3）** |

**这是第一张“引导 + 压力”同时成立的合成关。**
