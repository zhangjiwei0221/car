# 四等分 v2（A 版）——画面可读 + 审核通过

## 目标图怎么拼的

- 画布 **38×38**，最外 1px 是 L3 四段边框（25/12/34/13）；
- 四个象限**完全等大（18×18）**，每个取一张官方图的一个象限（一个主体）；
- 每个主体一圈**独有描边**：14 / 28 / 19 / 16（并色时受保护，不会被合并）；
- 主体内部**不做量化**：只把全局占比 <1.2% 的稀有颜色并入最近色（`--min-color-share 1.2 --no-clean`）；
- 共 **15 色**。

## 关卡结果

| 项 | 值 |
|---|---|
| 容量 | **1444 = 1444** |
| 页面 | 峰值 4、**at4=25、run4=20**、**道具 0** |
| 全知 | 42 步；窗口 **8–35:4**（连续 28 步）、37–40:4 |
| midLate4 | **16/18（89%）** |
| 链条 | 2 组、合法 |
| **审核** | ✅ **严格通过**（前期 3.0 < 3.2 / 后期 4.0 / 峰值 4） |
| L1 首用 | 28@2 → 14@4 → 19@10 → 16@33 |

## 这版的意义

这是**第一张同时满足三件事**的关：

1. **画面能读**（四个主体内部结构原样保留，能认出是什么）；
2. **有压力**（at4=25、run4=20、窗口连续 28 步）；
3. **过严格审核**（不是“前期卡点”那种擦线）。

## 已知瑕疵

- 四个主体**同深度**，所以 L1 先后不完全单调（28 在 14 前面）；
- 若要严格阶梯，需要深度差（0/1/2/3），但那样主体大小就不等了。
