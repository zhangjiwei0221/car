## 2. 换位加压与「一块冰」起点

```bash
# 第 1 次换位：raw 底座，200 轮
node 03_工具/正式版/PressureBuild_v5.js 实验关/产线v5/C13_十关/154/关卡_ZC_154b_default.json \
  --out 实验关/产线v5/C13_十关/154_p_raw --iters 200 --seed 1 --p3 0.32 --nrand 12
# → freeP3=0.163、win=0.917、H=1.515、open 7（freeWon=true）

# 加 1 块数字冰 r2c5 delay 7（把自由路线的长债务窗口顶到 buffer≥3）
# 第 2 次换位：200 轮
node 03_工具/正式版/PressureBuild_v5.js 实验关/产线v5/C13_十关/154/关卡_ZC_154_base_rawice.json \
  --out 实验关/产线v5/C13_十关/154_p_ice --iters 200 --seed 1 --p3 0.32 --nrand 12
# → best：freeP3=0.327、win=0.917（12 局）、H=1.674、open 6、freeWon=true
```

- 为什么加 1 块冰：第一次换位后的自由路线有 42/49 步「无车可吃满」（fillOpts=0），但 buffer 只稳定在 2；给 r2c5 加 delay 7 的冰后 buffer 稳定到 3，freeP3 从 0.163 跳到 0.69，H 掉到 1.29；**再跑一次 PressureBuild 换位**把 H 拉回 1.67，同时 freeP3 回落到 0.327（仍在门槛内）。
- 最后补 2 个问号（r0c0、r6c6）：所有指标不变（freeP3/win/H/open 逐项相同），用于满足「少量冰/问号」的观感。
- 最终处方：**1 个数字冰 + 2 个问号、0 锁链、0 管道**。

## 4. 失败与重试记录

1. **未补碎色**：`关卡_ZC_154_default.json` / `guard0` / `guard0_build` / `guard0_rx` 全部 `hard=1`（L5：色 7 被撕碎，138px / 74 块 / 最大 3px）；CarSplitPlan 无硬门候选。→ 并色 7→1 后重建。
2. **补碎色后**：`guard0` 硬门过但 ratchet=FAIL；KnobPlan `KP_cap_31_big2small` 也 ratchet=FAIL。回退到 raw 切车版。
3. **链版对照**（`guard0_rx`，9 链）：freeP3=0.605，但 win=0.25（12 局）、H=1.389、ratchet FAIL；链是陷阱，放弃。
4. **去链 Rx 版 + 换位**（`154_p/`，seed1/seed2/p3=0.28）：freeP3 只有 0.041 / 0 / 0.041；卡在 buffer=2。
5. **加冰扫描（去链 Rx 版）**：逐格加 1 块冰（delay 8，25 个候选）freeP3 不动；加 2 块 delay 8/12 要么不动、要么第 5–11 步走死；4 块 delay 20 → freeP3 0.667 但 freeWon=false、win 0.417、H 0.986。
6. **raw 版 + 换位**（`154_p_raw/`）：freeP3=0.163、win 0.97（100 局）、H 1.515；有长债务窗口但仍差 buffer 1。
7. **raw 版 + 1 块冰（r2c5 delay 7）+ 再换位**：**成功**（本文最终版）。

## 5. 结论

图 154 的自由路线有一条 42 步的「无车可吃满」窗口，但 buffer 原本只到 2。给 r2c5 加一块 delay 7 的数字冰把窗口顶到 buffer=3；再用第二次换位把被冰压低的熵拉回（H 1.29→1.67），freeP3 回落到 0.327，仍 ≥0.25。五项门槛全部达标。
