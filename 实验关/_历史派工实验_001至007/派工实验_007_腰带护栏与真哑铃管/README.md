## 6. 施工发现

1. **真哑铃确实能落地**：补上管口侧后，两关终版队列 `[28,12,12,28]`（原图）与 `[28,14,14,28]`（微创），管口/管底都是 ≥24px 整车，逐色容量 1024/1024 守恒。
2. **棘轮优先选样立竿见影**：原图 6 style 里只有 1 个 ratPass=true，旧逻辑按 rand 距离会选到 ratPass=false 的关；新词典序两关终版都 `ratPass=true`。
3. **腰带护栏把死墙拆了但没治好 style0**：39px 独苗消失，`humFair` 选样版从 #006 的 `.958` 升到 `.983`；style0 的 `.308` 依旧，根因在链/冰，不在腰带。
4. **后段波峰**：微创版 `bufWave[2]=1.55`，比 #006 的 1.02 明显回升，距 #002 旧版 1.73 还差 0.18（40 局样本噪声内）。真哑铃管底 28px 大车 + 隔板沉底的方向是对的。
5. **视觉代价**：新规则选中的腰带色是绿色 19（距离 217）而非粉色 2（距离 96）。若总工要求“同色系阴影”，把 `near` 从排序第一键降为第二键即可选回橙色 28（距离 99.6）。
