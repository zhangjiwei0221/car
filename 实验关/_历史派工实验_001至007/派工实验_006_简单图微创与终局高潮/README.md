## 2. 刀 A：`--wall-band` 零毁容阴影腰线

```
改前：1024px / 13 色 / 最大连通块 136px（色1，行 4..18）
改后：1024px / 13 色 / 最大连通块  76px（色1，行 4..10）
改动：24px，全部在行 11–12、列 14–25
腰带色：2（图内已有，RGB 距离 95.8，占比 15/1024=1.5% → 39/1024=3.8%）
色1：140→124px；色33：210→202px（腰带桥接吃掉 8px 黑条纹）；色数不变，无新增 <8px 颜色
```

腰带把 `136px` 红块干净切成 `76px`（上）+ `40px`（下），轮廓未毁容（见 `ascii_band_compare.txt`）。

**副作用（重要）**：`SplitLevel` 把新加的 24px 腰带与原有 15px 色2 合成了**一辆 39px 的纯色 2 车**（`caps` 里出现 `39:1`，全盘唯一一辆色2 车）。这辆“单色债车”在 board row 4（约 30% 进度）只要没全露出来就点不动，成了认真档的死墙：
- band style0：humFair `.292`
- band style3：humFair `.100`，p=1 的 `deathMean = 0.284`（28% 进度全灭）
- band style1（主选）：humFair `.958`，恰好吃到它时已全露，侥幸没事

→ 下一次改进方向：腰带色必须选**图内已有 ≥3 辆车/≥腰带像素×3** 的颜色（或直接并入同位置的 33 黑条纹），禁止把 <20px 的小色抬成单车大债车。

## 3. 刀 B：隔板色沉底 + `--pipe-mouth dumbbell`

- 12/12 次建造全部 `shellPlaced=2 / corePlaced=2 / shellSunk=2`（机制 100% 触发，见各 `rep_*.json` 的 `climax` 字段）。
- `dumbbell` 队形（管口→管底）：
  - orig style2：`[28,14,14,16]`（口 28 大车 ✓，底 16 未达 ≥22 ✗）
  - band style1：`[19,12,14,14]`（口 19、底 14，**退化**）
  - 原因：`split_pipe_v1` 只能“1 整车 + 3 半车”，11.txt 的底盘最大车 32px → 半车只有 16px；没有 ≥44px 的车就拆不出 ≥22px 的管底大车。
- 管口大车压中段有效：orig style2 的 28px 管口车是全盘最大的入口塞子。

11 点 `p` 曲线（短视真人，p=0→1）：

```
旧版 : .55 .55 .65 .60 .75 .88 .85 .95 .97 1.00 1.00
原图 : .35 .40 .53 .53 .50 .70 .78 .90 .93 .97 1.00
微创 : .65 .57 .70 .75 .80 .95 .88 .82 .93 .95 1.00
```

**主结果**：
- 原图升级版把 `humMid` 从 `.875` 压到 `.700`（−17.5pp，超出 40 局噪声量级），C 档四门（rand/hum/humMid/fair）全部进带，**唯一硬伤是棘轮**（free-first 路线在第 22 步 buffer=4、3 条链同时锁死 → `progressDead`；solver/max-eat 仍能通关）。
- 但 `bufWave[2]` 从 `1.73` 掉到 `0.90`，后段高潮没顶起来。
- 微创版反而更水：rand `.608`、humMid `.950`，`bufWave[2] 1.02`。

两版的 style 不同（原图选中 style2，微创选中 style1），主表不是严格同底对照 → 见下节消融。

## 6. 客观结论（对应交工区 §3）

1. **仅靠车场「隔板色沉底 + dumbbell + C 档爬山」**：能把原图压到 `rand .375 / hum .425 / humMid .700 / fair .967`——C 档四门全进带，**但棘轮探测到 buffer=4 三链锁死的路线，`allPass=false`，不可直接上线**；后段波峰反而从 1.73 掉到 0.90。
2. **再加零毁容微创腰带**：主跑选中 style 的 `humMid` 没降反升（.950），后段波峰 1.02；同 style（style2/不沉底）能看到腰带把 `humMid` 压 −30pp、后段 +0.07、棘轮修好，但 rand 抬到 .683。腰带当前实现有“小色被抬成 39px 单车”的副作用，2/3 个 style 的认真档在 ~28% 进度撞墙。
3. **两把刀都不是“免费难度”**：它们改变的是中段暂存压力与车的债主结构，后段波峰 `bufWave[2]` 没有稳定提升；要顶后段，仍需另配“终局明牌挪车”或更深的管底大车（11.txt 拆不出 ≥22px 半车）。

## 8. 遗留 / 下一步建议

1. **腰带色护栏**：候选色要求 `total[cand] >= 3 × 腰带像素` 且“图内已有 ≥3 辆车”，避免 39px 单车债车；或允许腰带并入中腰处已有的黑条纹色（33）。
2. **棘轮感知选样**：`BuildV7Stagger_v1` 的 best 回退在 6 个 style 全不过时仍按“rand 最接近目标”选，会选出棘轮 FAIL 的关卡；建议 best 排序把 `ratPass` 放第一位。
3. **dumbbell 真正落地**：需要 `split_pipe_v1` 支持“拆 44px+ 大车”或允许 2 整车 + 2 半车，否则 32×32 图上管底只能到 14–16px。
4. **后段波峰**：`(6,2)/(6,4)` 钥匙 + `(5,2)/(5,4)` 顶盖的机关本次 12/12 都摆上了，但 40 局样本里 `bufWave[2]` 没有稳定抬升；需要用 `--games 120` 或 3 seeds 复核，再决定是否继续加“终局明渠”。
